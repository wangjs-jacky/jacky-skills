# 知识格式与自动写回

创建者先按领域和既有 schema 裁剪此模板，填写变量。运行时在新增、修正或重复验证经验时读取。

## 唯一归属和路由

| 文件 | 维护内容 |
| --- | --- |
| `references/{{COLLECTION}}/index.md` | key、别名、适用场景和对象档案链接 |
| `references/{{COLLECTION}}/<key>/index.md` | 跨 operation 的事实、限制、来源、操作目录 |
| 对象下 `operations/<operation>.md` | 单个用户目标的可复用经验 |
| `experience.local.md` / `local/` | 私有实例入口、配置映射与证据位置 |

key 和 operation slug 稳定且使用 kebab-case。平台事实只在对象档案维护；操作目录只保存必要摘要和链接，不复制步骤。公共文档不能链接私有证据路径，私有实例可以引用公共知识。

## 对象档案

最小内容：能力或对象边界、跨操作共用的事实、操作目录、共享陷阱和来源。来源说明核对日期及适用范围，未知写未知；核对一项不能刷新整份档案的验证日期。

对象索引和 operation 的字段一致。额度、价格、平台限制要带计量单位、作用域、周期、套餐/版本和超限行为，并指向当前官方来源；这类字段仅在领域实际需要时添加。

## Operation

建议最小元数据（迁移时保留适用的既有格式）：

```yaml
---
{{KEY_FIELD}}: {{KEY}}
operation: {{OPERATION}}
status: documented
last_verified: null
---
```

正文记录：

1. 目标：一个用户可理解的结果。
2. 适用状态、前置条件与授权：避免把一例成功推广到所有环境。
3. 设计或执行步骤：稳定语义、关键分支和需要重新观察的节点。
4. 成功标准：可以实际观察或读回的结果。
5. 常见坑与恢复：区分现象、已验证根因、恢复方法与待核实假设。
6. 证据与未完成项：日期、来源类别、观察结果、适用范围和剩余问题。

不要把点击流水、临时引用号、动态 ID 和完整响应当作操作知识。浏览器定位策略要重新核对当前页面；平台限制要重新核对当前适用条件。

## 可信度与日期

| 状态 | 含义 | last_verified |
| --- | --- | --- |
| documented | 文档/设计或未经过真实场景验证的指导，标明来源 | `null` |
| partial | 有部分运行证据，目标或成功条件仍有缺口 | `null`，局部证据日期写正文 |
| verified | 当前声明的目标与全部成功标准有真实证据 | 实际成功日期 |

状态表示知识可信度，不是任务调度状态。源码检查、文档核对或结构校验不等于业务执行成功；本地证据不等于生产验证。诊断完成与修复完成分别判断。

导入历史经验保留旧日期；迁移日不是验证日。旧结论被新证据推翻时，修正或降级，移除当前成功日期并在正文保留历史验证范围；不能让索引继续宣传已失效结论。

若目标 OPS 采用“仅保存已验证 operation”，保留该模式和既有 schema：候选需求放模型清单，部分执行放私有记录；禁止强行为每个候选生成 operation。生成时应删除不适用的状态说明，保证唯一有效规范。

## 每次任务后的自动写回

1. 对照本次 operation 的成功标准，分清完整成功、部分完成、失败和没有新增事实。
2. 找到唯一归属，合并新增事实、修正旧结论；不追加矛盾段落。
3. 重复成功维护该 operation 和相关索引的真实验证日期；同日且所有内容一致时允许无文件 diff，但仍说明已核对。
4. 不完整执行只记录已观察事实、待核实问题和适用边界，不刷新成功日期。临时登录失效或等待授权不能被写成平台缺陷。
5. 同步受影响的路由、状态和日期；检查路径、引用、字段与私密信息。适用且允许执行的既有校验器可以提供结构检查。
6. 报告实际写回文件和证据范围；若无新知识则说明原因。写入失败或检查未通过时保留明确未完成项，不能声称已沉淀。

保留已有授权，知识维护不引入新的业务动作。不要为了刷新日期擅自重新执行操作，不为了收集经验创建后台任务。用户接管时立即停止受控操作，只整理已经取得的证据。

## 私有信息

`.gitignore` 应覆盖 `experience.local.md`、`*.local.*`、`local/`。实例记录只引用公共知识，保存实际机器、账号、环境映射及证据文件位置；不复制共享事实。

被忽略不等于可以保存秘密。凭据、Cookie、Token、签名 URL、完整业务响应不得进入经验文件。共享事实须脱敏，并且仍足以说明适用条件。
