# 安装与全局触发

生成或配置目标 OPS 的安装提示词时读取。提示词随目标 OPS 分发，安装 Agent 才能在其他机器上发现它。

## 必须生成两个入口

1. 目标 `references/global-agents-prompt.md`：使用[安装模板](../assets/global-agents-prompt.template.md)，填好领域范围、分类名称和 Skill 名。
2. 目标 `SKILL.md` 顶部的安装段落：要求负责安装/配置的 Agent 先读取该提示词，按授权处理；普通使用直接进入操作流程。

仓库有安装索引时补充链接。描述自动发现的范围，但不把 description 命中当作强制前置保证。

## 触发范围要具体

浏览器示例：

> 无论当前使用哪个技能，只要任务涉及通过浏览器进行网页操作，都必须先读取 ego-ops，并遵循对应 site 及 operation；实际控制浏览器前，同时加载并遵循当前浏览器执行 Skill。

Cloudflare 示例：

> 无论当前使用哪个技能，只要任务涉及 Cloudflare 的设计、开发、配置、部署或排障，都必须先读取 cloudflare-ops，并遵循对应 capability 及 operation。

两个前置规则可以同时适用：使用浏览器管理 Cloudflare 时，`ego-ops` 管导航与页面操作经验，`cloudflare-ops` 管平台能力和限额。分别写回自己的唯一归属，不复制两套事实，也不形成相互调用循环；本轮已经读取且仍适用的内容直接复用。

仅写网页代码或讨论浏览器概念时，不应因为出现“浏览器”关键词就强制启动网页操作流程。触发句应对应实际工作。

## 生效与授权

- 全局规则是 Agent 的前置阅读约束；宿主是否加载、何时重载要按实际环境说明。
- 安装 Agent 展示规则全文、真实目标文件和范围，等待明确同意后修改。创建提示词、安装 Skill 和授权全局配置是不同范围；不要重复请求已获得的同范围授权。
- 纯文件复制或链接不会执行交互。没有回答时保持正常安装，提示词仍保留给后续配置。
- 目标目录只读时，选择并报告一个用户可写的唯一经验源；不要创建几套互相漂移的副本。不能写入时提供补丁并报告未保存。
- 跨设备先核对用户指向的设备和当前执行机；历史设备记录不覆盖用户最新说明。

不默默修改当前全局指令，也不为了促使加载而向无关技能批量注入重复规则。
