# 视频字幕拼图

核心产物是**原画面叠加对应原字幕，再将同一观点的片段拼成长图**。参考图决定视觉形式。AI负责选片段、聚合同一观点、找对应画面，不负责重写字幕或增加讲解。

## 必要边界

- 文字来自已选字幕，可摘取原句的连续子串以去掉口语铺垫，原句与摘选须分别保留；不能借此删掉条件或否定、润色、概括或补充作者没说的话。识别错误只允许对照原音频或原画面纠正，并保留原始转写。
- 不添加新标题、段落小标题、解释、总结、金句、彩色信息栏、页码或出处说明栏。原视频自带文字与水印保留；来源和时间放中间文件，默认不印在图片上。
- 选择片段时保留使意思成立的条件和上下文，不因拼图丢失否定词。跳过部分内容须能回查，不把不相干句子拼成作者没表达过的观点。
- 人物表达选择实际说话者画面；图表或操作解释选择当时对应画面，保留坐标、数据与操作信息。图表不套用人物画面的渐隐遮罩。
- 同一观点内可包含多个画面加字幕片段，按原顺序纵向拼接。字幕多时增加长图高度，不改写压缩，不擅自做成知识卡片或课程。

## 执行

先确认输入和保存目录，已有授权直接复用。需要 Node、FFmpeg/ffprobe；URL下载使用yt-dlp。排版使用Python与Pillow；无现成字幕时可用已有本地MLX-Whisper。通过 `--python` 或 `VIDEO_CARDS_PYTHON` 指定实际Python环境，不擅自切换到付费云服务。

```bash
node "$SKILL_DIR/scripts/video-cards.mjs" prepare \
  --input "$VIDEO_INPUT" --out "$OUT" --python "$PYTHON_BIN"
```

已有字幕加 `--transcript /path/to/subtitles.srt`，支持SRT、VTT及带时间戳JSON。素材准备保留视频、音频、原始字幕、统一字幕和最小来源信息；不保存Cookie或完整下载器响应。下载与公开发布分开核对，不自动发布。

通读整期字幕并看对应画面，先判断哪些内容让读者获得具体方法、步骤、判断标准或有依据的知识。每组应能说清读者学到了什么、可以怎样做或判断；一句话表达完整不等于值得成图。单纯感慨、近况和反复表态不单独成图，不能靠增加聊天字幕扩大产出。素材缺少实质内容时应说明并选择更合适的视频。

原作者已有“方法一、方法二”或步骤结构时，优先沿用真实分类，每组保留方法、具体做法或例子与必要解释；不要打散成零散金句，也不编造原片没有的方法或编号。摘选原字幕时保留使观点成立的背景、条件、转折与否定，省略聊天铺垫和重复论述。数量由这些有实质内容的完整组决定，不默认每期三张，也不按时长或平台标题凑固定张数；只有用户明确要求少量样例时才缩小到演示范围。

同一组可以包含多幅对应画面与原字幕，形成完整长图；不要把同一个论点的例子与限制拆散来增加张数。选段依据中简要记录保留、合并与省略的原因，让整期产出数量可解释。内容计划只引用字幕ID与画面时间，格式见[选段计划](references/content-plan.md)。

```bash
node "$SKILL_DIR/scripts/video-cards.mjs" frames --out "$OUT" --plan "$OUT/plan.json"
```

看实际候选图后修改 `frames.json` 的 `selected`。检查发言者、图表状态、转场和遮挡；不要把动画未完成的图表当完整数据。

```bash
node "$SKILL_DIR/scripts/video-cards.mjs" render \
  --out "$OUT" --plan "$OUT/plan.json" --python "$PYTHON_BIN"
```

默认1080像素宽、黑底白字居中、上方原画面和下方字幕；人物画面下沿渐隐，图表画面完整保留。每段只显示原图与原字幕，多段纵向拼接。默认长图上限12000像素；`--max-height`可调整，超长时按完整观点重新选段。中文字体可用 `--font` 指定。

## 验收与交付

打开实际PNG，对照参考图检查；尤其核对文字是否仍是原字幕、有没有额外讲解或装饰信息，以及画面是否对应。程序只保证字幕引用与时间等约束，语义和转写准确性仍须对照原片段。

交付图片本身、绝对路径和未验证项。来源、原字幕、选段、选帧与引用依据保存在同一输出目录，便于回查；网站、部署和平台发布属于独立任务。
