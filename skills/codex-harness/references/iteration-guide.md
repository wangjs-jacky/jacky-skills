# 经验沉淀指南

`experience.local.md` 只记录下次还会值钱的东西，不记流水账。

Codex 自身的安装、运行配置、技能、认证连接与用量经验按 `codex-ops` 的能力及 operation 写回；本文件只维护通用工作习惯和暂未另有归属的历史。自有工程经验优先写对应工程 OPS。同一事实只选择一个当前归属，旧记录可保留历史引用。

## 什么时候写

命中以下任一就写：

- 同类错误第二次出现
- 发现一个稳定有效的做法，后面大概率复用
- 确认了用户的长期偏好
- 确认了某个工作区 / 仓库的固定约定

## 什么时候不要写

以下内容不要进入 `experience.local.md`：

- 一次性的任务背景
- 已经在系统提示或仓库文档里很稳定的通用常识
- 敏感信息、token、账号、隐私数据
- 还没验证的猜测

## 条目分类

建议只用这四类：

1. `F-xxx` 失败模式
2. `P-xxx` 有效模式
3. `U-xxx` 用户偏好
4. `W-xxx` 工作区约定

## 条目模板

```markdown
### F-001 条目标题
- 信号：什么时候说明这个问题又出现了
- 修正：下次应该怎么做
- 适用：在哪些任务里生效
```

```markdown
### P-001 条目标题
- 做法：已经验证有效的执行模式
- 原因：为什么有效
- 适用：下次哪些场景优先复用
```

## 写回规则

- 每条控制在 3 行内
- 优先追加，不大改历史
- 旧条目失效时，直接标注 `已失效` 和替代做法
- 如果某条规则已经稳定到对大多数项目都成立，升级进 `SKILL.md` 或 `references/skill-routing.md`
