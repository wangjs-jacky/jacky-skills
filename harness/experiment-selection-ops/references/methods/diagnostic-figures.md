# 用诊断视图检查，再解释结论

用于均值、通过数或单个终点可能掩盖波动、相反条件和暂态时。目标是决定还需观察哪种结构、检查哪条解释，最后才选择图表与讲解。少量确定值/离散状态可直接用表，不要求做图。本条细化[报告指南](reporting.md)，不复制其证据契约、图面QA或真人反馈规则。

## 原文与增量

Scholar固定Figure Catalog把主比较设为“Bar + scatter overlay of seed-level points”，追问“Is the adapter improvement consistent across seeds?”；动态例要求区分“Is instability transient or persistent?”。Common Pitfalls明确列出“Hiding instability behind a mean value”和“Mixing seed-level and subject-level units”。选段、文件/行段/commit/SHA见[示例图目录](../sources/excerpts/scholar-figure-catalog.txt)、[分析陷阱](../sources/excerpts/scholar-analysis-pitfalls.txt)及[来源catalog](../sources/catalog.json)。

原意是在真实数据图与解释中保留个体、时间和证据单位，避免只报最佳结果或均值。原图目录是作者的说明例，不是本项目做过的训练实验。本项目将它推导为“主张 → 数据结构 → 诊断视图 → 反例 → 条件决定”的操作顺序；配对点、条件分面和缺失表是工程适配，不冒称上游逐字规定。已有报告指南已经要求解释图的目的/观察/意义，本条不把这三句话重新算成新方法。

## 如何应用

1. **写图要检查的主张。** 例如是典型收益、稳定性、条件改变还是过程暂态。先说明什么形态会削弱该主张；不知道图会改变哪项判断就先不用图。若问题仍含混，引用[从选题到比较](question-to-contrast.md)整理预测。
2. **先核数据结构，再挑载体。** 保留实际独立单位ID、配对/区组、条件、时间/事件、有效/缺失及原件定位；不得把同一页面的九张图当九次独立生成。每个绘制点/表格项应能回到真正支持它的记录及聚合规则。

   | 要检查的结构 | 可选择的诊断视图 | 需要保留的限制 |
   | --- | --- | --- |
   | 多个可比单位的波动是否被均值遮蔽 | 原始单位点配合汇总；适合时用分布图 | 点数、独立单位、技术重复与区间含义分开；只报最好一次不够 |
   | 配对/区组中差异方向是否一致 | 同单位连线、配对差值或明细表 | 保留整对/区组身份；漏一端不能补成完整对 |
   | 不同工作负载是否给出相反建议 | 同量纲的分条件表或分面图 | 无实际分布权重时不只给加权总分；条件交互见[变量设计](blocking-and-interactions.md) |
   | 过程异常是暂态还是持续 | 有真实时间/事件顺序的轨迹或状态序列 | 不把稀疏截图连成未观察的运动；观察时刻与精确采集时刻分开 |
   | 确定字节、有限通过/失败/未测 | 精确表、状态矩阵与必要案例 | 不给确定值伪造误差条，不把unknown置零或当失败 |

3. **在分析中保留反例。** 同时核原始单位与汇总，条件与汇总、过程与最终端点是否一致；发现反向条件、尾部失败或缺失集中时，回到相应记录核实。图只让问题可见，不自动证明差异显著、等效或某种机制；不因图不支持结论就删点、改分组或换指标。新增分析要标探索及实际原因。
4. **决定是否需要补证据。** 分开“已有数据足以复算/重画”与“需要新增采集”。前者可在原授权下修正派生；后者须看当前范围与预算，未获授权或到限则保留缺口，不因图好看就追加实验。已有数据不足时，示意图只能标示意，不替实测图。
5. **讲清观察为何影响选择。** 用具体记录说明看到的形态，引用支持解释的证据及替代解释，指出约束，再给条件建议或下一步缺失证据。图注负责单位、n、变换/平滑、区间/缺失等独立可读信息；正文解释观察如何支持/削弱实际决定。图面渲染与数据复算分别按[报告指南](reporting.md)核对，AI描述不代替真人理解。

## 应用例与反例

未运行的设计示意：若比较计划担心冷/热条件下的排序改变，就先准备保留条件的对比表/视图。若未来观测出现相反方向，应报告各条件及用户实际使用前提，不能只给一个总体均值。这是可能结果的解释路线，没有虚构本项目已取得这样的数据。

反例：只有两个最终均值的图，却声称“运行很稳定”；一张暂态截图后直接断言“最终文字被裁切”；用不同单位/缺失策略的柱子强行评出总分。补充标题或配色都不能弥补其数据结构与论证缺口。

## 可观察产物与局限

在已有分析/报告里保留主张、相应数据结构与聚合、诊断观察、反例/未测和决定之间的关系；需要图时，实际图及其数据入口才是产物。方法清单齐全不代表已制图、已观看、已复算或真人已看懂。没有重复就不能检查跨运行稳定性，没有时间序列就不能检查持续性；相依数据也不能从点多推独立证据多。
