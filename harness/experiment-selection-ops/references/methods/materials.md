# 从文章、视频/转录与案例提炼方法

用于资料输入，不自动启动新的业务实验。媒体格式不是分类主键；提炼出的任务特定方法归对应 operation，跨类型方法归本目录相应正文。来源身份归 sources，解释不另复制多份。

## 获取与定位

先确认读得到的实际材料、许可/授权和版本。文章保留作者、标题、发布日期/查询日期、URL与节/段定位；视频记录作者、标题、URL/版本、时间码范围、字幕/转录来源和与画面的核对范围；案例记录成品/代码版本、输入、运行条件及观察位置。只有转录时，不能推断镜头/视觉/动效已看过；只有截图时，不能推断连续交互成功。

按宿主搜索、媒体与网页工具规则获取内容。材料缺失或无法读取时写明可见范围与待补证据，不根据标题/二手转述臆造原文。保存许可允许的原文片段/转录及哈希；禁止分发的素材只留合规定位与解释，披露接手者不能离线核对的缺口。

## 不只提炼好看的呈现

对实际有内容的维度逐项读材料，没有就写“来源未说明”而不编造：

| 提炼维度 | 要从来源找到什么 |
| --- | --- |
| 选题/选择 | 为什么值得比较、决策对象/候选如何形成、适用读者/用途 |
| 比较过程 | 先做什么、比较单位、共同输入/对照/反例、步骤与记录如何衔接 |
| 条件与变量 | 固定/变化/混杂因素、工作负载、采样/必要重复与停止条件 |
| 测试办法 | 预期来自何处、真实性/负控、失败边界、运行证据与缺失如何处理 |
| 计算与论证 | 指标实际含义/单位/分母、计算与不确定性、哪些证据能支持何种主张 |
| 呈现 | 问题到建议如何组织、图/表/可播放案例承担什么解释；哪些关键过程被保留 |
| 条件与反例 | 方法何时适用/不适用、来源承认的局限、哪些迁移是本 Agent 推导而非原作者主张 |

每条只保留可改变下次设计/报告的要点。把“作者原文/直接观察”“Agent解释”“迁移建议”分别标明。论文被某Skill引用不等于本轮重读/认证论文；来源作者的成功案例也不是本 Skill 的实测。

## 一个可检索的来源条目

来源记录至少含：稳定 `source_id`、作者/标题/媒体类型、原URL与日期、版本/commit/段落/时间码、保存片段及SHA（或不能保存原因）、许可/署名、所提炼主张和原文/推导区分、适用与不适用、未覆盖、**唯一知识归属路径**。例如某视频的比较方法可以归函数/库 operation，正文排版方法归reporting；来源同一条目可列各主张的不同归属，不复制同一方法正文。

现有来源与格式见[来源索引](../sources/index.md)及其catalog；新来源可以按规模维护目录/独立条目，不要求追加到一个无限长JSON。类型/operation索引提供中文名、别名、目标与来源入口，使下一次按问题能检索到方法，而不是只能按作者名找到附件。

## 合并、冲突与证据级别

先查已有归属；相同规则合并并补来源，冲突则列条件、优先直接证据，不追加互相矛盾的通用命令。没有真实运行只能documented。局部使用可partial，完整验证只对该条明确成功标准及所测条件有效，不能把来源资料整体升为verified。

按[知识协议](../knowledge-schema.md)更新唯一正文及相关索引、校核链接/隐私/许可，报告实际写回路径与证据范围。资料提炼结束、获取失败或中断都要作写回判断；未读取/无可复用内容就说明原因。写入失败提供补丁，不静默另建当前库；资料可能建议的实验/部署不扩大本轮授权。

本指南最初来自用户需求、OPS规则和[已有来源](../sources/index.md)的证据原则。09随后实际读取01已保存公开原文，新增三项documented方法并核对入库/索引；这是文档与结构证据，不是这些方法的业务复用、表达效果或跨场景迁移通过。
