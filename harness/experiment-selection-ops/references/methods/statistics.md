# 按估计对象选择统计方法

仅在本题涉及数字汇总、连续测量或推断时读取。核心是先确定“估计什么、单位是什么、哪些记录相依”，再选方法。本指南不是统一统计检验规范。

## 什么可以只描述

单份构建的字节、固定手选案例的通过/失败、每方法一份页面、某视口的尺寸，可直接给精确值、范围与覆盖。单次确定量不需要显著性或误差条。有限手选案例不支持总体准确率CI；同一页面的视口、按钮、截图不是独立生成；同一输入的循环调用/技术重复不能自动当独立样本。

连续测量先写目标效应（例如每次调用差多少微秒、典型配对时间比、给定条件下更快的概率）、独立单位、配对/嵌套/区组、采样来源及多比较范围。fresh process只说明进程分离，不能认证共享宿主/时间独立。必要时仅作探索性描述并陈述残余依赖。

## 数字要有可复算定义

| 量 | 定义与解释 |
| --- | --- |
| 均值/中位数及离散 | 标明每组有效n、单位、缺失；SD、极值范围、分位或区间分别命名，不能把min–max当CI |
| 配对绝对时间差 | 同一对`d_i=t_Ai-t_Bi`，正值表示该端点B用时少；汇总方法和单位明确 |
| 配对几何时间比 | 正时间下`G=exp(mean(log(t_Ai/t_Bi)))`；G>1表示配对乘法尺度上B较省时，**不是**两个算术均值相除 |
| 百分比 | 给基准与公式；几何时间比下B相对A用时降幅`1-1/G`，若相同工作量吞吐与时间成反比，吞吐比增益`G-1`。两者不能都简称“快X%” |
| 体积差 | 给原始byte或明确`KiB=byte/1024`，相对变化`(B-A)/A`以A为基准；gzip注明实现/版本/参数 |
| 批次与单次 | `ms/N次`不是`ms/次`。每次微秒差×业务调用次数，再除1000才是总毫秒差；附真实/假定调用量及其来源 |
| 诊断计数 | 配置数、原生issue数、包装后路径数/去重规则各自列分母；不能混轴或把四路径叫四配置 |

比值输入为0/负值时先核测量定义与分辨率，不能默默加常数。报告有符号方向、绝对收益与具体使用规模；微秒差有统计证据也不自动改变生产选择。

## 什么时候推断/功效有意义

主张要越过所观察案例，且采样/设计及假设可支持目标效应时，按实际问题选估计、区间/检验与敏感性分析。配对数据重采样按完整对/独立单位，不拆行造n；层级/时间依赖需相应模型或限制结论。比较多个端点/候选时说明预先的比较族与适用的多比较处理，不对没有该推断目的的计数强套校正。

计划样本量或功效要有目标效应/最小有意义差异、设计、变异/依赖假设及错误率/功效要求，给假设依据与敏感性。预算只够单例时承认范围，固定n≥3/12/31不证明充分。没有可信前提不做假精确功效；观测功效不能把非显著变成无效应证明。

诊断图/统计量用于检查特定假设，不能认证设计正确；不按正态诊断p值自动切换问题/检验。计划偏离及探索性分析给理由，不为显著性筛输入、换指标或删异常。范围交叠只描述已观察范围，不能证明无差异/等效；小p也不能证明实用价值或跨环境保证。等效主张需事前有意义界值和相应设计。

## 可重复性与报告范围

保留原始值、单位/缺失、公式/脚本、依赖版本、随机种子及运行结果。关键数字独立复算或核对数据到表/图映射；只读过脚本不等于执行通过。bootstrap方法相同但不同RNG得到相近区间，只能称交叉检查，不能称逐位复现；未重算的诊断值明确未验证。

统计叙述要对应真实估计对象：方向符号检验检验的是方向概率，不是均值相等。区间说明覆盖目标/假设/方法。预设阈值、业务判断和统计结果分开；不能把范围规则改称显著性检验。建议仍须满足部署方式、产品语义与真实使用条件，见[报告](reporting.md)。
