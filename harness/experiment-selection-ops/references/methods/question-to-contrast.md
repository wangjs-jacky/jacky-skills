# 从选题到能区分解释的比较

用于“哪个更好”尚未对应实际决定，或某个差异有多种解释时。它细化[事前计划](design-and-execution.md)中的问题与案例区分力，不另建运行闭环。只有查API、制作单件或已经有明确确定性契约时，可直接查资料或检查契约，不必强加机制假设。

## 原文与本项目的增量

固定K-Dense原文要求“Which rival predicts a different observable pattern?”，并保留“indeterminate outcome”；设计链是“candidate → mechanism → prediction → observable → operationalization → design → analysis → interpretation”。Scholar问题卡要求写“What would support it”“What would falsify it”“Minimal next action”。必要原句、节名、行段、commit及原文SHA见[kd-hypothesis-quality](../sources/excerpts/kd-hypothesis-quality.txt)、[kd-discriminating-tests](../sources/excerpts/kd-discriminating-tests.txt)、[scholar-question-card](../sources/excerpts/scholar-question-card.txt)及[来源catalog](../sources/catalog.json)。

原意是让研究问题、前瞻预测和区分替代解释的设计相连。本项目将它改编为工程选型的分支判断与最小测试；不把候选库等同科学假说，不继承医学审批、人类评审状态或统一质量分。旧指南已有“为何值得测、案例区分力”，本条补足怎样找到有区分力的对照与何时停止试验。

## 如何应用

1. **先写决定及其前提。** 选题写成“谁在什么场景、版本与约束下，要决定采用/保留/暂缓什么”。标为探索、验证既有预测或应用比较；候选进入比较的理由来自实际约束与可取得证据。若产品含义未定，先列条件分支，不能用实验替用户确认价值取舍。
2. **列可能改变决定的解释。** 对想验证的差异列一个有实际依据的替代解释，例如观察来自候选能力，还是来自适配层、输入政策或测量方式。没有合理的机制问题时不编造一组假说；检查两候选是否满足契约即可。
3. **让解释作出不同预测。** 对每个需要区分的分支，写条件、可观察量及其单位、各解释预期出现的模式，以及什么结果两者都解释不了。幅度未知时用有依据的方向或边界，不虚造预期提升百分比。若所有可能结果都能被同一解释事后吸收，或差异低于可取得精度，当前设计不能判别。
4. **从分歧选择最小测试。** 优先选各解释预测不同、且与实际使用有关的输入/状态；保存外部预期与来源。需要隔离适配层时，分别观察原生与适配后结果；需要区别测量失败与产品失败时，沿现有[正式准入控制](design-and-execution.md)取证。固定、变化与区组安排见[变量设计](blocking-and-interactions.md)，不为区分解释另起一套guard。
5. **事前写下分支出口。** 可以是支持某个条件选择、削弱当前解释、两者均不支持，或测量/预算不足而无定论。缺少的关键前提先通过允许的资料核对或最小可行性检查解决；本轮不能取得就缩小主张或停止该分支，不能以继续试到赢为出口。
6. **按原预测解释结果。** 执行后对照预测与实际偏离，不只呈现最顺眼的解释。事后发现的新解释作为探索记录及未来测试建议；不将已看结果反写为事前预测。方法、计时、原件和写回仍沿用共用指南。

## 应用例与反例

以下是未运行的设计示意：问题从“哪个包小”改为“本次分发方式下，包的选择是否值得以用户等待时间作决定”。一种解释是传输体积影响等待，另一种解释是等待主要受共同初始化路径影响。单份bundle字节只能回答大小；若获授权并有真实分发条件，需在明确的加载/初始化端点上设计能区分两者的对照。若没有分发方式与调用量前提，保留体积事实和条件问题即可，不虚构性能测试或默认必须测速。

反例：看见A一次更快后才声称“模块化造成提速”，随后只挑A占优的输入；或者让两个适配器共用同一补偿逻辑，再据包装后相同断言原生等价。两者都没有让替代解释产生可检查的分歧。

## 可观察产物与局限

在已有计划中留下“决定/前提 → 解释与预测 → 区分输入与观察 → 分支出口”的短链即可。能回查预测依据、无定论出口和实际偏离，才说明设计被具体化；纸面链完整不证明测量有效、机制因果或选型更好。小样本、同题熟悉、共享宿主、不可逆学习/缓存或缺少关键条件都可能使解释不可分。交叉/配对不是自动消除这些影响的办法。
