# 报告：让选择沿证据成立

报告回答一个实际选择。借鉴学术写作的清晰论证，而不是固定十节、字数、图数或通用总分。小实验可以一份报告，复杂问题可附分析和原始证据；必要的中间过程不能因短摘要被删掉。

## 推荐的阅读顺序

可以使用[可裁剪报告模板](../../assets/decision-report.template.md)。按本题合并章节，但逻辑应可复述为：**问题与候选 → 调研/设计理由 → 真实执行/异常 → 结果与计算 → 解释 → 条件建议 → 局限、改进和后续问题**。

开头先说本次能决定什么、建议及关键前提/未决。随后说明哪些资料、设计和执行产生了证据，为何选择这些案例/变量/判断方式，实际有什么变化、失败和缺失，哪些证据改变了判断。原始日志另附，正文保留能让读者复述关键过程的步骤与精确入口。

## 每个核心建议的证据契约

用短段落或表记录下列内容；不是给全文强加统一评分：

| 字段 | 要填的实际内容 |
| --- | --- |
| 主张/建议 | 对什么输入与用途采用、暂缓、排除或无定论 |
| 直接证据 | 精确文件/记录/图/案例及版本、所测条件和定位；不是只引“见日志” |
| 解释 | 证据如何支持主张；计算/中间推导、权衡，事实与机制假设分别写 |
| 适用条件 | 产品语义、部署/分发方式、工具环境、输入分布或读者任务等真正需要的前提 |
| 不确定与更强措辞 | 当前尚缺什么，哪些外推不被允许，发现核心错误时撤回/弱化哪条链 |
| 决定与下一步 | 保留/弱化/修订/撤回；最小缺失证据与改进方向，是否在当前授权范围 |

正确数字不能代答部署前提。单个bundle较小不能推出生产启动更快；局部微基准不能决定全项目；metafile/模块化描述不是隔离机制的因果证明。一份页面失败不能推出整个设计Skill差，诚实报告失败也不意味着实验框架差。证据足够的局部事实可保留，核心错误只封锁依赖它的采用链。

主要数字错误、原始来源不可追、误导图或无依据前提，会阻断相应建议，不能由美观、篇幅、过关数或多票抵消。问题无法消解就保留争议/条件，不强制赢家。

## 指标第一次出现时就解释

给通俗含义、测量对象、单位、分母/独立n与记录数、方向、基准、采集来源和比较条件。计算放能定位的位置，不要求读者翻英文附录才知道主表比的是什么。术语首用解释，例如client宽是页面内容区宽，不等于请求的viewport；issue条目数不等于路径数。

结果分开写：已观察事实、计划/假设、推导、未运行/缺失和未知。内容存在、动作成功、视觉偏好、读者理解、模拟/真实生产分别命名。检查未执行不能填通过，某个检查通过也不替其他检查。

## 选择合适载体并实际检查

| 本题要表达什么 | 常用载体与检查 |
| --- | --- |
| 少量精确数值、条件或离散状态 | 表/文字；状态矩阵保留unknown/skip，明确对象和实际检查范围 |
| 规模/分布/配对差异/趋势 | 有助决策才画图，保持数据/脚本、单位、轴、刻度与区间含义可核对 |
| 页面/交互事实 | 直链实际最终案例及必要视口/状态截图、动作读回或录屏；截图不能替代未拍的状态 |
| 时间运动与连续过程 | 可播放案例及时间码、播放条件、必要关键帧；静帧不能证明整段运动 |
| 函数/库接入 | 版本命令、可运行示例、输入输出、覆盖表和边界；mock不当真实builder |

主图必须解释：**为何需要它；具体看什么；观察怎样改变决定**。没有决策/解释作用可以不用图。生成图就实际渲染观看，记录精确文件/版本与观看范围；读SVG或文件存在不等于看过图。实际看图与数据复算分别记录。没有观看能力则标未验证，不伪造视觉QA。

检查图表与唯一源数据、正文、标签一致：计量对象不混轴；状态不当连续分数；截断轴/对数轴注明；误差线命名为实际SD/CI/极值等；确定字节不伪造误差条。若图叫viewport而数据是client/scroll，修改标题/标签；数字正确仍可能图面误导。

截图/录屏按候选中性编号、最终版本、视口、状态/时间码精确链接，避免“initial.png见目录”让接手者猜。中性评看入口与候选身份映射隔离，核入口能打开的是最终版。隐去包装并不能保证正文/文件名不泄露身份，盲法局限如实说明。

## 读者与独立评审

AI可做逻辑/可读性预检，但不能替真人作选择或声称用户已懂。真实读者先只看交付，不补讲、不看身份/预期答案，按需询问：要解决什么选择与建议；关键证据/图表及怎样得到；条件与未知。保存原话、卡点/对应段落，补讲另记；未参加就保留“用户理解/盲选未验证”。

有授权的多Agent独立初判各自先冻结，再核事实/推断/呈现差异；同模型多意见可能共享偏差，不构成统计独立。事实分歧回查来源、运行和计算；无法消解时报告争议，不能多数票放行关键错误。作者自查不冒充独立验收。

## 交付前读回

检查主要建议能沿链接回到证据、核心数字/方向/分母、最终版案例与图面，失败/偏离/局限及未来改进没有消失。精确区分“满足/不满足/不适用（理由）/未验证”，这些判定针对对象和范围，无全能总分。

给出可复现入口与所需环境、实际执行范围及遗留项，按[知识协议](../knowledge-schema.md)完成写回并报告位置/失败原因。报告写清建议，但不把后续缺失证据的建议自动变成新增实验、部署或发布授权。
