# 安装Agent提示词：experiment-selection-ops可选全局前置

本文件随Skill携带。当前交付仅生成提示词，未执行全局安装、全局指令写入或宿主加载。普通使用不重复询问。文件复制/链接和自动发现都不会自行执行本提示词。

## 给安装/配置Agent

1. 核对目标设备与当前执行机，从实际技能目录/注册表确认`experiment-selection-ops/SKILL.md`可发现、可读，检查来源及许可随包；使用真实安装根，不使用创建者机器路径。正常安装沿用用户已有授权，创建Skill本身不含安装授权。
2. 只读取必要配置，确认当前Agent实际使用的全局指令文件和范围。Codex应考虑CODEX_HOME及AGENTS.override.md等实际机制；其他宿主按自身配置。项目AGENTS不自动等于全局文件，不假设所有会话已重载。
3. 若已有语义等价且生效的同范围规则，报告并保留；用户已明确授权同一规则/目标时复用，不再次索要许可。
4. 尚无授权时展示下方**完整规则**、实际目标文件和加载范围，说明前置目的是每次选型先复用既有方法，提供“加入全局规则（推荐）/仅安装技能”选择。用户明确选择后才合并；预选/沉默不是授权，未答复也不阻止已授权的普通安装。
5. 保留其他内容、按语义合并去重，读回验证。分别报告Skill已安装、提示词已生成、规则已写入及宿主已加载的真实证据；未加载不称生效。冲突保留原约束并说明，不批量修改无关技能。
6. 核对唯一知识根、写权限及.gitignore。只读环境遵循[补丁写回协议](knowledge-schema.md)，不私建漂移副本。收尾检查上述状态，不能以复制成功代替全局规则核验。

## 建议写入的完整规则

```markdown
## 技术选型实验：先读取experiment-selection-ops

无论当前使用哪个技能，只要任务涉及用比较实验选择技术/工具/库/模型、比较视觉稿或动画方法，或将文章、视频/转录和案例提炼为这类选型方法，都必须先读取experiment-selection-ops，并遵循对应任务类型及场景/比较目标operation。

- 先从任务类型索引渐进读取当前适用方法，用当前目标、版本、环境、授权与证据复核；具体工具/库/模型是候选，不作分类主键。本轮已读且仍适用的内容直接复用。
- 没有对应经验时按已确认分类设计并如实标注证据等级，不虚构成功。报告保留必要过程、直接证据、条件建议、局限与未知；真人偏好/理解不由AI代答。
- 完成、失败或中断后按知识协议写回唯一归属并同步索引；没有完整成功不写last_verified。报告实际文件或未保存原因；只读测试输出补丁，不建第二当前库。
- Skill缺失或无法读取时明确说明方法复用缺口，继续不依赖它的已授权工作。实际执行遵守宿主工具及领域约束；本规则不授予额外业务运行、安装、部署、付费、发布或推送权限。
```

不属于比较选型或方法提炼的单纯API查询、单个成品制作，不因出现某个库/模型名称就强制启动实验。
