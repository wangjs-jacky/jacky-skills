# 比较同一文档首页的设计方法

目标：在给定内容、交付和使用条件下比较若干设计方法，留下可打开案例和有依据的条件建议。本 operation 的成功目标是比较与可移交证据，不保证生成页面无缺陷或选出赢家。

## 适用与不适用

适用：相同文档首页 brief 的信息/交互/交付取舍。先有内容、候选及可用生成/页面工具、授权和预算。单例可以比较本次成品，不能据此决定方法长期质量。若只需制作一页，直接使用制作工具，不启动比较。若只给截图，只能做其可观察范围的静态比较。

按需细化：[区分替代解释的比较](../../../methods/question-to-contrast.md)、[区组与条件交互](../../../methods/blocking-and-interactions.md)、[诊断视图与论证](../../../methods/diagnostic-figures.md)。共享步骤只在这些正文维护，本operation保存场景应用与证据。

## 运行方法

按[共用设计与执行](../../../methods/design-and-execution.md)留下事前计划，并具体化以下内容：

1. **固定共同输入**：保存 brief、给定文案/代码/命令与许可资产的版本/哈希。列出必须保真的内容、必要动作与最终交付方式；字体/图片/外部资产、工具、内层生成预算和允许迭代应可比，无法对齐的差异明确为混杂。
2. **用任务检验差异**：按实际目标选案例，例如找到安装命令、搜索指定组件与无结果状态、打开/关闭某个预览、提交表单后的反馈。任务名写“安装命令可见”“所测Dialog打开”，只有观察到相应关闭/焦点读回才扩大主张，不用“理解完成”或“所有预览通过”代替。
3. **先核仪器**：确认真正在打开目标最终版、内容非空、尺寸合理且目标元素可见。新自动检查器按共用指南做正常/错误控制；空白/0×0等仪器拒收不计作成功测量。正常页面的产品动作失败是有效负结果，保留失败图、读回及必要源码定位，不删除成“无效样本”。
4. **真实操作与证据**：运行/打开页面，记录每项动作的实际状态、所测视口和命中的版本。需要关闭/键盘/焦点/复制时各留对应动作证据；没运行的项写unknown/skip及原因。截图名、报告链接和记录标识明确页面编号、终版哈希、视口、状态；必要时用录屏补连续过程。
5. **最终版对齐**：内容或样式变更保存新版本和差异，只复查受影响路径并说明其他路径沿用何版证据。事后重建的before明确标注，不能冒充事前快照。生成中的内部修订不算新独立产物。
6. **中性评看**：建立编号“案例01/案例02”的可打开入口或相对目录索引，入口直达最终成品及必要播放/启动说明。候选身份、顺序生成依据和编号→身份映射留在任务的隔离证据中，不混入盲选页；检查标题/资源文件名等泄露并披露盲法局限。事实报告可说明候选，供真人初看使用的入口保持中性。
7. **按条件建议**：如本次确实要求单文件，核实际本地引用闭包、文件/字节及缺失资源后再讨论交接；源码字节不代表加载速度。按[报告指南](../../../methods/reporting.md)区分内容、动作、偏好与理解，保留失败/unknown和取舍。

## 成功标准与检查范围

- 共同输入、候选/条件与事前判断方式可定位，实际差异/偏离已说明。
- 每候选有可重开的最终案例；所声明视口/状态证据对应版本，任务结果逐项可核查。缺候选或动作失败可得出有限/无定论报告，不得填成通过。
- 中性入口及隔离映射实际存在并检查链接；不能仅写“以后提供”。真人未使用时标“视觉盲选/用户理解未验证”。
- 主要建议直连证据及前提；一页故障不升级为生成框架普遍较差，多视口不增加独立n。没有共同质量量表不跨任务比较过关数。
- 运行结束、失败或中断按[知识协议](../../../knowledge-schema.md)写回判断与索引。真实用户可用性/偏好若未取得，不属自动可声称成功的范围。

## 失败恢复与初始证据边界

同名ID/选错元素可造成“源码有Dialog而点击失败”；先保存实际目标类型、状态与异常，再检查源码，修正后另存版本。若静态文本提取因高亮span断开字符串，应按真实文本语义检查，不能把格式差异误判内容缺失。这些是旧原版案例观察，非新Skill保证的已验证恢复方法。

来源：2026-10-17本项目04/05冻结观察（V1/V2）及06的X3/X6/X8/X10，详见[来源说明](../../../sources/index.md)。原版揭示关闭/焦点缺证、任务标签过宽、最终视口命名和交接定位问题。它们支持上述设计指导；初始快照尚未在新 Skill 下执行；本次局部执行证据见下节，仍无完整成功验证日期。原始证据仅在持有者的私有映射可定位，本包不冒称携带旧网页证据。
