# 函数/库

比较明确语义下的可运行接入、失败边界及适合实际工作负载的成本。原生库能力、适配器和共同业务策略分别说明，不能因包装后相同就说两库原生等价。

- [比较CSV导入解析接入](operations/compare-csv-import.md)：字段保真、错误定位/恢复、实际流API及规模条件。
- 其他函数/库先用[设计与执行](../../methods/design-and-execution.md)确定目标；涉及连续测量才读[统计方法](../../methods/statistics.md)。

## 跨场景条件

可运行用法须给版本/lock、安装与运行命令、最小调用和实际输入输出。只保存bundle重放、typecheck、干净安装、真实构建、mock交接分别是不同覆盖范围。声明API能力的精确来源需随证据移交，不能只链接作者机器的依赖目录。

计数分开：fixture记录条数、按说明等价规则去重的输入种数、候选检查次数、诊断issue数、受影响路径数、独立测量单位和技术重复。数组顺序等语义保留；JSON内容去重不证明统计独立，也不能未经定义推广到含函数/引用/undefined的对象。

成本端点应服务真实分发方式和输入分布。单份构建字节、同进程warm调用、fresh-process启动代理各有边界；没有真实工作负载前提，采用建议保持条件。源码行数不是维护工时，错误路径更多也不等于真人更易理解。
