# 任务类型索引

先按要作的决定选类型，只读命中的档案和 operation。工具/库/模型是候选，不是分类。可信度与日期只在知识正文维护，索引不另存一套状态。

| 要比较的结果 | 类型与使用入口 |
| --- | --- |
| 页面信息表达、视觉与交互成品 | [视觉稿](visual-design/index.md) → 文档首页比较 |
| 函数/库在明确语义和工作负载下的接入 | [函数/库](function-library/index.md) → Node配置校验比较 |
| 随时间展开的动画或动效 | [动画](animation/index.md) → 播放、采样与条件指导；未实跑，不虚构场景 operation |

已有文章/视频/案例要提炼为方法时，按其目标类型路由；跨类型共用方法归[资料提炼](../methods/materials.md)，不把媒体格式当新主键。新目标没有现成 operation 时用[设计与执行](../methods/design-and-execution.md)，并按[分类模型](../ops-model.md)建立有内容的唯一归属。

## 按比较中的问题找共享方法

选题/替代解释、区组/条件交互、均值/暂态掩盖问题，从[共享方法检索](../methods/index.md)定位唯一正文。类型与operation仍是场景入口，不按作者、工具或资料格式另建知识分类。
