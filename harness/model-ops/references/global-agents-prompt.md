# 安装与可选全局前置

安装 Agent 先核对目标设备、当前宿主、CODEX_HOME、override 与真实全局文件。已有等价规则无需重复写入；已有相同内容和范围的明确授权可直接复用。

没有授权时展示以下规则全文、实际目标文件与生效范围，请用户选择启用或只安装。等待明确答复，预选和沉默不代表授权。只安装不阻塞 Skill 正常使用，也不写全局文件。

同意后保存可恢复材料、保留其他内容与文件身份、按语义去重并读回。分别报告规则已生成、已写入与宿主已加载；其他运行会话不会因此自动获得已验证状态。

## 建议规则

```markdown
## 模型与推理服务：先读取 model-ops

无论当前使用哪个技能，只要任务涉及本地模型或推理服务的部署、检查、调用、升级、排障，或语音模型的转写、合成与音色设计，都必须先读取 model-ops，并按 model → operation 渐进读取。

- 复核已有部署、运行环境、模型版本和当前可用性，复用原生工具或已有服务。
- 参考声音、版本、角色绑定与试听继续由 voice-material-ops 管理；密钥取用继续遵循 account-pool-ops。
- 完成、失败或中断后按真实证据维护唯一经验源和索引；不虚构成功、不扩大原授权。
```

本规则依赖 Agent 遵循指令，不是后台服务或工具强制钩子。普通业务跳过安装交互，按模型与操作处理，并遵循原工具和声音素材的授权边界。
