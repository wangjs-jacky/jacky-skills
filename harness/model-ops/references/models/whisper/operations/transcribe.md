# 转写

输入为已有音频／视频。依据当前请求和明确的个人选择传入型号与格式；无需登记内容场景。txt 为纯文字，md 保留阅读时间轴，srt／vtt 用于播放器字幕。

```bash
bash scripts/run.sh whisper audio.m4a -m large-v3 -f md --dry-run
bash scripts/run.sh whisper audio.m4a -m large-v3 -f md
bash scripts/run.sh whisper ./audio --batch -m large-v3-turbo -f srt
```

模型和格式必填，语言省略时自动检测，输出默认在输入旁；`-o` 指定目录。此工具没有交互菜单或个人偏好写入，参数临时覆盖不会改长期选择。dry-run 不读媒体、不加载模型。

完整输入按本实现转换为 16kHz 单声道 WAV；这个要求不推广到其他模型。批量串行处理、汇总失败且返回非零。只写所选格式，空识别或无效时间轴不生成成功产物。外部分片时合并需加回原片偏移。

核对原片时长覆盖、时间顺序和内容样本；结构通过不能证明全文正确。同模型局部重识别可辅助定位漏字或幻觉，结果仍按原片坐标保留。报告实际参数、输出与检查范围，失败不切换引擎或上传素材。

当前适配器返回的 `duration` 是最后识别段的结束时刻，并非独立测得的原片时长。使用 ffprobe 核对输入；字幕不必覆盖末尾静音，不能仅凭二者差值判定漏转。

工具沿用原转写实现的 Python／MLX 生态；推理、格式化和运行选择分别可测。具体本机真实验证记录与证据按私有索引读取，不将迁移日期替换历史验证日期。

2026-11-25 验证范围：Apple Silicon / MLX、本地已缓存的 large-v3 与 large-v3-turbo、显式 zh / srt、HF 离线模式；同一段官方公开中文短样音均产生非空、顺序与边界有效的 SRT，文本抽查与项目演示文字一致。仅覆盖短句及字幕导出，不证明长录音、噪声、方言、说话人分离或抖音媒体获取成功。

2026-11-25 后续补充：同一公开视频的约16分钟中文教程音轨，large-v3-turbo / zh / md 在离线模式完成整段推理；多个原生字幕片段与转写可按上下文对应。英文专名有误识别，结尾出现重复文字及少量超出源时长的时间标记；原始结果保留，回答不采用可疑结尾，不将单条成功外推为逐字正确或所有长音频均有效。完整字幕文件是否能从平台导出属于媒体读取环节，不由ASR成功证明。


剪辑切句不要直接把整段SRT边界当作词间边界。MLX-Whisper原生word_timestamps可提供词级对齐；修剪后应重新核对主要词句，防止将相邻词末字切到下一句。此能力不等于强制对齐或完整听校，工具CLI未暴露该选项时可在同一已验证本地模型环境使用原生调用。

2026-11-26：缓存 large-v3-turbo / zh / srt 对约297秒构建完成的教程旁白完成推理，实际稿件覆盖至末句；末尾静音产生一段无依据的订阅口号，且结束时标超出输入。保留原始转写，将该段排除质量依据；正式字幕仍沿核对原稿，不把这种回转录当逐字人工听校或自动替换字幕。应在音频写入完成后再开始转写，避免读到尚未完成的输入。
