# Suno

用于从文字提示或真实音频参考生成音乐、纯器乐与重编变体。模型家族为 `suno`；供应商、路由名、版本、费用和账号分组是调用条件，不为每个供应商复制一个家族。

先按创作目标选路：**相近风格但重新写旋律、即兴新作**进入文字生成；只保留风格描述，不传原音轨、旧任务或旋律来源。**翻奏、重编、保留原曲再变化**才进入音轨参考 Cover。用户提供参考音乐不等于希望沿用原旋律，听感评价“好听”也不代表认可旋律已重新创作。

当前已验证条件：经 BBLABU 的 `su2-suno-v6-mini` 文字路由完成一次纯器乐生成；经 `suno-cover-audio` 音频参考路由完成一次真实原音轨输入，返回两轨。两条路径的音频下载、完整解码与试听附件交付均成功。路由名与产物元数据不能独立证明上游底层模型版本；单次技术成功不等于所有路由可用或用户已认可听感。

- [generate-instrumental：生成纯器乐并保存音频](operations/generate-instrumental.md)。
- [generate-from-audio：使用真实音轨作为生成参考](operations/generate-from-audio.md)。用户已经给出作品时先核对该入口；外部音频理解模型不是必经步骤。
