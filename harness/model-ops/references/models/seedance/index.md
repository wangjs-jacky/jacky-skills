# Seedance

BBLABU 当前提供多个 `sd*-seedance-2.0*`、`sd*-seedance-2.5*` 路由。版本、线路前缀、清晰度后缀和供应商是调用条件；保持精确 ID，不由名称推断上游身份或性能。

- [检查目录与状态](../../operations/check-bblabu-video.md)：先核对所选 Key 的目录，再看当前路由状态。
- [提交视频与保存结果](../../operations/generate-bblabu-video.md)：逐型号核对时长、清晰度、参考图／视频／音频、首尾帧、人脸规则与费用。
- 同系列各线路的字段、素材组合和计费可能不同，不套用其他线路或官方直连协议。
- 具体 Key 引用及最近目录从 `experience.local.md` 进入本机视频接入记录。

2026-11-26 已验证 BBLABU 只读目录与鉴权；此路径真实视频生成尚未验证。
