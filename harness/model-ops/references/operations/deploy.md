# 部署并验证

先读家族档案和已有本机记录。核对来源、明确版本、能力、框架、内存和所需输入；用户要固定声线时先确认支持参考或已有音色映射。模型已有可用环境时复用，不重新装全局工具。

按当前设备存储约定定位权重与运行环境。后台执行要从实际进程核对路径读取；终端成功不能替代。权重下载、依赖导入、真实推理分别取证。确需服务化时沿原生或现有服务方式部署，不为统一入口强制所有模型常驻。

通过计划使用的日常入口执行短样本，核对实际模型／量化／版本、产物可解码和核心内容；流式能力需另验首片与完整结束。原版本、启动入口和可恢复配置保留，部署只影响授权对象。

结果记录为当前机器实例。文件到位但推理失败时不标整个部署成功，保留错误、尝试和未完成条件。新建过程不改变已保存声音和用户默认。
