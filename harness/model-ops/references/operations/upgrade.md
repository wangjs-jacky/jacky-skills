# 升级与回退

先确定本次允许变更的模型版本、运行时或服务实例，保存旧入口与可恢复配置。不要让新模型覆盖旧声音参考、作品绑定或无关服务。

使用可区分的版本与环境验证，记录实际权重 revision／量化和依赖版本。用同一固定输入与声音参考比较核心内容、格式及声线；原引擎认可不自动转为新版本认可。

通过用户实际调用入口验证后才切换默认实例，并记录切回旧版的入口。升级失败先保留证据，在已有授权内恢复原实例；未走通实际调用或回退时分别报告，不能仅以下载成功完成交付。
