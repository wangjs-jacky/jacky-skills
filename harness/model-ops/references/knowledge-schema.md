# 自动维护

每次执行：读命中经验 → 当前证据复核 → 执行 → 对照目标验证 → 写回唯一归属 → 同步父索引 → 读回并报告。失败、中断与无新增也作判断，不需要用户再说“记录一下”。

- 家族共用能力／限制归模型 index；一个可复用目标的步骤、坑与恢复归对应 operation。
- 机器、解释器、权重路径、服务地址和实际运行证据归 ignored `local/`；`experience.local.md` 只做小型模型／部署导航。
- `local/runtime.json` 仅供启动器确定性选择家族解释器，不保存秘密、业务偏好或服务监控状态。模板为 `{"version":1,"interpreters":{"whisper":"/absolute/path/to/python"}}`。
- 已明确用户调用偏好以 `local/call-preferences.md` 为当前源；当前请求优先，临时覆盖不写长期值。原已授权的同范围记忆继续有效，不把推荐、沉默或一次成功登记为偏好。
- 参考声音、哈希、版本、运行映射和认可归 Voice Material OPS；完整输入、输出与执行日志归原业务任务，不复制第二套目录。
- 导入历史保留原日期、条件及证据链接；迁移、文档、检查、真实推理、质量抽查和用户认可分别记录，不刷新未执行业务的成功日期。

知识文件用 Markdown，沿用已有稳定 ID 并同步索引。operation 的 `status` 用 documented／partial／verified；只有在注明条件下完整达到声明目标才写 `last_verified`。单次机器成功不推成所有实例已验证。失败保留已完成环节、错误和未完成项，不补造成功。

同范围真实方法与同类对象按已确认分类自动维护；改变分类轴、拆并归属、扩大职责再确认。没有可复用新事实可说明原因；有重复完整成功则维护其验证日期。写入失败明确报告未沉淀。

记录协议依靠 Agent 执行，不是后台巡检或强制工具拦截器。经验维护不扩大部署、付费、删除、改默认、提交或发布授权。
