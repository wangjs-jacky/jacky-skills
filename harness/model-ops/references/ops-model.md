# 分类与职责

状态：已确认。依据：用户认可“Model OPS 管部署／调用／排障／经验，Voice Material OPS 管素材／版本／角色，迁移转写核心后撤旧入口”，并明确“开始优化”。

- 主键 `model` 为模型家族，当前含 `whisper`、`qwen3-tts`、`breezetts2`、`suno` 及模型清单中的视频和 3D 家族；已有云端适配 `doubao-asr` 独立保留，不混作本地部署。家族可按真实任务扩充，不把初始清单当作能力上限。
- 能力用于模型索引检索。Qwen3-TTS 的 Base、CustomVoice、VoiceDesign，以及参数规模、量化、版本、框架和机器是模型条件／实例，不为每种组合建目录。
- BreezeCast 是现有 BreezeTTS2 工具入口的检索别名，不能据名字推定后续版本的底层模型不变。
- 原生工具和已有服务负责实际执行；本库保留重复、确定性的轻量适配与格式化工具，Python 沿既有 MLX 生态使用。
- 用户偏好、机器路径、运行映射和原始证据进入唯一 ignored 本机资料；共享方法不复制本机地址或完整业务日志。

## 已确认的首批目标

生命周期：部署并验证、检查可用性、诊断故障、升级回滚。具体推理：Whisper 转写、Qwen3-TTS 合成／音色设计、现有 BreezeTTS2 服务复用。文档设计、依赖就绪、真实推理和试听认可分开记录。

2026-11-26 用户明确要求把本次成功的音乐模型登记在 Model OPS，按同一模型家族主键新增 Suno 云端音乐生成。供应商的具体路由名是实例条件；调用方法、参数与生成故障归本库，API Key 保管与限定鉴权结果继续归 Account Pool OPS。

2026-11-26 用户提供 BBLABU 视频状态 API 与 Key，明确要求配置后供下次视频任务调用。因此沿用模型家族主键补充 Seedance、MiniMax H3、Grok Imagine、Gemini Omni、Wan、Muse、Vidu；BBLABU 及线路前缀是供应商条件，共用视频 operation。此次仅授权接入配置与只读验证，不登记持续付费授权或唯一默认型号。

2026-11-26 用户进一步提供 BBLABU 3D Key 与状态 API，明确要求配置三维生成模型。沿用相同主键新增 `tripo3d` 与 `trellis` 家族；v3.1／P1／P2 等作为版本或线路条件，共用供应商 3D operation。授权范围是配置与只读验证，不推定为已授权生成、持续付费或唯一默认型号。

## 三处唯一归属

| 对象 | 归属 |
| --- | --- |
| 模型能力、执行方式、兼容限制、运行参数、部署实例与故障 | Model OPS |
| 参考声音、文本、哈希、音色版本、角色绑定、引擎声音映射和试听认可 | Voice Material OPS |
| 全文、完整音频、字幕、章节与成片、业务验收 | 原任务 |

部署不改变声音身份；同一参考在新引擎的表现单独验证，原认可不自动扩大。只有参考真正改版才追加声音版本，不覆盖旧版或旧作品绑定。

同范围新模型、操作与别名按真实工作自动维护；分类轴、归属拆并或新媒体职责变化再确认。未来可能能力只记候选，不制造成功记录。
