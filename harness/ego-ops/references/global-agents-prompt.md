# 安装 Agent 提示词：建议启用 ego-ops 全局前置

此提示词随 `ego-ops` 分发，供安装或配置它的 Agent 读取。阅读或保存本文件不构成修改全局指令的授权。

## 给安装 Agent 的提示词

完成正常安装，并建议用户启用下方规则，让其他技能进入网页操作时也先读取站点经验。

1. 核对目标设备、当前执行机与安装目录。从技能目录或注册表确认 `ego-ops/SKILL.md` 可发现、可读取；不硬编码安装者机器路径，不沿用已售出或停用设备的历史映射。
2. 定位当前 Agent 实际使用的全局指令文件。Codex 考虑 `CODEX_HOME` 和 `AGENTS.override.md`；其他 Agent 使用其实际机制。区分持久用户配置、隔离会话与项目文件，不把项目 `AGENTS.md` 当成全局配置。只读取和展示有关段落，避免暴露无关配置。
3. 已存在语义等价且有效规则时报告已配置，不重复写入；用户已明确授权相同内容及范围时直接复用。
4. 否则展示下面规则全文、准备修改的真实文件和生效范围，说明“建议启用后，其他技能涉及网页操作时也会先读取站点经验”，提供 **加入全局规则（推荐）**、**仅安装技能** 两个选项。通过当前宿主的交互工具或文本选项等待明确答复；沉默、预选或安装授权不等于同意修改全局配置。
5. 获得同意后保留原有内容，合并并去重；遇到冲突先说明，不覆盖已有约束。读回相关段落，报告真实写入位置和宿主加载时机，不宣称运行中的其他 Agent 已重新加载。
6. 用户拒绝或没有答复时保留正常安装，不写全局规则，不在普通网页操作时反复询问。纯文件复制/链接不会自动执行此交互，无交互安装可留下建议供后续配置。

## 全局规则

只将以下代码块写入用户确认的全局指令文件：

```markdown
## 浏览器网页操作：先读取 ego-ops

无论当前使用哪个技能，只要任务涉及通过浏览器进行网页操作，都必须先读取 ego-ops，并遵循对应 site 及 operation。

- 从当前环境的技能目录或安装注册表定位 ego-ops/SKILL.md，按站点索引、当前站点和目标 operation 渐进读取，不扫描整个知识库。
- 执行途中才发现需要网页操作时，在继续浏览器操作前补读；本轮已读取且仍适用的内容直接复用。
- 实际控制浏览器前，同时加载并遵循当前浏览器执行 Skill，保留任务空间、授权、用户接管和收尾规则。
- 没有站点或 operation 时按 ego-ops 的探索与沉淀规则处理，不伪造旧经验；技能缺失或不可读时明确说明，继续不受影响的工作。
- 真实成功后按证据自动写回并维护验证日期；未成功不刷新成功日期，失败经验按 ego-ops 的证据规则处理。
```

## 范围与生效边界

规则覆盖使用浏览器打开、观察、交互、采集或配置真实网页的任务；只讨论浏览器概念或编写网页代码不因此启动浏览器流程。若任务还涉及 Cloudflare，同时读取适用的 `cloudflare-ops`；页面经验与平台经验分别归位，已加载内容不重复读取。

全局规则是 Agent 的前置阅读要求，不是执行器拦截钩子。它不替代浏览器执行能力，也不增加业务操作授权。
