# 核验发布样例的资源与交互

## 目标

在独立静态工具样例中确认同站内容地址图片、外部 OSS 图片真实解码，并验证详情开合；页面发布与完整字节验证由 Cloudflare/OSS 流程分别取证。

## 前置条件与授权

明确授权测试的独立公开样例，已知正式地址及预期版本标记。只读浏览和样例按钮，不操作账号控制台或其他生产页面。先绑定一个数字任务空间及精确标签 target，跨轮沿用。

## 入口

打开本轮记录的精确样例 HTTPS 地址，复核 URL 与版本标记。使用同一空间/标签刷新验证后续版本，不按名称恢复其他空间。

## 已验证步骤

1. 读取页面语义结构，确认版本标记及代表图片存在。
2. 等待选定图片 complete 且 naturalWidth 大于零，核对实际自然尺寸；同站与外部图片分别读取，不能以 HTTP200 或下载头代替解码。
3. 依据当前页面中的“展开详情”按钮执行点击，核对详情可见、按钮变为“收起详情”且 aria-expanded 同步。
4. 用当前会话绑定的截图 helper 核验目标/URL后捕获并报告关键步骤；不复用其他运行截图。

## 检查点

页面版本、图片自然尺寸与详情可见性同时符合预期；资源域不同不自动要求 iframe 跨域 DOM。任务空间失效或用户接管即停，截图不匹配不能上报。

## 成功标准

选定图片均真实解码；用户点击能改变实际可见内容与无障碍展开状态。版本读回、完整字节、CORS 和地区速度分别取证，本操作不代替它们。

## 失败模式与恢复

本次未确认可复用的浏览器失败根因；不将网络超时当作站点缺陷。图片未就绪时保留失败，不截图宣称通过或自动循环重试。

## 验证证据

2026-11-04，在已发布的独立样例先验证同站封面，再验证同站与 OSS 两幅图片均为 480×320；详情展开状态与可见文本一致，关键截图经会话/运行绑定上报。随后实际回退首版，页面版本标记恢复、外部图片项移除，同站封面仍480×320；详情展开与收起、aria-expanded 回到false，最终已验证状态已上报。仅覆盖单账号样例与当前浏览器网络，未验证跨账号或中国地区速度。实际地址、版本及证据归本机目标记录。
