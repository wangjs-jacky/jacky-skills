# 本地API链路回归

## 目标

验证狗头军师在本地合成 Responses 上游下的截图上传、咨询方式切换、历史恢复与主动停止。不能将该结果解释为真实模型能力或公网发布验收。

## 前置条件与授权

用户已授权改造并本地验证 AI SDK 与 Sub2API 接入。使用隔离临时数据库、合成凭据与合成图片；不修改生产数据，不发起真实个人 Paws 授权。

## 入口

启动项目的本地 API 回归实例后，用其输出的 loopback 地址进入。登录页包含邀请码输入和“进入狗头军师”；聊天页侧栏包含历史与“AI 服务”。不固定端口、邀请码或临时文件路径。

## 已验证步骤

1. 按回归实例提供的测试凭据登录，确认真实聊天工作区可见。
2. 打开“AI 服务”，确认默认服务说明标注合成回归；切换个人设置后出现连接入口，但不开始授权；选择默认服务返回聊天。
3. 使用上传输入添加实例提供的合成图片，再发送消息。确认用户消息保留图片，合成回答注明接收了图片。
4. 从“选择咨询方式”切换“回复参谋”，继续发送消息；确认原历史仍在，合成回答显示新的模式与携带的历史数量。
5. 刷新页面，确认原消息、图片和咨询方式恢复。
6. 发送实例支持的保持流开放的测试消息，待收到部分正文后点击“停止生成”；确认停止状态、已接收正文与历史保留。

## 检查点

默认服务状态不得触发个人授权；个人设置入口应可见“连接”。模式切换前后是同一段历史；刷新不增加重复消息。停止后不再显示生成中，页面展示“已停止生成”和重发入口。

## 成功标准

实际页面完成截图与两轮对话，模式切换及刷新后内容保留；开放的合成流被主动停止且部分回复没有丢失。回答必须明确标注合成上游，不能宣称真实模型已通过。

## 失败模式与恢复

本次流程修复后未遇到浏览器操作失败。若任务空间或目标被用户接管、目标URL改变，按 Ego 控制权规则停止，不能创建其他空间绕过。

## 验证证据

2026-10-16，通过 Ego 的实际 DOM 交互验证登录、默认/个人设置入口、文件上传、模式切换、刷新恢复与取消。关键步骤截图经会话绑定回执上报，最终取帧显示停止成功与部分回复保留。仅本地合成上游；没有真实模型、生产域名或真实个人授权证据。
