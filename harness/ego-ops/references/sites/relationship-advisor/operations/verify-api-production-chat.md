# 验证线上API聊天与截图历史恢复

## 目标

验证更新后的受保护公网实例能真实理解聊天截图、跨轮记忆，切换咨询方式后仍保留同一历史，并可刷新恢复。

## 前置条件与授权

用户已授权发布并验收新默认 API 后端。原账号和历史须保留；使用已有合法登录态，只新建明确标注验收的对话和虚构聊天截图，不导入旧历史、不更改认证配置、不重新授权个人服务。

## 入口

进入该站点公网首页。侧栏含“开一段新对话”“AI 服务”和“聊过的心事”；聊天输入区含“添加聊天截图”和“选择咨询方式”。

## 已验证步骤

1. 页面恢复原账号后确认旧历史可见，旧 Paws 会话仍展示其原服务入口。
2. 开新对话，打开 AI 服务，确认默认咨询服务为 Sub2API/Codex，并说明固定领域 Skill 与不开放主机工具；选择“使用 Sub2API · Codex”返回聊天。
3. 通过图片文件输入上传虚构聊天截图，发送包含独有记忆标记的关系咨询问题；确认回答准确引用只存在于图片中的原文，并出现建议。
4. 打开咨询方式菜单，选择“回复参谋”，在同一对话追问先前标记与截图中的沟通建议；确认新回答包含原标记和正确上下文。
5. 刷新页面，确认四条消息、原图、模式及空闲状态恢复，再记录最终验证截图。

## 检查点

使用默认 API 不应触发个人授权。图片验收要核对模型真正引用图片原文，而非只看上传缩略图；跨轮记忆要核对新助手消息，不能误匹配用户首轮中已有的标记。生成完成后应无停止按钮，刷新后图片须加载成功且原消息数量不变。

## 成功标准

真实模型完成两轮咨询；图片原文、独有标记与模式均正确，刷新后历史及图片保留。旧会话可见且未迁移。不把本操作说成重新登录、所有旧上游或整机重启验收。

## 失败模式与恢复

本次自动化最初使用不存在的设置按钮 ID，定位失败；同一空间重新观察后按可见“AI 服务”入口完成操作。以当前快照与真实 DOM 为准，不从其他产品猜测选择器，不创建替代空间绕过失败。浏览器目标或控制权变化时须停止。
