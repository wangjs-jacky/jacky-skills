# 展开并读取评论楼中楼

## 目标

对明确的一条评论展开回复并读取实际子回复

## 前置条件与授权

仅在本次明确授权范围内执行；对象不唯一、影响范围扩大或不可逆时停止并确认。

## 入口

目标评论下的 共N条回复 与 点击查看 控制。

## 已验证步骤

1. 用当前 snapshot 锁定目标评论正文和对应的回复计数，确保 点击查看 属于这一条评论。
2. 点击查看 用于展开已有回复；不能误点 回复，后者用于撰写评论。
3. 展开后在同一 BILI-COMMENT-THREAD-RENDERER 开放根内有界遍历，核对实际 BILI-COMMENT-REPLY-RENDERER 及正文出现。
4. 读取少量子回复并保留父评论关联；不能用页面其他线程新加载的正文数量增长代替目标楼中楼验证。

## 检查点

- 本次目标线程从仅有根正文变为十段正文，可读到实际子回复；没有进入撰写或发送流程。
- 展开读取不等于后续分页已加载；需要翻页时按[楼中楼分页](paginate-comment-replies.md)执行。本轮已另验两页样本，没有验证任意深度全部回复。

## 成功标准

选定父评论与真实子回复同时可核对，读取范围明确，未发送回复。

## 失败模式与恢复

尚未记录经证实且可复现的失败模式；结果不明时回到检查点，不更新验证日期。
