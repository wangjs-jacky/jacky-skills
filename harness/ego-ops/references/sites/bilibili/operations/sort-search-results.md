# 切换全站视频搜索排序

## 目标

按最多播放或最新发布查看关键词视频，并核对真实结果变化

## 前置条件与授权

仅在本次明确授权范围内执行；对象不唯一、影响范围扩大或不可逆时停止并确认。

## 入口

当前关键词搜索页的 最多播放、最新发布 等实际排序控制。

## 已验证步骤

1. 核对关键词和视频类型，记录当前少量标题；不得混入课堂、直播或用户卡片。
2. 从当前 snapshot 选择明确的排序，等待目标控件活动态和真实视频卡片更新。排序按钮活动态本次含 vui_button--active。
3. 本次最多播放与最新发布分别产生新列表；保留页面实际 order 参数用于来源核对，不能把一次点击或 URL 改变当作列表已更新。
4. 从含 h3 的视频标题链接读取规范 BV 来源；保留有限结果和当前排序，不声称全站排序算法或所有筛选组合都已验证。

## 检查点

- 本次最多播放与最新发布均验证了选中状态及真实新标题，最新发布样本显示近期发布。
- 与日期、时长组合时仍需逐项对照结果字段，不能由排序通过推断筛选条件一定有效。

## 成功标准

关键词、类型和排序一致，实际视频列表已刷新，少量来源可核对。

## 失败模式与恢复
