# 切换视频评论排序

## 目标

切换最热与最新评论入口，并验证实际列表变化

## 前置条件与授权

仅在本次明确授权范围内执行；对象不唯一、影响范围扩大或不可逆时停止并确认。

## 入口

目标视频评论区当前可见的 最热、最新 控制。

## 已验证步骤

1. 先读取当前评论少量正文和排序控件，保存用来比较的列表摘要。
2. 通过当前 snapshot 或唯一语义定位选择 最新；本次验证方向为初始最热列表切换到最新。
3. 控件由 bili-comments-header-renderer 开放根中的 BILI-TEXT-BUTTON 呈现，语义定位可按 button 的名称选择；不能因宿主没有普通 button 标签就判断控件不存在。
4. 等待新的真实评论正文出现并核对列表摘要变化，保存当前页面状态；点击回执或同名控件存在本身不能作为排序成功。

## 检查点

- 本次切到最新后，可见评论序列与原列表不同，关键帧已核对。
- 未验证反向切换、评论翻页、长期自动刷新或全量时间排序。

## 成功标准

目标排序操作后出现新的可读评论列表，来源视频仍匹配，未点击评论点赞或发布控件。

## 失败模式与恢复

尚未记录经证实且可复现的失败模式；结果不明时回到检查点，不更新验证日期。
