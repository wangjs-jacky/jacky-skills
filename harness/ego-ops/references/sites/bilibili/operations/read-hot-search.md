# 读取B站搜索框热搜

## 目标

从现有 Ego 页面读取 B站热搜词与页面标注的名次

## 前置条件与授权

仅在本次明确授权范围内执行；对象不唯一、影响范围扩大或不可逆时停止并确认。

## 入口

https://www.bilibili.com/ 的顶部搜索框；输入为空时点击搜索框查看 bilibili热搜。

## 已验证步骤

1. 在当前拥有的 Ego Page 打开 B站首页并核对 URL；通过当前 snapshot 定位顶部搜索框，不复用旧的临时引用号。
2. 点击空搜索框，等待可见的 bilibili热搜 标题和热搜条目出现；不清空浏览器历史、不改变登录状态。
3. 在可见 .trending 内读取 .trending-item 的名次与关键词；按页面明确标注的数字排序，不能把双列 DOM 的奇数列顺序当作榜单顺序。
4. 热搜条目本次为可点击容器；如需搜索入口，可用实际关键词生成规范站内搜索 URL，并明确它是生成的搜索入口。仅提取本次真实渲染的词条，不请求站内私有接口。
5. 截图前若显示个人搜索历史，可仅临时隐藏其页面容器，保留热搜可见；不得点击清空或持久更改用户历史。按运行时要求验证当前任务、精确目标及 URL，捕获并报告最终热搜画面。

## 检查点

- 搜索框展开后同时存在搜索历史区和 bilibili热搜 区，两区必须区分；本次热搜区真实显示名次 1 至 10。
- 按显式数字名次排序后，词条与屏幕顺序一致；只描述页面榜单，不把热搜词条所述事件作为已核实新闻。

## 成功标准

当前页面显示 bilibili热搜，且取得实际可见热搜词与其明确名次；来源页面和读取时间可核对，截图不包含个人搜索历史。
