# 用现有会话检索B站视频

## 目标

在不改用户登录状态的前提下验证视频关键词搜索

## 前置条件与授权

仅在本次明确授权范围内执行；对象不唯一、影响范围扩大或不可逆时停止并确认。

## 入口

https://search.bilibili.com/all

## 已验证步骤

1. 使用当前任务拥有的Ego页面打开关键词搜索页，核对页面关键词与预期一致。
2. 等待真实视频卡片出现，读取标题与指向video路径的链接，并区分课程广告和直播等其他结果。
3. 记录当前浏览器是否已有登录会话，只声明本次会话覆盖的结果；不得为免登录实验清空浏览器会话数据或退出用户账号。
4. 结构化提取仅使用包含实际标题 heading 的视频链接；课程、直播等其他卡片不混为视频。作者未在对应可见卡片明确取得时保持未知，不从站内接口补齐。

## 检查点

- 本次复用了已有登录会话，搜索返回多条有效视频；独立匿名API返回412，匿名HTML没有结果，尚无本机未登录搜索成功证据。

## 成功标准

搜索页显示匹配关键词，且取得至少一条有效视频标题及原始链接；登录条件和未验证范围明确。

## 失败模式与恢复

尚未记录经证实且可复现的失败模式；结果不明时回到检查点，不更新验证日期。

## 验证证据

- 2026-11-24：AI视频工具关键词搜索返回五条视频链接；已有登录会话通过，匿名接口受阻。截图及摘要归原测试任务。
- 同日 Web Search 新模块通过 Ego 复用已有会话，返回三条视频标题与规范链接，观察约 1.9 秒；本轮没有使用原生采集命令或匿名搜索接口。
