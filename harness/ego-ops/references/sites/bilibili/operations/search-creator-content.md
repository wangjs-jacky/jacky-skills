# 在UP主主页内搜索作品

## 目标

使用作者空间内搜索限定当前UP主检索视频

## 前置条件与授权

仅在本次明确授权范围内执行；对象不唯一、影响范围扩大或不可逆时停止并确认。

## 入口

目标作者主页内占位文字为 搜索视频、动态 的输入框。

## 已验证步骤

1. 核对当前作者 UID，区分空间内搜索框与顶部全站搜索框。
2. 在空间内输入实际关键词并按 Enter，等待同一 UID 下 /search 路由与 keyword 参数匹配。
3. 等待 共找到关于关键词的N个视频 等真实结果摘要和标题卡片，不用旧列表残留或仅有输入值证明成功。
4. 读取少量真实标题与视频链接。结果可能有标题不直接包含关键词的项目；不能用每个标题都必须含词作为唯一成功条件，也不能在未验证时断言服务器具体匹配哪些字段。

## 检查点

- 本次关键词 Agent 的页面摘要显示八个视频，少量实际结果可读；未重复提交搜索。
- 动态分类入口可见，但本次空间内检索只验了视频结果。

## 成功标准

当前作者 UID、关键词参数与结果摘要一致，真实作品标题和规范链接可读。
