# 采样真实界面并核验脱敏交互回放

## 目标

通过真实只读操作采样页面状态，恢复可操作的脱敏 DOM 副本。区分生产入口观察、已完成的只读动作、静态回放、本地模拟和未采样能力，不把目录自身的点击能力当成产品功能已可操作。

## 前置条件与授权

用户已明确授权操作真实产品、记录步骤并制作公开脱敏副本。只读采样不自动扩大到发送、归档、删除、授权、安装或设备更新；有既有授权时按已指定对象执行，缺少可写对象时独立完成可观察的只读路径。不得修改首页已有草稿。产品源码可作为交叉证据，不替代运行结果。

## 入口

从用户指定的当前 Paws 入口开始，核对实际部署版本和账号上下文，不读取凭据。首页配置触发器使用 `session-config-*` 测试标识；账号菜单提供设置入口；会话管理图标打开命令面板；会话右侧能力中心按模块进入。

## 已验证步骤

1. 记录首页草稿是否存在，保留原值；分别打开机器、目录、Agent、权限、模型和推理强度选择器。输入搜索并读回过滤结果，关闭菜单后继续，不误改选择值。
2. 从账号菜单进入设置，打开外观、声音、语言、功能开关和智能体默认值；声音完成事件可以展开候选。只读看到候选不等于设置保存或声音已播放。
3. 进入 Skills 列表，搜索已安装的目标 Skill，点击结果并读回原文。搜索结果与详情分开采样。
4. 从命令面板搜索已授权查看的会话，打开正文，再进入能力中心的快捷指令、来源和会话操作；标题菜单的详情入口进入会话详情。记录每个入口的实际去向，不根据名称猜测。
5. 切换项目、清单和时间线标签；置顶会话可能占满视口，须在侧栏滚动到分组区。插件目录可搜索并打开详情；详情中出现打开/卸载按钮不代表已进入插件正文或已卸载。
6. 在每个稳定状态采样当前可见 DOM、必要 portal、CSS 和已加载字体；替换会话内容、标题、身份、路径、动态标识及图片。公开文件不包含浏览器上下文、报告或认证材料。
7. 在隔离静态副本中连接实际采样状态，恢复搜索、开关、返回和局部演练。用可观察的结果核验模型选择、输入后发送可用、快捷指令带入、保存后刷新读回、Skills 原文、未覆盖提示与原生下载重开。
8. 发布后读取公开文件并比较哈希；在同一受控浏览器空间确认公开代表路径、窄屏导航和放大后的局部平移。最终报告浏览器状态、知识校验后独立收尾。

## 检查点

弹窗不一定属于应用根节点；可见 portal 祖先可能没有自身高度，不能仅因零高度删掉。`aria-hidden` 表示可访问性状态，不能单独作为视觉隐藏依据。跨路由残留容器须按真实可见状态裁剪。

CSS 规则可能有多行嵌套结构；不能按行去重，否则闭合括号会被误删。保留完整规则以及每个采样状态的顺序，运行时主题变量和已加载字体另行保留。图片和壁纸被替换时明确说明，不能声称像素级一致。

复制 DOM 不包含 React 的事件和状态管理。输入值、disabled、搜索、保存以及返回均须重新绑定并实际验证；公开副本不得保留真实提交地址。未采样按钮说明边界，不伪造成功。

## 成功标准

真实采样步骤有动作与观察；结构化目录能定位其状态和源码；声明支持的副本交互有实际可观察结果；下载可离线重开；公开文件与持久源一致。上述结论不扩展为所有产品功能、真实业务写入、实体手机或像素级复原通过。

## 失败模式与恢复

按行合并 CSS 后，副本只解析部分样式且字体未加载；改为完整规则分块并保留各状态规则顺序后，样式与四种字体正确加载，所有采样状态可渲染。

在本次 Ego 运行环境，缩放 iframe 内的高层点击没有触发目标。先检查 DOM 与当前状态，再按 iframe 和控件实际矩形换算坐标，用 Ego 鼠标点击后状态切换通过；不猜坐标，不把该现象泛化为产品按钮失效。长页控件须进入实际可见区域后再点击。

## 验证证据

2026-11-03，真实 Paws 只读菜单、搜索、会话与设置路径形成四十个 DOM 状态；源码目录关联四十七项能力，其余保留未采样标记。静态副本模型搜索与选择、草稿/演示发送、快捷指令、重命名刷新读回、声音候选、Skills 搜索原文、插件未执行提示通过；全部采样状态有渲染核对。公开代表路径、原生下载、离线重开和窄屏导航/平移通过。精确环境、URL、图像与回执在所属任务私有验收记录。

未真实发送、修改会话、保存设置、安装卸载、分享或更新设备；未取得完整功能逐项业务验收，也不宣称设计已获用户认可。首次公网导航超时后，同一目标读回已完成加载，不能由此断言超时根因。

2026-11-03 逐控件补查：分享窗口需记录主题单选、封面选择/移除、取消和创建；设备环境需展开默认账号菜单、账号改名/删除/额度刷新确认，以及工具详情。只保存页面截图或入口列表会漏掉这些二级动作。控件清单保留禁用条件和出现位置，有模态窗口时不把被遮挡背景计入当前可操作控件；相同会话示例条目不当作独立产品功能。

同日补充恢复验证：一次抓取在浮层节点出现、动画和布局尚未完成时保存了底层页面，导致回放状态名正确但分享控件不存在。等待有限动画完成及布局帧后重采，分享控件正确保留。复验应断言目标状态的关键控件存在，不能只检查通用根 DOM、状态名或总按钮数。分享颜色/封面/演示链接停止，设备默认账号、检测、改名和更新演示有实际浏览器结果；不扩展为真实发布、绑定或更新成功。

同日公开修正版：三个公开文件与持久源哈希一致；分享主题/封面/本地创建、设备默认账号读回、操作清单搜索和待补筛选、实际下载的脚本/数据一致性通过。首次load等待超时后在同一任务目标读回完成，没有另开恢复空间；未证超时根因。静态封装减小后解析数据一致，未把公开演示或下载一致性外推为全控件业务验收。

同日剩余交互补齐：对前轮待补登记保留编号，通过真实鼠标点击逐项核对，再单独验证文件保存/冲突/刷新、消息编辑与分叉、账号草稿、插件、设置和原生文件选择/下载。DOM副本的消息动作可能保留依赖React悬停的pointer-events:none；恢复已接入按钮的命中区域后才可操作，不能用强制DOM点击冒充通过。会话菜单覆盖层应能从正常按钮收起，再点击正文；空白关闭区不应因脱敏被误标成消息操作。

真实页面显示无管理员权限或连接失败时保留该状态，源码确认的可写过程仅提供明确的本地演练。最终公开副本、实际下载的file URL解包、保存刷新读回和窄屏操作清单有成功证据；静态待补归零不代表全部产品功能或真实业务通过。源码与过程写入仍以用户原授权范围为准。
