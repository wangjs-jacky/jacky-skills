# 核验源码功能地图与公开静态交付

## 目标

验证由单一目录生成的 Paws 功能地图：检索分类、状态切换、关系导航、源码追溯与离线导出，并核对授权的公开静态版本。地图交互验收与 Paws 真实业务验收分开。

## 前置条件与授权

用户已授权静态功能盘点、地图交互验证及脱敏公开预览。产品源码只读，不操作真实会话。按当前 Ego 指南使用本任务唯一空间和目标；截图使用本会话的受验证回执并只提交一次。

## 入口

从任务报告中的当前预览链接进入；失效时依授权重新签发预览。页面标题为“Paws · PC Web 功能地图”，页头有阅读说明、路由覆盖、下载目录和离线 HTML。不把临时域名作为生产地址。

## 已验证步骤

1. 检查总数、状态统计及能力域；通过搜索与能力域/状态组合筛选验证匹配、空态和重置。
2. 展开或收起模块，进入条目后切正常、异常及权限状态；沿依赖导航并返回，确认详情对应编号。
3. 打开源码证据，核对相对路径、行号、摘录及固定提交链接；打开路由覆盖并点击某行的实际目标编号。
4. 通过原生下载事件保存目录与离线 HTML；比较目录字节。重新打开离线文件，检查默认状态、选项数量与检索详情。
5. 同一操作轮内设置窄屏并确认实际视口；验证详情、源码弹窗、关闭后滚动及首页边界。
6. 对已发布公开版本复测代表性交互与两种下载，并用独立 HTTP 文件哈希核对静态快照。最终恢复首页、验证并报告，写回后独立结束任务空间。

## 检查点

- 搜索是目录全字段匹配，引用编号也可能命中；期望结果应依据目录。
- 路由首行不保证指向固定编号，使用按钮当前实际目标验证跳转。
- 导出前的筛选不能污染离线初始页面，筛选器选项不能重复。
- 窄屏必须检查当轮 innerWidth，不能假设上一进程的 CDP 模拟继续有效。
- 来源 URL 正确不等于外站已打开成功；公开页面能访问不等于用户实体设备已验证。

## 成功标准

声明覆盖的交互有可观察结果；目录与内嵌内容一致；实际下载可恢复并操作；公开文件与源一致；最终状态有当前会话/任务的截图回执。生产业务、后端或手机客户端没有因此被宣称通过。

## 失败模式与恢复

本轮曾在下一 Ego 进程中读到桌面宽度，导致窄屏断言失败；把设备模拟放到同一轮并读回实际宽度后，窄屏边界通过。这个现象只适用于本轮运行环境，不概括所有版本的持久性。

下载导出需在首次渲染前保留自有静态页面节点，防止导出渲染后的控件选项并在重开时重复初始化；本轮修正后真实下载与重开通过。检查原始 HTML 的选项数量时，应排除脚本字符串中的标签文本；不能把测试断言错误当产品缺陷。

## 验证证据

2026-11-03，真实 Ego 桌面与窄屏操作通过：检索、分类、展开、状态、依赖返回、源码、路由和原生下载。公开页面与目录 HTTP 200、哈希一致；公开下载与已验证离线文件一致。最终公开首页已验证并提交 Happy 关键步骤。具体目录版本、临时入口、截图回执、下载与各轮 Case 保存在任务私有记录。

仅验证地图与静态交付；未执行 Paws 生产业务、真实设备触摸、所有条目逐项点击、来源外站登录或预览生命周期长稳。
