# 验证目标机器新会话与迁移目录的后台读取

## 目标

从真实页面新建指定机器的会话，让后台进程读取迁移目标与兼容入口，核对模型回复和会话完成状态。终端可读与 daemon 在线仅作为前提。

## 前置条件与授权

用户已授权迁移及对应会话验收。预先准备只读探针：断言卷身份，列目录，打开指定小文件并核对哈希，文件访问设有超时；不安装、不修改配置、不启动或停止服务。具体机器、目录、哈希与证据留在任务私有档案。

## 入口

从正式 Paws Web 的“新建会话”进入，使用机器选择器、项目目录及模型/工作量控件。已有验收会话通过当前任务空间的精确标签与目标身份继续，不能猜测同名会话。

## 已验证步骤

1. 新建会话后观察目标机器、项目目录、模型与工作量；机器列表存在重复名称时，核对当前勾选项，不能按顺序猜。
2. 选择机器后重新读取项目目录；已观察到重新选择机器可能将目录重置为 Home。验收使用不占用待迁目录的工作目录。
3. 发送明确限定的只读命令，由后台核对卷身份并读取目标目录；核对模型返回的完整本次标记。
4. 入口切换后，在同一会话再次运行兼容入口探针，检查入口实际指向目标及文件哈希。
5. 等待“发送消息”按钮恢复，再核对当前会话头部显示“已完成”。成功回复出现时，执行状态仍可能尚未结束。
6. 最终浏览器截图按宿主的会话/运行绑定机制报告；随后写回经验、校验知识并独立结束任务空间。

## 检查点

新建会话时确认目标机器及模型；发送后确认指令进入当前会话；回复后确认本次模式、数量与运行标记；最后确认当前会话“已完成”。兼容入口读取须实际打开文件，不能只看目录存在。

## 成功标准

真实新会话收到模型回复，探针确认卷身份、目标或兼容入口、目录读取及指定文件哈希全部通过，当前会话显示“已完成”，并保存对应浏览器证据。只代表探针涉及目录和操作的后台可读性，不能推广为所有服务、全部 Skills 或生产业务均已验收。

## 失败模式与恢复

本次未复现新的启动失败，未通过修改系统权限验证既往故障根因。不得把旧权限拒绝日志当作已确定原因，也不能声称授予某项系统权限必然解决。重复机器名称和目录重置通过重新观察当前选中机器与工作目录处理。任务空间失效、用户接管或目标身份异常时停止，不能新建空间绕过。

## 验证证据

2026-10-19：正式页面新建目标机器会话，后台读取14个准备目标并收到模型成功回复；切换后12个入口、追加迁移后的13个入口分别读取和哈希通过，三次均核对会话“已完成”。当前后台启动依赖保留内置，未改系统权限。页面截图与具体探针收据存于迁移任务的私有证据目录；本站知识不保存动态会话、机器身份或文件路径。
