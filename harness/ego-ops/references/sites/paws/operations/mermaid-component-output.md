# 核验 Mermaid 编写输出与实际组件渲染

## 目标

用 Happy 实际 Mermaid 组件核验给定源码的分组、编号、证据标签和主题显示

## 前置条件与授权

仅在本次明确授权范围内执行；对象不唯一、影响范围扩大或不可逆时停止并确认。

## 入口

Happy/Paws 实际 MermaidRenderer 的隔离验收页面，使用本机 loopback 服务

## 已验证步骤

1. 固定输入场景和 Mermaid 源码，复用实际 MermaidRenderer 与主题语义配色，仅隔离无关原生模块
2. 在已记录的数字任务空间和精确标签页打开页面，等待内联图片完成解码且 naturalWidth 大于零
3. 点击全屏打开图表，等待 SVG 节点完成及 Modal 动画结束，检查节点文字和系统分组
4. 切换浅色与深色主题，分别核验同一源码的完整节点和可见范围，使用会话绑定截图助手上报

## 检查点

- 只使用本任务空间、标签页与显式预期 URL；失去控制权立即停止
- 原版编写规则的显式选项、输入提供的事实与实际产品已集成状态分开记录
- 跨客户端比较优先使用逐字相同的 Mermaid 源码，并记录图表实际尺寸与 viewBox 比例；布局适配的输出不能冒充另一客户端的真实会话截图
- 用户要求先确认效果再接入时，独立视觉 POC 必须明确标记未接入，保留产品工作树；外观审核通过不替代实际组件、图片序列化和原生端回归

## 成功标准

图像解码成功；全屏节点和分组完整可见；截图上报成功；主题中的实际问题如实记录

## 失败模式与恢复

源码中的固定 classDef 和 subgraph 填充色不会自动随宿主深浅主题变化。本次同一源码在深色主题仍保留浅色分组底色，不能把节点可见和解析成功表述为主题适配完成。应保留原样截图并报告实际局限；评估原版 Skill 时不静默修改配色以美化结果。

分组框、步骤标签和长回路即使语法正确，也可能产生大块留白和较远的连线；这些应由完整图截图判断，不能只根据节点数量或内联预览截取部分判定布局优良。

判断语法可被宿主布局适配为虚线圆角矩形。虚框并不天然表示未核验，应同时核对节点文字与实际边框规则，不能从外观反推事实状态。仅持有参考截图时，人工重建图需要明确标为结构复原稿，不能声称原始源码或节点位置完全一致。

仅设置节点的固定浅色填充而未指定文字颜色时，深色主题可能仍使用浅色正文，导致文字几乎不可读。应在实际 SVG 中同时检查标签计算颜色、节点计算填充与对比度，并用相同源码切换浅色主题对照；节点 textContent 存在不代表文字可读。固定输入可用 SHA-256 核对页面字符串与保存源码一致，避免把重新生成的不同文案混入比较。

使用颜色混合后，计算样式可能返回 OKLab 而非 RGB。对比度检查应按实际颜色空间转换后计算，不能把任意颜色字符串内的数字都按 RGB 处理。

实际组件切到 SVG text 标签后，旧验收脚本的 `.nodeLabel` 不一定存在，应同时识别 `.node text` 并计算最终图片比例。ELK 可能把带回路的长链排成横向结构；长图裁切 Case 应使用确定的纵向无环链，用户原始带环源码另存并按摘要核对，不能为了通过几何断言改写原始输入。

官方 ELK 输出的粗线可能同时带 normal 和 thick class；仅按 normal class 设细线仍会覆盖粗线。用实际样式验证普通、粗线、虚线与双向端点；不要只用简化 mock 证明标准语义保留。

验证 Native HTML 时可直接复用生产构造函数、仅在验收 bundle 暴露它，在同源 iframe 内运行真实 CDN 与 ELK。导航默认 load 可能等待动态 iframe；已提交且文档 complete 时应观察当前页，不另开任务空间。此结果只证明 HTML 渲染链，不代表原生控件或真机。

需要核对不透明来源环境时，可在相同验收 iframe 加入仅允许脚本的 sandbox，保留真实 CDN，等待来自该 iframe 的成功缩放桥接或错误消息。父页不能再通过 contentDocument 读取沙箱内 DOM；不要把同源访问异常当成 Mermaid 渲染失败。测试钩子可在错误桥接中附加具体 message，必须注明该钩子是否存在于产品。桌面 Chromium 的成功不能证明手机网络、WebView版本或装机OTA一致；手机只有通用错误卡片时，先核对Update ID，不直接归因为CDN或语法。

评估紧凑布局时同时记录自然宽高与文字实际字号，保持节点、边、步骤和不确定性标签不变，并检查节点背景两两重叠。官方 ELK 的 wrapping 选项对含复合分组的输入不保证达到目标长宽；不能把减少留白的实例稿写成所有长链均能自动折返。桌面1000px视口完整可见，不等于390px手机固定字号可读。

用户要求“超高步骤弯一下”时先锁定目标图，保留已认可的其他图与样式；分行折返不能用全局紧凑参数、缩小字号或缩短文案替代。官方 ELK 的单边 wrapping 会将各行重新从左到右放置，不等于交替方向的蛇形折返；若隔离稿采用特定单链位置适配，应明确其范围，不能声称通用折返已接入产品。

接入共享渲染工厂后应验证实际组件，而非继续截图独立 ELK alias。Mermaid 的节点 helper 会原地将 rect 归一成 squareRect；边标签 helper 返回内部内容组，移动标签时须定位最近的 edgeLabel 外层并保留文字居中变换。应同时核对最终 viewBox、节点实测尺寸、边标签位置与原生工厂序列化后的真实渲染，避免节点已折返、旧标签坐标仍撑高画布。
