# producthunt

## 平台特征

- 公开产品详情使用 /products/<product-slug> 路径，Overview 中展示产品简述、Visit website、截图画廊及开发者和用户讨论。
- 本轮未登录页面仍可读取产品正文和已有讨论；页面同时显示 Sign in 与 Login to comment。本记录不推断所有产品页面均有相同访问状态。
- Reviews、Alternatives、Built with 与 Team 是独立标签；仅看到标签不代表已读取对应内容。
