# zeroomega

## 平台特征

这是浏览器代理扩展，域名字段记录其已验证的扩展主机。入口为浏览器扩展管理中的 ZeroOmega 详情 → 扩展程序选项。代理情景模式可分别设置各网址协议及默认代理，保存通过“应用选项”生效；只读的当前代理状态可证明是否由该扩展控制。

## 站点级陷阱

系统代理设置不能单独证明浏览器当前路由；扩展控制时应在已授权的扩展设置页核对当前生效规则，按目标网址协议分别验证。
