# 读取图文正文与有序配图

## 目标

从当前真实笔记取得标题、作者、正文和按顺序核对的配图

## 前置条件与授权

仅在本次明确授权范围内执行；对象不唯一、影响范围扩大或不可逆时停止并确认。

## 入口

从当前搜索、作者主页或收藏中的真实笔记卡片进入详情；签名链接只在页面内用于本次点击。

## 已验证步骤

1. 进入详情后等待标题、作者和正文或真实图片加载，核对目标身份。先辨别项目介绍、作品展示与具体步骤教程，不能把介绍补写为安装教程。
2. 将读取范围限定到当前 .note-detail-mask，使用 #detail-title、#detail-desc 和当前作者字段，避免混入背景列表或评论区的同名元素。
3. 从 .swiper-slide 的 data-swiper-slide-index 去重并排序，排除循环轮播的 duplicate；本轮五个轮播 DOM 节点对应三张真实图片。
4. 只在当前页面内读取图片 src；需要逐图学习时，利用当前 DOM 给出的公开图片地址，通过现有 Ego Page 保存图片字节，随后逐张查看。地址仅在进程内存中使用，不写入文件、日志或 OPS。
5. 需要操作轮播时点击当前左右箭头并检查索引；截图前等待 swiper 动画完成，并核对激活页与画廊视口对齐，索引变化本身不等于过渡已结束。
6. 按原图页序整理作者明确内容与自己的推导；私有正文、图片、文件摘要和证据归原任务，OPS 只维护可复用方法。

## 检查点

- 正文、作者与当前笔记身份一致；图片索引连续，已保存图片有真实字节并能逐张打开。
- 配图懒加载时先检查 src 与实际加载状态，不能只看 currentSrc 或原始 DOM 数量就漏图或重复计数。
- 详情 URL 的签名不得进入捕获回执；实际加载并核对身份后，在同一页面脱敏地址栏，再用确切任务空间、标签目标和预期 URL 捕获。

## 成功标准

标题、作者和正文可核对；配图按去重后的实际页序逐张查看，摘要不超出真实内容，链接不含签名。

## 失败模式与恢复

轮播刚改索引时截图可能仍处于两页之间；等待 animating 为 false 及激活页视口对齐后再捕获，并查看原图核对。项目介绍没有安装步骤时明确缺口，不自行补齐。

## 验证证据

- 2026-11-25：真实取得一篇项目介绍的标题、作者、正文和三张有序原图，逐张查看并核对轮播终态；原图与私有证据保留于原任务。
