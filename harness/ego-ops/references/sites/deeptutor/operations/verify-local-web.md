## 目标

确认本地 DeepTutor 的首页在真实浏览器中渲染完成。此操作只验证页面加载，不代表模型已配置、问答已通过或全部功能可用。

## 前置条件与授权

用户已要求启动并检查本地 Web 应用。使用启动器实际报告的前端地址，确认当前 Ego 任务空间归本次 Agent 管理；通过远端访问时先核对目标机器。

## 入口

使用官方启动器给出的前端根地址。根路径可能导航至 /chat；继续使用同一 Page，后续截图前核对明确的 URL、数字任务空间及精确 targetId。

## 已验证步骤

1. 在本任务空间的新 Page 打开启动器报告的前端地址，导航到 /chat 后观察同一 Page。
2. 确认侧栏包含 Home、Partners、Personalized Learning、Learning Space、Task Board 和 Settings，聊天区有输入框与 Send 控件。
3. 读取可见状态；若模型尚未配置，保留该事实，不通过发送无配置请求冒充问答验收。
4. 确认页面已渲染后，在同一 Ego 运行轮使用 Happy 指定的会话/run 证据助手采集，并仅上报助手返回的原始路径。

## 检查点

页面标题为 DeepTutor；聊天区出现 How can I help you today? 输入框。导航成功或 HTTP 200/307 本身不足以证明前端已完成渲染。

## 成功标准

真实浏览器能观察到上述导航与聊天输入界面；最终页面截图绑定本次任务空间和目标，并成功报告到 Happy 技能进度。模型与真实聊天另行通过配置、在线诊断及一次实际问答验证。

## 失败模式与恢复

本轮初次导航在静态资源加载时超时，随后沿用原任务空间和 Page 观察、等待可见内容后完成加载。未发现经独立验证的站点缺陷；资源加载中不能重建空间绕过控制权。页面若显示建议生成失败，只记录当前提示，不能据此断言模型服务或整个页面的根因。

## 验证证据

2026-10-24首次核验：页面出现侧栏、New chat、问候语、输入框和Send，当时未配置LLM。后续配置后重新加载同一应用，首页与输入控件仍真实可用，新首页帧已通过会话绑定证据助手采集并上报Happy。资料问答的完整验收另见[知识库聊天](chat-with-knowledge-base.md)，不把页面加载本身当作模型成功。无凭据或私有业务内容进入本文。

2026-10-27修复后重载复核：首页聊天输入、Send及文件输入真实可见，两张指定图片可作为当轮附件准备，并通过Happy绑定证据助手上报。后续长回答验收遇运行机器离线，未作为问答成功；本operation仅更新首页及上传准备的验证日期。
