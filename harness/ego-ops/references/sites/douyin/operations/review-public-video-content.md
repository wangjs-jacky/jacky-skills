# 只读查看公开视频与内容反馈

## 目标

核对公开视频的作者、画面、章节、互动与相关评论，并明确实际抽样范围。

## 前置条件与授权

用户已授权只读查看指定账号或作品。本人入口需要现有登录态，并须核对账号名称；不访问私密作品、私信或账号设置，不点赞、评论、关注、发布或更改作品。

## 入口

用户提供的公开视频详情页，或已登录的 `/user/self` →「作品」。本人主页可使用「搜索你发布的作品」查找相关内容。

## 已验证步骤

1. 在本次独立任务空间打开指定入口，核对账号名称和当前标签；后续复用同一任务空间。
2. 从本人「作品」区域读取卡片标题与规范链接。需要筛选时，在「搜索你发布的作品」输入主题并按 Enter，等待作品卡片实际出现；只读取作品列表内的链接，排除推荐区。
3. 作品标题在快照中可能被截断，可读取卡片内段落的完整 textContent。搜索结果可能模糊命中无关内容，不能把搜索结果数当成全部技术作品数。
4. 打开从目标账号作品列表取得的规范视频链接，重新核对作者、标题与 URL。读取播放器实际时长、页面可见章节和互动区域；章节是平台摘要，可能存在转写错误，不等同于作者原始逐字稿。
5. 按任务需要查看代表性画面或指定时间点。只查看若干画面时报告为抽样查看，不声称完整看完、听完或验证作品中的产品功能。
6. 只读查看与任务相关的评论，区分询问项目、作者回复与持续使用证据。个人身份和评论详情不写入站点经验。
7. 关键步骤按宿主提供的会话绑定截图协议报告；最终已验证页面报告后，再按浏览器 Skill 独立结束任务空间。

## 检查点

本人主页账号与用户目标一致；详情页作者与作品来源一致；当前视频已加载且时长有效；计数从当前作品对应的互动控件读取；明确实际查看范围。

## 成功标准

取得身份一致的作品链接、内容观察及任务相关反馈，关键页面可视证据核验通过；没有执行任何站内社交或作品写操作。

## 失败模式与恢复

- 本轮本人作品搜索结果卡片计数统一显示为零，但相同作品的普通主页卡片和详情互动区具有非零计数。搜索卡片只能用作标题与链接来源，不能据此推断零播放或零互动。
- 详情页 meta description 中“已经收获……个喜欢”在多条视频中复用作者主页获赞总数；不要将它当作单条视频点赞数。
- goto 可能已提交至目标详情页，却等待 load 超时。报错明确说明已提交目标 URL 时，在原标签重新观察并等待实际视频加载；无需创建新任务空间。
