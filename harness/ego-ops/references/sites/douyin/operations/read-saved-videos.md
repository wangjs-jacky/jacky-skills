# 读取收藏中的前 N 个视频

## 目标

在已登录的个人主页中只读列出收藏区域按页面顺序出现的前 N 个视频

## 前置条件与授权

- 仅在当前登录、权限和用户授权范围内执行。
- 对象不唯一、影响范围扩大或不可逆时停止并向用户确认。

## 入口

从左侧“我的”进入个人主页，再打开“收藏 → 视频”

重复回归且入口仍有效时，可直接进入
`https://www.douyin.com/user/self?from_tab_name=main&showSubTab=video&showTab=favorite_collection`，
随后复核当前页面仍是已登录账号的收藏视频视图。

## 已验证步骤

1. 打开抖音首页并确认头像和“我的”入口表明当前登录状态可用
2. 进入“我的”，确认个人主页存在“收藏”主标签
3. 进入“收藏”并选择“视频”子标签，确认页面处于收藏视频视图
4. 只读扫描当前列表，按页面顺序筛选指向 /video/ 的唯一链接，跳过 /note/ 图文条目；页面存在多个滚动容器时，选择包含最多 `/video/` 链接的主内容容器
5. 收集前 N 个视频的标题与规范链接；不足 N 个时停止并报告

## 检查点

- 未显示“我的”入口或个人主页时停止，交还用户处理登录
- 收藏或视频标签不存在、目标列表不足 N 个或页面顺序不稳定时停止

## 成功标准

当前收藏视频视图中取得 N 个去重的视频链接及对应标题，且未触发任何写操作

## 失败模式与恢复

尚未记录经证实且可复现的失败模式；遇到结果不明时回到检查点，不更新验证日期。

## 验证证据

- 页面地址显示收藏主标签与视频子标签
- 本次只读提取 count=30，uniqueCount=30，结果均为去重的 /video/ 链接
