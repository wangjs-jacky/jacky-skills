# 验证外部封面图片可嵌入效果库

## 目标

区分资源上传成功、浏览器图片解码与跨域脚本读取，验证已授权外部封面 URL 能被效果库普通图片元素使用。

## 前置条件与授权

具有测试页面和明确公共图片的核验授权；资源上传/权限设置由对应平台操作处理。本操作只读取图片，不修改服务端站点。只使用本次记录的数字任务空间、精确 targetId 和预期 URL；控制权或目标变化时停止。

## 入口

打开效果库实际主入口，核对页面标题、URL 和任务所属页签。

## 已验证步骤

1. 观察效果库页面，在实际页面 origin 中创建不设置 crossOrigin 的 Image；设置已授权的外部测试图 URL。
2. 通过一次 load/error 事件及有界单次超时获得结果；load 后读取 naturalWidth 和 naturalHeight，确认解码为预期非零尺寸。不通过定时网络查询等待。
3. 记录使用方式、图片格式和尺寸。最终页面状态通过当前宿主隔离截图上报后，再独立结束任务空间。

## 检查点

HTTP 200 和文件哈希一致不等于浏览器可以解码；默认域名带 attachment/force-download 响应头也不能单独推断嵌入 img 必然失败。普通 Image 的 load 成功不证明 CORS fetch/canvas 可读取内容，浏览器 decode 更不证明目标地区访问速度。

## 成功标准

精确页面 origin 中图片触发 load 且原生尺寸与输入一致，数值证据已保留，最终已验证浏览器状态完成隔离截图上报。

## 失败模式与恢复

本轮未观察到浏览器嵌入失败；若之后触发 error，检查实际 URL、Content-Type、访问权限、页面 CSP/CORP 与解码条件，不因服务器返回 200 就标记成功。只对真实验证后的原因补充恢复经验。

## 验证证据

2026-11-03：效果库正式 origin 加载新资源桶中的 2×2 WebP 成功，naturalWidth/Height 均为 2。该对象 HTTP 含强制下载头，但本次普通图片嵌入可解码。最终页面隔离截图已通过 Happy 上报；未修改正式站点，未验证 CORS 脚本读取、画质、性能或其他浏览器。具体 URL、桶名与运行证据归所属目标私有档案。

2026-11-04：正式效果库的生产 WebP 封面以普通 img 加载并解码为640×360；本地故障注入验证外部图失败时仅切换一次同站备用图，不做状态查询或循环重试。正式桌面与触摸模拟关键画面已上报。实际资源清单、数量、URL和匿名哈希验证归目标档案；未验证跨域 canvas/fetch 或其他地区。
