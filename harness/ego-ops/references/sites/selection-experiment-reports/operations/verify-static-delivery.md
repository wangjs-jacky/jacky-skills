# 核对静态报告公开阅读与抽样交互

## 目标

核对静态报告公开阅读入口、主文在所测桌面与手机视口的宽度和局部表格滚动，并分别记录抽样案例交互、一份报告正文与首图的实际读回。成功范围限于这些可观察结果，不判定整个实验方法、六页全功能或真人理解。

## 前置条件与授权

使用当前任务已授权的公开静态范围与发布记录；发布流程以 happy-ops / execution / diagnose-integration 为权威，浏览器动作遵循当前 ego-browser 与宿主规则。源码 ZIP 仍仅本地交付，公开页面不授予源码包发布权限。

本次浏览器操作及关键帧报告均由根协调者完成。知识写回者只读原观察、捕获索引和回执，不控制浏览器、不重发截图、不重复 report 或代替根协调者 finish。以后复用须取得自己的当前控制权与证据。

## 入口

从当前发布记录取得临时入口，核对主文标题，再按“六个中性案例”或“报告、结果与阅读边界”的实际导航进入图库或报告目录。主文的 CSV 比较区域可由其片段导航进入。临时子域、端口和运行标识不作为长期定位条件；不沿旧链接推断最终版本。

## 已验证步骤

1. 在桌面 1440×900 打开最终主文，读回标题、实际视口、文档 clientWidth/scrollWidth 与 main 宽度；本次分别为 1425/1425、850。公开阅读 CSS 的字节身份与修正后清单一致。
2. 实际导航到中性案例入口和报告目录，区分页面访问与资源请求。最终公开入口的 15 个案例、报告和图库请求返回 200，并有相应标题读回；这不表示每页已实际渲染或完成交互验收。
3. 前一公开快照的抽样案例中，案例02三份内嵌 Jost face 有 loaded 记录，主标题两项有限动画有 finished 记录；案例05实际打开 Dialog，Escape 后读回已关闭，焦点返回“创建项目”submit 按钮。这两页字节在最终发布中未变，最终入口没有再次重测这些交互；不推广到其他案例、字体或动画。
4. 实际打开一份原版配置校验报告，读回正文、标题和一张表。首轮全量图片 decode 等待在 15 秒到限，未生成成功帧；随后确认图片为离屏 lazy，滚到首图，再读回 complete=true、naturalWidth=1152、naturalHeight=346。第二图仍未加载，不将首图成功写成全部图形已看。
5. 在手机 390×844 打开主文 CSV 区域，最终文档宽度为 390/390，main 为 353.21875；所测表格 wrapper 的 client/scroll 为 351/590。实际横向 wheel 后 scrollLeft 从 0 到 238 再回 0，pageX 始终为 0。它证明所测表格局部滚动，不代表实体手机触控或全部宽表。
6. 原公开主文曾被宽表撑到文档 scrollWidth=610。根协调者另建签发草稿，只在 ≤960px 的 main 规则增加 width:100%，阅读 CSS 净增 11 字节，其余 46 个公开文件不变；本地及最终公开入口均有上述桌面/手机尺寸和滚动复验。它是阅读封装修正，没有追加业务实验或修改案例。
7. 关键状态使用当次原 helper 帧及回执；最终手机表格状态也已由原观察者报告。两个暂态或失败中间帧不作成功 step，截图来源、观察时刻和报告结果分别保留。

## 检查点

- 请求 200、正文实际渲染、图片自然尺寸、交互读回与截图各有适用范围，不能互相代替。
- 视口尺寸、文档可用宽度、main 宽度、表格 wrapper 和表格滚动宽度分别记录；桌面 1425 不表示视口未设为 1440。
- 字体 loaded 不等于标题动画完成；首张图片加载不等于离屏懒加载图均完成。
- 六份完整报告和 CSV 等入口有请求证据，仅一份原报告正文与首张 SVG 有实际渲染证据。剪贴板内容、完整无障碍、全站交互及真人盲选仍未知。
- 旧公开快照的交互证据只在字节身份已核对的范围引用，不能冒称最终入口重新测过。

## 成功标准

主文在上述两类视口实际读回，所测手机表格可在页面不横移时往返滚动；图库/报告导航及所列请求有读回；抽样案例交互和一份报告首图按各自来源保存；原 helper 与归档帧/回执可追溯。全部声明均限定在这些已发生的目标。

未检查的其余页面功能、其余懒加载图、剪贴板实际内容、完整无障碍、实体手机触控、真人审美与理解继续标为未知。该有限成功不升级整体实验或 Skill 的可信状态。

## 失败模式与恢复

- 本次手机主文被宽表撑开时，wrapper 自身已达表宽，单有 overflow-x:auto 并未形成局部滚动。上述主列宽度约束后，本地和公开实际宽度及 wheel 复验恢复；保留原失败记录。不能将“缺少 min-width:0”当根因，因为原 main 已有该属性；更广的浏览器内在尺寸传播机制未审定。
- 离屏 lazy 图的全量 decode 等待曾到限。经实际滚到首图并读回自然尺寸后，只确认该图加载；其余图仍未知。不把等待到限写成隧道或网络故障，不增加业务状态查询循环。
- 临时链接失效时先核对当前发布记录；本轮未验证旧链接关闭、到期回收或重新发布的完整恢复路径。
