# 核对已登录首页及新输入框

## 目标
确认当前已登录 ChatGPT 首页已完成加载，使用当前输入框和侧边栏语义继续操作。

## 前置条件与授权
用户授权当前 ChatGPT 相关任务；只在自己拥有的任务空间和精确目标操作，不选择其他用户标签或输出聊天历史。

## 入口
https://chatgpt.com/。

## 已验证步骤
在新任务的首页观察当前状态；当前输入框是可编辑 DIV，role=textbox，可见名称为“询问 ChatGPT”。当前 DOM 未提供旧的 #prompt-textarea。检查“打开个人资料菜单”等控件，并在需要取证时使用“显示/隐藏侧边栏”收起个人历史。

## 检查点
导航提交后即使初次 load 等待超时，也继续在同一页核对 URL、DOM 和就绪状态，不另建任务空间。登录态或订阅准入不能只由某个 CSS selector 是否存在推断。

## 成功标准
首页主区域、可编辑输入框及账号菜单出现，收起侧栏后可对当前空白会话取证；这不证明生成、搜索或任意 API 路由均可用。

## 失败模式与恢复
本次没有验证站点缺陷的根因。无输入框时先确认是否仍在加载、是否页面结构改变；不要自动判为未登录、不要清理全局浏览器状态。

## 验证证据
2026-10-26 的实际 DOM 观察、收起侧栏后的 Happy 验证关键帧，以及该任务在本机另行完成的认证准入检查。凭据、个人历史、账号标识和截图临时路径不写入本知识库。
