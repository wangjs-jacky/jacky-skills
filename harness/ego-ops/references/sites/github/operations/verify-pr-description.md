# 核验已创建PR的正文与证据链接

## 目标

只读确认PR正文、按要求提供的稳定证据链接与验证边界正常展示，不执行合并或触发发布。

## 前置条件与授权

PR已由本次授权的CLI流程创建，URL已读回；仓库可见性已核实。本次公开PR无需切换账号；不因能够查看页面而推断有合并授权。

## 入口

显式的GitHub PR URL，在本轮新建并记录的数字任务空间与精确目标标签页打开。使用Conversation正文与当前约定证据作为观察范围。

## 已验证步骤

1. 进入明确PR后，核对标题、Open状态和目标分支信息，不根据其他同名标签页猜测对象。
2. 在PR正文检查功能摘要、验证数量与未合并／未发布边界；图片使用固定commit的raw URL，不依赖本机临时路径。
3. 当前约定有图片时，通过替代文字辨认目标图，确认complete且naturalWidth大于零。使用视频下载链接时核对指向固定提交，CLI单次下载与本地产物哈希对齐；链接可见、下载成功和手机播放分别判断。
4. PR正文更新后重新观察，使用会话绑定助手捕获最终核验状态并上报；上报完成后再独立结束任务空间。

## 检查点

每轮核对任务空间归属、精确target和显式预期URL；正文与图片要属于该PR。CLI创建成功、页面加载成功、图片解码成功和CI状态分别判定。

## 成功标准

真实页面显示预期PR正文；所要求的固定提交证据链接正确；存在图片要求时均解码成功；最终截图上报成功。只确认当前读取时的CI状态，不将运行中或跳过写成测试／发布成功。

## 失败模式与恢复

本次未验证可复用的失败与恢复路径。图片不唯一、任务空间失效、用户接管或URL改变时停止，不以其他空间或未验证图片回退。
