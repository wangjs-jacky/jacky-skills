# jacky-design

## 平台特征

画廊无需登录，首页按设计问题或完整风格浏览，支持组合筛选、真实HTML样本、来源与验证范围、指定案例或AI范围选择的复用提示词。风格可视样本直接展示效果、规则、来源及提示词，Kami与Carbon Blue各有独立入口；旧场景目录保留历史路径。AI默认排除草稿，显式启用保留试用边界。新增独立“规范对照”入口，用相同内容比较单个参数，不含提示词；原风格样本仍沿旧入口。正式入口为 https://design.paws.rodeo/ 。
