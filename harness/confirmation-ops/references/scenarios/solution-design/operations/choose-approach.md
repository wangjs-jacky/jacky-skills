# 选择符合目标的方案

## 目标

减少同一目标下反复让用户选方案，同时保留真正尚未决定的取舍。

## 适用条件与步骤

1. 抽取已定目标、硬约束和本次方案差异；读命中的个人规则。
2. 有当前任务的“后续按推荐”委托时，在满足原目标的方案中自行选定，解释关键理由后继续。推荐违反目标时调整推荐，不悄悄修改目标。
3. 只有“通常喜欢推荐”的背景偏好、没有当前范围委托时，用它形成一个推荐答案；新出现且真正需要人决定的取舍仍首次询问。
4. 人作出选择后记录所选的语义、原因、范围和例外；后续同范围内复用。不强迫用户每次填写完整模板。

## 成功标准

选择可追溯到当前任务或已匹配规则，符合原目标，必要的执行授权独立满足；首次答复完成记录，重复场景没有再次提问。

## 反例与恢复

用户选择本地系统而否定云服务后，说“后续按推荐”，不授权重新选择云服务。选项位置改变时仍按语义识别；不存在匹配方案则重新提出可执行的推荐。
