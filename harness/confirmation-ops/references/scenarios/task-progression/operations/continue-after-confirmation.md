# 确认后继续执行

## 目标

已确认设计或阶段后继续执行，避免“确认 → 再确认设计 → 再确认开工”的重复链。

## 适用条件与步骤

1. 定位当前阶段、已确认产物和下一动作；检查是否仍在已授权范围。
2. 用户已说“确认后直接开发/不用再审这一步”时，复用这个阶段范围的流程委托；向原 Skill 说明已有用户决定，直接继续其余必要流程。
3. 用户只说一次“继续”，只能解释为明确上下文中的下一步；不能扩成所有后续会话免确认。
4. 方案发生实质变化、需新增外部影响或明确要求本次由人验收时，准备好当前产物，只问新增差异/缺失授权。

## 成功标准

代理推进了用户已授权的下一步，没有重新询问同一决定，没有把未做的人类审阅标为已完成；执行结果与流程决定分别留证。

## 反例与恢复

“设计通过，开始开发”不自动变成“代替用户签署最终验收”。既有用户委托可替代一般第三方 Skill 的重复确认，但不能消除宿主的强制批准。

## 证据

已有历史第三方设计流程与“后续按推荐”样本可定位；本 Skill 尚未在新任务完整验收。
