# 启用跨技能全局前置

## 目标

将统一确认入口接入用户授权的全局指令，避免修改每个第三方 Skill。

## 适用条件与步骤

1. 依 codex-ops 或当前宿主管理技能核对持久入口、真实全局文件和 override。
2. 准备好可审阅技能及完整全局规则；本 Skill 的内容来自 references/global-agents-prompt.md。
3. 已有相同内容和作用域授权就直接合并，否则展示规则全文、真实路径和范围，只请求一次明确选择。用户只授权创建技能时不能把“通常用推荐”转换为全局配置许可。
4. 写入后读回，保留其他规则。新会话是否发现及触发必须另据实际证据判断，不能宣称正在运行的其他会话已自动重载。

## 成功标准

技能可读且唯一归属清晰；全局状态准确标记已生成/已写入/已加载；授权和修改对象可追溯。未授权时正常安装可完成，但全局启用仍未完成。

## 反例与恢复

另一台设备的启用许可不自动许可本机或所有 Agent；“创建确认 OPS”不是修改所有第三方 Skill 或所有全局设置的许可。

## 证据

2026-11-11：用户明确批准已展示的分类和全局前置规则后，实际追加准确规则并读回；原内容与权限保留，私有备份和去重检查通过。宿主技能目录已发现本 Skill，本会话随后收到含新段落的替换式全局指令。验证覆盖本机安装、规则保存和当前会话加载；其他会话重载、第三方真实业务自动触发未验收，精确路径及证据留本机记录。
