# 安装提示词：确认 OPS 全局前置

本文件随 Skill 分发。只保存它不会改变宿主行为。

安装 Agent 核对设备、持久技能入口、当前 Agent 真正加载的全局文件及 override。不要把临时 CODEX_HOME 或项目文件误当持久全局源。已有同范围授权直接合并，没有时展示下列全文、真实目标文件和范围，用户明确同意后再写；仅安装或没有回答时保留提示词，不阻塞安装，不在日常任务重复询问。保留无关内容、备份、去重并读回；分别报告保存、发现与实际触发情况。

## 建议合并的完整规则

```markdown
## 确认与选择：提问前读取 confirmation-ops

无论当前使用哪个技能，只要准备向用户请求方案选择、继续执行或操作许可，先读取 confirmation-ops，按 scenario → operation 复核当前指令和已有决定；本轮已读且仍适用的内容直接复用。

- 已有同范围有效决定或持续授权时直接继续；未命中且确需人决定时，只问缺失项，先完成可独立进行的准备工作。
- 用户选择后按原范围自动沉淀，不另问是否记住；不把通常采纳推荐、单次同意、沉默或自动选择升级为持续动作授权。
- 当前要求、撤销和保留对象优先；遵守系统、开发者与工具的有效审批要求，不伪造用户答复或人工验收。
- 完成、失败或中断后维护唯一规则与索引，区分已记录、已执行和已验证；技能不可读时说明，并继续不依赖它的工作。
```

## 生效边界

触发范围是 Agent 即将向用户请求实际决定，不是出现“确认”二字就启动。该规则依靠 Agent 遵循，不控制其他运行中的会话、不拦截宿主审批弹窗、不替人完成登录签署，也不保证所有第三方宿主自动加载。
