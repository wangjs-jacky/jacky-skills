# 交互复用 OPS

## 安装与配置

负责安装/配置的Agent先读[全局前置建议](references/global-agents-prompt.md)，按真实授权处理。普通使用直接走下面流程。源码可读、已安装、宿主发现分别核对；本文件不授予安装、发布或全局配置权限。

## 进入与选型

用户给出页面并要求优化交互时，默认自行识别场景、选用合适效果并直接适配；无需让用户逐项挑动效。先理解页面的内容、主要操作、既有状态/返回和鼠标/触摸输入，保持当前任务范围。选效果的依据是反馈是否有用、空间关系是否更清楚和是否匹配当前风格，不按动画数量评价。

1. 定位本Skill实际目录；若有experience.local.md，只读命中的当前实例。读取[分类标准](references/ops-model.md)和[场景索引](references/scenes/index.md)。
2. 只读当前页面命中的scene/index及operation，再读所选effect及关联源码。别先把整库全部塞进上下文。跨场景沿链接复用唯一方法。
3. 方法的source-example验证只证明原示例。接入新页面前复核DOM身份、几何、素材裁切/加载、输入取消与减少动态条件。参数写清原文、拟合或新适配值。
4. 按[实际复用](references/reuse.md)执行；素材、视觉和业务状态需要适配，不整页套参考外观。明确请求才涉及新页面或新源视频；现有案例数量不授予全量采集权限。

## 参考实现与缺口

场景下effect是方法正文，assets/demos是完整自编参考实现，assets/patterns是经实际接入校正的小型可移植行为。assets/catalogue.json仅路由身份与路径，不维护第二份长方法。一个视频示例可以含多个可复用子效果；原片、作者截图、完整字幕及私有过程不进共享Skill。原始提示词由有权限的来源项目保管，自写复用提示词在effect中明确标注。

缺少匹配案例时，在当前页面需求与授权内实现并实测，记录为新事实；没有证据不要冒充旧库成功经验。已收录原位搜索、滚动搜索顶栏和数量步进器；不同输入控件按实际方法检索，不用滑杆经验冒充文本输入反馈。新增同类方法可按已确认标准维护；分类轴/既有归属或服务范围改变时再讨论。

## 验证与写回

验证至少覆盖触发→中间→终态→返回、快速重复/取消与适用的键盘、触摸、减少动态。浏览器先ego-ops再当前ego-browser，遵守其任务空间/控制权/截图/收尾规则。需要图片时优先现有可用自制素材，确需生图时使用环境实际可用能力并记录输入，不宣称未核验的模型。

每次完成、失败或中断后，按[知识与写回](references/knowledge-schema.md)判断，更新唯一effect/operation、相关场景与索引；复用的真实证据留当前项目或ignored实例。只有声明范围的全部成功标准已验证才刷新日期；迁移或结构检查不刷新业务成功。写回和校验完成后再按执行工具收尾。

运行scripts/validate-library.mjs检查路由/相对链接/素材路径，结构通过不证明运行或用户认可。报告实际写回位置、实现/交互验证、与参考差距和未验证范围。该写回协议由Agent遵循，不是后台监控或宿主拦截器。
