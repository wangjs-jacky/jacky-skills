# 安装 Agent：交互复用 OPS 全局前置建议

本文件只是一份可分发建议，未授权修改当前全局规则。普通使用不运行安装交互。

安装Agent应核对当前设备、真实可发现Skill路径与宿主全局指令文件；已有同范围有效授权则合并并读回，语义等价规则不重复插入。未获授权时展示下方规则和目标文件，询问“加入规则”或“仅安装技能”；无答复不阻塞普通安装，也不写规则。复制/链接不自动运行该流程。

建议规则：

> 当任务涉及从参考沉淀Web交互，或优化现有HTML的导航、按钮、图片、弹窗、布局、文字、控件和图表交互时，先读取interaction-reproduction-ops，按场景及operation查找合适方法。按当前页面自主选型、适配、操作验证并按证据更新经验。实际浏览器与发布继续遵循对应执行工具/领域OPS，知识不会扩大外部动作授权。

安装后分别说明源码已就绪、Skill已安装、规则已生成/写入/被宿主加载；检查真实文件并报告，不能把文件复制当成所有运行会话已重载。
