# 顶部筛选全局联动

适用：筛选条件需要影响整页相关统计。

核心不变量：指标、柱图和占比来自同一筛选状态；示例数据不冒充真实业务数据。

## 来源和证据边界

https://www.douyin.com/video/7689682595944140058，示例3，62–83秒。来源实现已验证；迁移和新入口不自动获得同样结论。视觉相似度待评价；原提示词和完整原始材料由使用者有权限的原项目保管。

## 构图、触发和运动

黑白黄TURNSTILE门禁后台；左黑导航与白员工分类；顶部黑指标和黄色门卡，底白黄灰双柱/占比/通行列表。

点击今天/本周/本月及门区/人员过滤，所有数字和图表更新，页面与员工导航不刷新。

时间、门区、人员筛选联动四个数字、柱图和占比，无整页重载。

- 筛选按钮先给出选中反馈；总数、进/出/拒绝分别滚动到对应目标。
- 黄色与浅灰柱高随同一进度插值，部门占比也更新；不能仅换总数。
- 保持同一DOM与页面，新的选择打断前一过渡，从当前值继续。

66.5秒已本月284，70秒后回到本周68；非整页重新载入。
