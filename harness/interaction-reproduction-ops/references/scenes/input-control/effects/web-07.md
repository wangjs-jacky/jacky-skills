# 分档拖动条

适用：离散档位的连续拖动选择。

核心不变量：拖动过程连续、释放才吸附；数值独立滚动，取消恢复原档。

## 来源和证据边界

https://www.douyin.com/video/7693492904148405550，示例7，120–138秒。来源实现已验证；迁移和新入口不自动获得同样结论。视觉相似度待评价；原提示词和完整原始材料由使用者有权限的原项目保管。

## 构图、触发和运动

ROUE灰白，顶左右为助力档位/剩余km；底部斜纹圆角长轨，橙色已走区域、黑色圆拖柄与数字轮。

横拖圆钮，连续位置伴随离散数字；释放自动吸附1–5最近档。

跟手连续移动、1–5数字独立滚动、松手吸附、取消还原。

- 位置可在档位之间连续走，读数用四舍五入选择档位，不能拖动本身只跳格。
- 已走橙区域跟随拖柄边缘，数字独立滚动；续航按档变化。
- 释放后以弹性从当前连续位置到最近档，回程同理。

125.5秒4档附近、126秒快速到2档，随后静止；并非所有切换都经过教学慢放。

## 实现和适配

5档来自画面，行程由当前轨道宽度计算；640ms阻尼响应拟合，续航[120,104,92,76,60]为演示映射。

## 关键状态

- 121.5s：2档初态
- 124s：拖动中间
- 125.6s：4档
- 125.9s：向左移动
- 126.2s：回到2档
- 127.8s：2档吸附稳定
- 135s：3档与原文
