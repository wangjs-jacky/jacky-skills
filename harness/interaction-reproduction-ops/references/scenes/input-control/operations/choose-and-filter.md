# 选择数值与筛选

## 目标

区分连续操控、提交选择和取消恢复。

## 适用状态与前置条件

滑杆、筛选、分档、输入控件已出现在用户要优化的页面中，且存在明确的内容/输入目标。源示例已有操作证据，跨页面复用仍需验证；本operation暂按documented导入，不冒充已经通用于新页面。

## 选型与实现

- [分档拖动条](../effects/web-07.md)：离散档位的连续拖动选择。 拖动过程连续、释放才吸附；数值独立滚动，取消恢复原档。
- [顶部筛选全局联动](../effects/dashboard-03.md)：筛选条件需要影响整页相关统计。 指标、柱图和占比来自同一筛选状态；示例数据不冒充真实业务数据。

保持当前页面的任务和内容关系；读取选定效果的源码、参数与素材条件，按当前几何和输入适配。不要先套统一视觉模板。

## 成功标准

- 拖动过程连续、释放才吸附；数值独立滚动，取消恢复原档。
- 指标、柱图和占比来自同一筛选状态；示例数据不冒充真实业务数据。

在新页面实际触发、观察连续变化、返回和复位，验证触摸/键盘及减少动态；仍有差距如实说明。

## 失败与恢复

- 分档拖动条：无真实车辆模型；曲线与数字滚动时序按画面拟合。
- 顶部筛选全局联动：完整源数据与过滤规则未知；不是实际门禁服务。
