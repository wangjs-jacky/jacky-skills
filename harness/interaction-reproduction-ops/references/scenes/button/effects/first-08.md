# 弹性微缩按压反馈

适用：按钮需要明确按住与释放反馈。

核心不变量：按住保持0.96，释放先越过1再归位；阴影和尺寸分开收尾，取消使用稳态回归。

## 构图、触发和运动

浅底上黑色胶囊 Start Run 按钮，文字与箭头作为整体；上方标题及下方灰线固定。右侧 SCALE、SHADOW、OVERSHOOT 展示幅度。

按住 Start Run，松开观察超调；拖出按钮取消。也可用空格或 Enter 按住与释放。

按住保持 0.96；释放先超过 1，再略低于 1。阴影和尺寸有独立收尾，周围布局保持不动。

- 按下时外壳、文字和箭头一起缩小，标题与周围布局不动；按钮中心位置大体保持。
- 缩小的同时内侧暗影增强，轮廓边缘有凹入感；不是单纯降低透明度。
- 保持按住时停在 0.960，不不停跳动。释放后先回到 1 附近，再短暂超过 1，之后略低于 1，最终稳定。
- 阴影与大小不同步结束：160.0 秒阴影还有 18%，160.1 秒已经 0，但缩放仍大于 1。
- 示例只演示触感，未展示点击后的业务跳转或成功状态。

158.5–158.7 秒可见压入；159.8–160.6 秒可见释放、超调和衰减。按住的停留长度属于演示操作，不能写死成按钮动画时长。

## 关键状态

- 158.5s：接触前基准；1.000 / 阴影 0%，按钮完整大小。
- 158.6s：压入途中；0.966 / 阴影 84%。
- 158.7s：按住稳态；0.960 / 阴影 100%，内容整体微缩。
- 159.8s：释放开始附近；仍是 0.960，下一节点开始回正。
- 159.9s：回升；0.985 / 阴影 72%，尚未达到原尺寸。
- 160s：超过原尺寸；1.007 / 阴影 18%，出现 +0.7%。
- 160.1s：明显超调样本；1.011 / 阴影 0%，不代表真实最大值。
- 160.4s：小幅反向收敛；0.997，比 1 略小。
- 160.6s：稳定恢复；1.000，阴影 0%，触点也淡出。
