# 展示详情并返回

## 目标

解释入口如何变成信息层，并能沿原路返回。

## 适用状态与前置条件

弹窗、侧栏、底部面板、胶囊已出现在用户要优化的页面中，且存在明确的内容/输入目标。源示例已有操作证据，跨页面复用仍需验证；本operation暂按documented导入，不冒充已经通用于新页面。

## 选型与实现

- [流体胶囊形变](../effects/first-02.md)：紧凑状态入口需要展开为更多信息。 先变宽再长高、内容滞后；关闭也有独立时序。
- [阻尼弹性抽屉](../effects/first-05.md)：需要多档高度和越界反馈的信息抽屉。 上下边界都有阻力；释放速度也影响停靠，取消不能丢失起点。
- [列表加右侧详情抽屉](../effects/dashboard-06.md)：列表选择某项后就近查看详情。 抽屉占据布局空间，当前行保留；上下选择只换内容，末行与底部操作不能裁切。
- [玻璃面板浮起](../effects/popup-01.md)：旅行等轻量信息卡需要保留背景语境。 背景渐糊、玻璃卡浮起、数字与月份错峰；月份从底部填充，不能整体淡入。
- [圆环计数弹出](../effects/popup-02.md)：凭证需要同时显示比例与剩余数值。 先面板落位，再让圆环与数字共享同一进度；整数到终值不等于动画已结束。
- [刻度尺扫到今天](../effects/popup-03.md)：时间进度需要刻度表达，并可原位展开编号。 刻度逐根扫到今天；编号逐字替换，稳定布局中的行高不变。
- [照片抽屉贴合](../effects/popup-04.md)：图片与详情抽屉需要彼此贴合。 照片先从1.08回到1，抽屉再贴到照片下沿，进度内容最后进入。
- [点击翻面凭证](../effects/popup-05.md)：同一张凭证正面与背面承载不同信息。 保留单卡节点与裁切；90度后才显示背面，背面控件的inert随面切换。
- [下拉展开面板](../effects/popup-06.md)：票券的次要信息可沿底部把手展开。 只移动下半张；行程的40%两侧、2度摆动、取消与键盘收放分别测试。

保持当前页面的任务和内容关系；读取选定效果的源码、参数与素材条件，按当前几何和输入适配。不要先套统一视觉模板。

## 成功标准

- 先变宽再长高、内容滞后；关闭也有独立时序。
- 上下边界都有阻力；释放速度也影响停靠，取消不能丢失起点。
- 抽屉占据布局空间，当前行保留；上下选择只换内容，末行与底部操作不能裁切。
- 背景渐糊、玻璃卡浮起、数字与月份错峰；月份从底部填充，不能整体淡入。
- 先面板落位，再让圆环与数字共享同一进度；整数到终值不等于动画已结束。
- 刻度逐根扫到今天；编号逐字替换，稳定布局中的行高不变。
- 照片先从1.08回到1，抽屉再贴到照片下沿，进度内容最后进入。
- 保留单卡节点与裁切；90度后才显示背面，背面控件的inert随面切换。
- 只移动下半张；行程的40%两侧、2度摆动、取消与键盘收放分别测试。

在新页面实际触发、观察连续变化、返回和复位，验证触摸/键盘及减少动态；仍有差距如实说明。

## 失败与恢复

- 流体胶囊形变：176×60 与 490×330 沿用画面读数；相位差、曲线和内容时机为拟合。整块面板均可关闭，是补写的操作边界。
- 阻尼弹性抽屉：三档 110/430/650 沿用作者读数；阻力公式与速度投影为拟合。保存仅演示本地确认，不连接真实账户或设备。
- 列表加右侧详情抽屉：器材照片本轮生成；六行复用同一相机图并改变裁切，镜头照片与原片不同。
- 玻璃面板浮起：生成里斯本图替代；原天气和街景素材未提供，玻璃感依浏览器渲染存在差异。
- 圆环计数弹出：封面为生成雪景、非原书封；不接真实阅读账户。
