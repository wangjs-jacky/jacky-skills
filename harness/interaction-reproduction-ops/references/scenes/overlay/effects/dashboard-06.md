# 列表加右侧详情抽屉

适用：列表选择某项后就近查看详情。

核心不变量：抽屉占据布局空间，当前行保留；上下选择只换内容，末行与底部操作不能裁切。

## 来源和证据边界

https://www.douyin.com/video/7689682595944140058，示例6，131–151.5秒。来源实现已验证；迁移和新入口不自动获得同样结论。视觉相似度待评价；原提示词和完整原始材料由使用者有权限的原项目保管。

## 构图、触发和运动

Inventory米白器材库，左细导航；黄作业卡、橙库存圆饼、黑补货相机卡；下表与右侧黑相机详情。

点表格行，右侧详情滑入，列表压窄并保持当前行高亮；键盘上下更换内容。

右侧进场压窄列表、当前行高亮、上下只换内容、关闭与再次打开。

- 抽屉宽从0长到右侧占比，列表相应连续压窄，保持可读。
- 切另一行只更新同一抽屉内图片/名称/数字，抽屉不反复关开。
- 关闭抽屉，列表恢复全宽；选中行与滚动位置保留。

133.5秒详情正在进场，134秒左右到稳定宽度；136.5后切换第二行，作者写键盘分支但成片未完全证明事件。
