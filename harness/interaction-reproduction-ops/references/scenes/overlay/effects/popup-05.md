# 点击翻面凭证

适用：同一张凭证正面与背面承载不同信息。

核心不变量：保留单卡节点与裁切；90度后才显示背面，背面控件的inert随面切换。

## 来源和证据边界

https://www.douyin.com/video/7693766486346714431，示例5，77–92.4秒。来源实现已验证；迁移和新入口不自动获得同样结论。视觉相似度待评价；原提示词和完整原始材料由使用者有权限的原项目保管。

## 构图、触发和运动

深蓝NOMAD露营App，房车夜色与路上会员卡；正面照片上叠163天信息，背面灰卡、入营编号、完整资料。

点击查看凭证，整卡绕Y轴在原位置翻面；再点返回逆向翻回。

保留一张照片卡节点，绕Y轴180°，90°后见背面；编号后入，反向返回。

- perspective1200px，绕Y180°，0.8s曲线(.3,.7,.2,1)。
- 前半程还是照片正面，90°侧边时换背面；不让文字镜像或正反两面同时浮现。
- 背面编号后出现，返回同一张照片卡，布局和底按钮保持上下文。

80.8秒前保持正面，81秒附近薄侧面，81.3秒背面，82秒以后编号进入；后续教学缩回App画面。

## 关键状态

- 79.6s：正面照片凭证
