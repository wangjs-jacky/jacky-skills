# 光标变形

适用：图片可探索性需要轻量指针提示。

核心不变量：指针提示不替代可点击语义；触摸用点选，操作按钮上应收回查看圆。

## 来源和证据边界

https://www.douyin.com/video/7693492904148405550，示例2，34–47秒。来源实现已验证；迁移和新入口不自动获得同样结论。视觉相似度待评价；原提示词和完整原始材料由使用者有权限的原项目保管。

## 构图、触发和运动

CARVE黑底三列竖幅雪景，白色标题；大橙圆显示“查看”，轮廓按钮为橙描边。

鼠标进入照片，点状光标变成文字圆；离开照片到按钮时缩回。

鼠标小点/88px查看圆、惯性跟随、转到按钮缩回；触摸选择替代hover。

- 橙色圆跟随指针且有位置滞后；图片亮度随当前项改变。
- 从照片转到普通按钮，圆缩小、标签淡出；不是整个页面永久显示大圆。
- 系统光标只在相应鼠标区域隐藏，不能让触摸操作依赖不可见hover。

36.5–39秒主要是缓慢跟随保持；40秒附近移向按钮，返回小点。

## 实现和适配

88px来自屏幕原文；130ms位置跟随、缩放300ms为拟合。

## 成功标准与失败边界

指针提示不替代可点击语义；触摸用点选，操作按钮上应收回查看圆。至少检查初态、中间、终态与返回；按触发语义检查取消、快速重复、键盘/触摸和减少动态。
