# 共享元素无缝展开

适用：从图片列表进入详情，用户需要记住回到哪一张。

核心不变量：保持同一个图片节点与列表滚动位置，同时插值位置、大小、圆角、裁切和背景。

## 来源和证据边界

https://www.douyin.com/video/7685690273317309702，示例3，49–69秒。来源实现已验证；本次另在一个库存详情页验证复用，具体范围见“已验证复用”。其他迁移和新入口不自动获得同样结论。视觉相似度待评价；原提示词和完整原始材料由使用者有权限的原项目保管。

## 构图、触发和运动

Trails 列表中有多个雪景条目；选择的是第二张 Nordkette Ridge 滑雪者照片。详情由同一张照片、标题、指标、说明和 Start 按钮组成。

点击任意路线图片展开；使用左上返回按钮或 Escape 收回。列表可滚动后再选图，返回完成后可选择其他路线。

同一图像节点同时改变位置、大小、圆角和裁切；列表变暗，详情内容滞后进入。

- 照片边框、可见裁切区域和位置连续改变；同一人物在中间帧一直存在，没有先消失再出现另一张图。
- 列表图约为横向裁切；详情明显增加纵向可见范围，人物身体和雪地逐渐露出，不能只把横图等比拉大。
- 选中图片往上扩展并覆盖列表，其他条目/标题变暗；详情文字与返回控件在展开后出现。
- 60.0–60.5 秒是清楚的反向轨迹：大图缩回第二条的位置，列表恢复，详情信息退出。
- 视频自己的镜头放大也会让整个手机变大；只有相对于手机边框的图片位置、裁切及作者读数用于判断产品转场。

55–56.2 秒明确标 SLOW ×0.22，56.3 秒起有 FREEZE 注释；适合看轨迹，不适合量原生展开时长。60.0–60.4 秒返回有连续中间帧，60.4 秒后进入 COMPARE 擦屏。

## 实现和适配

列表图 358×210，详情图 390×520；同一个 img 在列表与共享图层间移动。位置/裁切以 p 通道连续插值，k=170/c=26；详情滞后 180ms。 未注明原文的实现参数为本地拟合；关键状态中的画面读数不等同源码实测。

## 关键状态

- 55s：列表中选中第二张；仍是 358×210 的 Nordkette Ridge 图片。
- 55.6s：同图开始扩展；360×227，人物仍在画面中。
- 56s：改变裁切与位置；367×292，列表背景变暗。
- 56.2s：继续露出图片；373×354；三个中间位置能追踪同一人物。
- 57.4s：详情构图；390×520；此时带作者注释，不能算正常停留时长。
- 58s：详情可返回；返回控件出现，详情文字位于图片下方。
- 60.1s：返回第一段；388×499；照片仍在，没有白屏。
- 60.2s：回到列表途中；379×412；原列表重新显露。
- 60.3s：接近原条目；364×272，原卡标签重新出现。
- 60.5s：回原位；358×210；此刻已有 COMPARE 辅助线。
