# 悬停预览图片

适用：文字列表需要预览对应图片而不打断阅读。

核心不变量：先确认对应行；图片切换有独立层和惯性跟随，移出缩小收回。

## 来源和证据边界

https://www.douyin.com/video/7693492904148405550，示例9，156–170秒。来源实现已验证；迁移和新入口不自动获得同样结论。视觉相似度待评价；原提示词和完整原始材料由使用者有权限的原项目保管。

## 构图、触发和运动

CARVE浅底列表：Nordkette、Chamonix、Dolomiti、Laax、Verbier；细横线分行，右侧海拔；浮图跟光标。

进入某行出现对应竖图，换行新图弹入覆盖旧图，行文字及海拔高亮。

按行替图、新旧两层覆盖、首次.8/换图.9、惯性跟随与缩小退出。

- 首次预览从.8放大淡入，图片位置带惯性而非贴死指针。
- 换行新图从.9弹入，旧图仍在后层短暂可见；保持同一浮动容器。
- 离开列表缩小淡出，其他行回到原色；图片不拦截列表指针。

157秒尚无预览，157.4秒Nordkette出现，158.6秒转Chamonix；有图层重合中间态。
