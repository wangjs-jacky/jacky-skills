# 滚动变小窗

适用：用户看评论或正文时仍需跟踪正在播放的媒体。

核心不变量：同一个video、同一媒体源和播放时间连续；网页小窗不是系统PiP。

## 来源和证据边界

https://www.douyin.com/video/7689313540751184970，示例5，59.1–70秒。来源实现已验证；迁移和新入口不自动获得同样结论。视觉相似度待评价；原提示词和完整原始材料由使用者有权限的原项目保管。

## 构图、触发和运动

Trail film顶部横向视频、12 MIN字样、下方评论；缩小后落右下角并保留粉色播放进度。

先点播放，再在评论区向下滚动；点击右下小窗回顶。播放/暂停可独立控制。

同一个video按滚动进度缩小与移动，停在右下；返回沿同一路径，不重新加载播放器。

- 滚动不是到阈值才瞬移：中途同时发生宽度缩小、位置向下/向右移动。
- 标题和评论按列表滚动，视频脱离正文位置但保持同一画面与进度。
- 到200px附近停靠右下角，继续滚评论时位置不跟着离开。
- 点小窗后沿路径反向放大；回程截图可见297→169→100→50的SCROLL变化与200→221→380→470的宽度变化。

62秒附近正常收缩，63–66秒含慢放/定格，68.6–69.3秒可见返回，不复制教学停格。

## 实现和适配

宽470→200沿原文；滚动50–180px的smoothstep映射为拟合。DOM身份、视频时间与暂停状态独立核对。

[可操作参考](../../../../assets/demos/second/cases/05.html) · [完整实现JS](../../../../assets/demos/second/cases/05.js)。同目录HTML/CSS、共享运行时及必要自制素材构成该参考，适配时提取所需行为，不整页照搬。

## 关键状态

- 62.2s：正文大视频；宽470，评论位于下方
- 62.8s：滚动中段；视频同时缩小并移动
- 63.2s：小窗形成；靠右下，评论继续可读
- 64.5s：稳定停靠；宽200，保持角落
- 68.6s：点击小窗；同一视频接收点击
- 68.9s：返回中段；列表回顶、视频反向放大
- 69.1s：接近大窗；宽度回470，仍在回顶
- 69.3s：大窗恢复；回原顶部位置

## 成功标准与失败边界

同一个video、同一媒体源和播放时间连续；网页小窗不是系统PiP。至少检查初态、中间、终态与返回；按触发语义检查取消、快速重复、键盘/触摸和减少动态。
