# 滚动钉住主图

适用：产品图与分段说明需要保持同一阅读上下文。

核心不变量：同一张图片连续裁切；滚动进度决定位置，反向同一路径返回。

## 来源和证据边界

https://www.douyin.com/video/7693492904148405550，示例1，14–33秒。来源实现已验证；迁移和新入口不自动获得同样结论。视觉相似度待评价；原提示词和完整原始材料由使用者有权限的原项目保管。

## 构图、触发和运动

ROUE浅灰产品页；左侧自行车方形图固定，右侧整车/车架/传动/车把四段文字；橙色细环与标签定位重点。

在右侧区域滚动，固定主图按章节推进局部细节，让产品介绍保持空间上下文。

固定图、分段文字、四处裁切和橙环，滚动正反向连续。

- 同一张自行车图片持续缩放和位移，左容器固定；右侧标题纵向通过阅读位置。
- 整车→车架时先出现局部中间态，后稳定在三角架，橙色环标记晚于接近目标。
- 传动与车把使用同一图片的不同裁切与锚点。返回由同一滚动函数计算，原片含重播跳回整车，不能将跳切当作自然回程。

17秒附近重播回整车，18.6秒后再进入车架；提示词键入和局部强调属于教学。
