# 柱状图跟手读数

适用：柱图需要在指针位置给出即时读数。

核心不变量：参考线连续移动，左右状态与上方数值一致；触摸和键盘有等价读数。

## 来源和证据边界

https://www.douyin.com/video/7693492904148405550，示例8，140–154秒。来源实现已验证；迁移和新入口不自动获得同样结论。视觉相似度待评价；原提示词和完整原始材料由使用者有权限的原项目保管。

## 构图、触发和运动

ROUE深底，内嵌密集橙/灰柱状图；左上大号km翻滚，指示线上端白圆图标与橙字读数。

鼠标横扫柱图，竖线连续走；左侧柱点亮，右侧压暗；上方数字独立滚动。

竖线连续移动、左亮右暗、顶部数字滚动、触摸和键盘读取。

- 线按连续位置计算，着色按线左侧柱序；不是每柱独立tooltip。
- 上方大数字有滚动中间态，标签读数与指示位置保持对应。
- mouseleave返回默认读数作为补写，原片主要展示横扫。

141.5–144.5秒指示从左向中间移动，数值24→50，能看见数字翻动分段。
