# 指标区滚动吸顶

适用：长页向下阅读时仍需看到关键指标。

核心不变量：同一批指标节点连续缩成顶栏；反向恢复，避免复制一份固定顶栏。

## 来源和证据边界

https://www.douyin.com/video/7689682595944140058，示例5，107–128秒。来源实现已验证；迁移和新入口不自动获得同样结论。视觉相似度待评价；原提示词和完整原始材料由使用者有权限的原项目保管。

## 构图、触发和运动

米白Nodeflux API Console；顶栏左黑圆Y/标题、右用户；四大指标，墨绿项目卡、白卡、青绿同心圆、端点列表。

往下滚，指标字号与间距连续缩小，最后收成顶栏中一排；回滚连续展开。

四个原指标节点随滚动收成一行吸顶，反向连续恢复。

- 四个指标节点持续可见，文字从大区向顶栏移动；不是大标题消失后另显示一排。
- 字体/间距与滚动归一进度连续变化；随后数据区域继续向上滚，指标停住。
- 反向滚动先停栏后逐步展开，回初态；原片多次滚动不同距离。

111秒字体已缩至较小，112秒收成一排，113秒后继续滚到端点列表；17px是屏幕读数，不等于源码精测。

## 关键状态

- 109.2s：大指标区
- 111.1s：缩小中段
- 111.5s：接近顶栏
- 112s：一行吸顶
- 113s：端点开始出现
- 114s：指标保持可见
- 117.5s：反向滚回展开
