# 图表悬停联动

适用：多张图表示同一组日期，需要同日探索。

核心不变量：引用同一个日期索引与一条对齐参考线；其他内容只降低强调，不换成不同日期。

## 来源和证据边界

https://www.douyin.com/video/7689682595944140058，示例4，85–104.5秒。来源实现已验证；迁移和新入口不自动获得同样结论。视觉相似度待评价；原提示词和完整原始材料由使用者有权限的原项目保管。

## 构图、触发和运动

Switchyard白灰珊瑚影视工作台，左下摄影配置，上方食物拍摄照，中间Camera hours柱图和August 2026排期，右检查清单。

悬停某天，柱图和排期同一天同时高亮，其他天压暗，竖向参考线对齐。

柱、日期、排期共享同一天，单条竖线贯穿两图，其他数据变淡。

- 橙色柱、日期数字、相应任务条同步变化，不能各图独立响应。
- 共享竖线从柱区贯穿排期同一x坐标；日期列宽一致。
- 移出图表撤销参考线与压暗，恢复全量数据。触摸与键盘需替代hover。

88秒高亮28号，88.5秒附近移出，90.5秒重新进入；源页有注释与定格。

## 复用提示词

在当前页面的图表与数据展示场景中适配“图表悬停联动”。适用目标：多张图表示同一组日期，需要同日探索。关键约束：引用同一个日期索引与一条对齐参考线；其他内容只降低强调，不换成不同日期。触发和返回：悬停某天，柱图和排期同一天同时高亮，其他天压暗，竖向参考线对齐。实现参数：七日列对齐，参考线从实际列宽计算；.15/.2s淡化拟合。这些参数按来源说明区分屏幕原文与拟合，不把作者屏幕读数当源码测量。结合当前布局、素材和输入方式接入，保留可取消、可复位和减少动态分支，实际操作后报告差异。

本段为自写复用要求；原屏幕提示词、补写和拟合的原始区分保留在来源项目，不伪造逐步聊天记录。
