# 磁吸游标与滚动码表

适用：带关键节点又可连续探索的曲线。

核心不变量：连续区与吸附区分别处理；每个数字位独立滚动，单位保持位置。

## 来源和证据边界

https://www.douyin.com/video/7685690273317309702，示例4，69–87秒。来源实现已验证；迁移和新入口不自动获得同样结论。视觉相似度待评价；原提示词和完整原始材料由使用者有权限的原项目保管。

## 构图、触发和运动

折线图、竖直指示线、橙色焦点/光晕、左上 km/h 大数字；右侧 CURSOR X、SNAP 节点编号和 VALUE 是教学读数。单位固定，数字处有垂直滚动裁切。

按住折线区域横向移动；方向键选点，Shift + 方向键连续探索，Home / End 到两端。

节点之间连续插值；接近节点才吸附。顶部两位数字各自滚动并被窗口裁切，单位保持原位。

- 离节点较远时 SNAP 显示横线，焦点仍在两节点间的折线上连续移动，VALUE 也变化。
- 靠近数据点后出现 P01/P02 等编号，焦点更贴近节点；不是全程把游标硬切到最近点。
- 数字滚动时，旧数字的尾部与新数字的头部同时可见，随后被窗口裁去；km/h 没跟着滚动。
- 焦点外侧半透明橙晕的范围/强弱变化，辅助定位；它与折线本体不是一起整体缩放。
- 后续从右侧 P12 反向滑回 P03/P01，体现双向探索；抬手后的隐藏/保留规则没有清晰独立演示。

72.5–73.2 秒可见正常移动与数字换位；73.3 秒进入慢放。看原片内 SLOW 标记，不能从这一整段直接拟合吸附时长。

12 点数据；吸附距离为相邻点间距的 0.14 倍。游标 k=650/c=45，数码 k=280/c=30。抬手保留当前选择是补写规则。 未注明原文的实现参数为本地拟合；关键状态中的画面读数不等同源码实测。

## 关键状态

- 72.5s：吸附在首点；P01，38.0；光晕围住首个数据点。
- 72.9s：数字开始滚动；旧数与新数同时出现在数字窗口。
- 73s：点间移动；SNAP=—，39.7；不能把这一段省成跳点。
- 73.1s：仍在连续插值区；VALUE=41.1，焦点沿线移动。
- 73.2s：接近下一节点；P02 出现，值还在收敛至 44。
- 73.3s：下一节点稳定；P02 / 44.0；此帧进入慢放。
- 77s：探索到右端；P12 / 50.1，顶部 50。
- 79s：反向探索；返回 P10 / 58.0，焦点和数字同步。
- 80s：回到左侧；P03 / 41.2；过程仍可往返。

## 成功标准与失败边界

连续区与吸附区分别处理；每个数字位独立滚动，单位保持位置。至少检查初态、中间、终态与返回；按触发语义检查取消、快速重复、键盘/触摸和减少动态。
