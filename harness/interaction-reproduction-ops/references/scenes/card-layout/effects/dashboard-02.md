# 模块就地放大

适用：多模块工作台需要临时聚焦某一块。

核心不变量：模块本身连续改变宽高，其他模块缩到底条，内部内容重排；不能只做中心scale。

## 来源和证据边界

https://www.douyin.com/video/7689682595944140058，示例2，42–60.5秒。来源实现已验证；迁移和新入口不自动获得同样结论。视觉相似度待评价；原提示词和完整原始材料由使用者有权限的原项目保管。

## 构图、触发和运动

Aurora Falls—S2E04浅蓝白面板；甘特、金黄柱图、任务、聊天五块，蓝色播放图标。

点击柱状图，从右上原位置放大，占据主区，其他模块移到下方缩略带。

同一模块连续变大，其他缩成底条，切换后可原路收回。

- 放大模块同一节点宽高/位置连续变化，内部图表同步撑开；不另造静态大图。
- 其他模块缩到下方且内容仍辨识，可点击切换当前放大项。
- 关闭回到原网格，保留所选模块与原布局；图表上同根柱可以继续高亮。

45秒后柱图开始横向放大，46–47秒仍在变化；47秒附近进入完整详情。教学箭头和从原位置放大注释不入产品。

## 关键状态

- 44s：完整五块网格
- 45.1s：点击右上柱图
- 45.5s：柱图原位增长
- 46s：下层模块缩小
- 46.4s：图表继续铺开
- 47s：详情主区成形
- 49.5s：底部缩略条稳定

## 成功标准与失败边界

模块本身连续改变宽高，其他模块缩到底条，内部内容重排；不能只做中心scale。至少检查初态、中间、终态与返回；按触发语义检查取消、快速重复、键盘/触摸和减少动态。
