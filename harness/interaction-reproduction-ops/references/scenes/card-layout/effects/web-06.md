# 功能块悬停翻色

适用：功能卡片需要明确当前聚焦项。

核心不变量：扩散原点来自箭头；同时只高亮一项，退出回程和文字对比度一起检查。

## 来源和证据边界

https://www.douyin.com/video/7693492904148405550，示例6，102–117秒。来源实现已验证；迁移和新入口不自动获得同样结论。视觉相似度待评价；原提示词和完整原始材料由使用者有权限的原项目保管。

## 构图、触发和运动

CARVE深底四张高卡；46cm雪况、32°坡向、2340m定位、5条雪道，各有图标、箭头和橙色小柱。

hover或focus一张，橙色从右上箭头所在位置扩散，卡片文字反黑。

圆从箭头中心扩散、文字反黑、箭头45°，同时只一块主色。

- clip圆心固定为右上箭头中心，初始半径0，扩散覆盖最远角。
- 文字同步反转；箭头45°转动，局部圆钮最终反色。
- 同时只有当前一张保持橙色；离开反向收回，不套整卡opacity。

104秒附近首卡已橙；后续切到第三卡与其他卡，有教学停留。

45°来自原文，440ms进入/退出同一CSS过渡为拟合。
