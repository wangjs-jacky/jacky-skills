# 动态弥散光晕边框

适用：少量核心卡片需要细边与柔光分层。

核心不变量：轮廓与背光分开；停止、离屏和减少动态都应停止持续更新。

## 构图、触发和运动

AI LINE COACH 深色圆角卡，橙色曲线与 Best line 1.4 min 内容保持稳定；亮线沿卡片外轮廓流转，卡片背后有更大、更软的橙色光域。

观察持续变化的细边框与背光。使用左下按钮暂停或继续，开启减少动态效果会停止变化。

卡片与图表固定；约 8 秒绕行一周，背后柔光用独立节奏呼吸。

- 亮的边框段沿四边迁移，卡片和内部文字/曲线不跟着旋转。
- 外部模糊光域随方向变化并明暗起伏；卡片轮廓仍比背光锐利，形成两种不同尺度的光。
- 115 秒附近的注释明确写“只有2px那么细”；这是作者标注，不能把缩放视频中的像素直接等同 CSS px。
- 119–120 秒有 PLAIN/CRAFT 擦屏，展示有无装饰的区别；擦屏线与教学读数都不是产品组件的一部分。

正常 LIVE 时 116/117/118 秒角度分别 102°/147°/192°，提示该演示约 45°/秒、约 8 秒一周；这是据读数估计，慢放区不计入。亮度节奏与角度不是同一个线性进度。

## 成功标准与失败边界

轮廓与背光分开；停止、离屏和减少动态都应停止持续更新。至少检查初态、中间、终态与返回；按触发语义检查取消、快速重复、键盘/触摸和减少动态。
