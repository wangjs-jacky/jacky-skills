# 导航底色跟随

适用：同一行导航项目需要标记当前项与临时悬停项。

核心不变量：移动同一个底块并测量真实宽度；移出返回当前项，不堆叠多个指示块。

## 来源和证据边界

https://www.douyin.com/video/7693492904148405550，示例5，85–99秒。来源实现已验证；迁移和新入口不自动获得同样结论。视觉相似度待评价；原提示词和完整原始材料由使用者有权限的原项目保管。

## 构图、触发和运动

灰白CARVE页，顶部整条深色圆角导航，logo白，橙色小胶囊在不等宽导航词后移动；下方文字与两张雪照。

鼠标在导航文字间穿行，底块在同一连续层中移动和变宽；移出回当前页。

同一个底块连续移动/变宽、移出回当前项、点击改变当前页。

- 底块为单个绝对定位节点，读取新项left和width；不可每项单独fade背景。
- 固定当前“雪板”由小橙点标记，hover可临时到固定器/门店/关于我们。
- 移出恢复当前项；点击后选中项改变，键盘焦点跟随。

87秒固定器，88秒雪场，89秒门店；橙块跨中间空间，不瞬移。
