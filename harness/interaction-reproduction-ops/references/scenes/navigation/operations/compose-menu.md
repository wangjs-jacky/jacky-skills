# 组织后台菜单与快捷动作

适用：导航位置、当前项文字、标题、图标提示或高频动作需要适配后台内容空间。先核对页面的信息层级和主要输入，不以菜单装饰数量做选择。

## 选型

- [透明顶栏](../effects/v7695986297705450806-01.md)：页面背景/材质需要贯穿导航，同时当前位置保持清楚。
- [右侧竖轨菜单](../effects/v7695986297705450806-02.md)：后台内容向左展开，主导航需要固定在右侧且辨识度高。
- [当前项展开文字](../effects/v7695986297705450806-03.md)：入口较多但只有当前项需要文字说明，切换仍须保留空间关系。
- [图标菜单配大标题](../effects/v7695986297705450806-04.md)：导航只留图标而页面名称仍要清晰，内容区可承载大标题与范围。
- [图标轨加悬停提示](../effects/v7695986297705450806-05.md)：紧凑图标菜单需要可发现文字名称，并照顾键盘/触摸。
- [菜单旁快捷操作](../effects/v7695986297705450806-06.md)：高频动作不值得跳到新页面，需放在主菜单旁直接操作。

## 操作与验证

从命中方法读取完整实现与适用边界，先适配原页面构图/文字/素材，再接状态与动画。菜单身份、当前页名称和实际内容须一致；快捷动作需直接有可读结果及取消/复位。检查运动中反向、快速操作、键盘/焦点、触摸和减少动态，按证据写回唯一方法。教学改版不能自动转换成产品每次操作。
