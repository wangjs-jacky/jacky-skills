# 三个完整网页与十个复用入口

RALLY、VITRINE、FOLIUM是分别编写的三个HTML/CSS/JS页面，十个条目通过片段定位共享页面中的机制。完整方法、场景及验证范围从走廊各条目读取。作者三个finesse Skill的源码和实际生成聊天未取得，本版没有安装或伪造作者的执行链。

本版使用独立素材：RALLY骑手照片1张、VITRINE中心作品2张、FOLIUM透明植物6张由当前原生imagegen生成；逐张输入及模型可核验范围见assets对应JSON。其他VITRINE作品是26份原创SVG；RALLY风景复用此前自制照片，来源相对路径/哈希在assets/rally/reused-sources.json。图片只承载作品/植物/照片，页面和交互由活DOM及代码实现。

主要差异：RALLY原横图是骑行视频，本版静态照片替代；未知字体使用系统字体；植物和作品均非作者素材，标本记录部分合成，18研究卡复用六图。所有运动参数是根据画面拟合或本版补写，不是作者源码实测值。回放/分段导航、键盘/触摸取消、减少动态是为可复用验证补充的操作。用户视觉认可、实体设备、其他浏览器和长期稳定性尚未取得。

原视频、作者帧、完整原提示词、私有分析及操作证据不在这个公开目录。自写复用提示词和过程概述从走廊查阅；完整原文链接需要来源private仓库访问权。
