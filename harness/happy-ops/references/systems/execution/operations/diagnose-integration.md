## 失败模式与恢复

连接/订阅成功不等于模型可用；文件存在不等于线上任务完成。不要把隔离视频采集当成写入产品后的完整成功。

已删除对象的创建 ID 不能复用。只有服务端明确拒绝复用该 ID 时，才允许保留原输入、持久化一个新 ID 并有界重试创建；网络不确定或普通拒绝仍保留原请求。删除确认只清理匹配的创建恢复记录，不能清空连接存储、凭据或执行 outbox。

原生会话恢复必须保留原 thread：已成功恢复后不要因重复初始化再恢复一次，失败也不能静默创建空白 thread。同步过期判断涉及数据库无时区时间列时，应使用明确 UTC 比较，并在生产时区执行真实数据库回归。

预览修改后仍显示旧内容时，先区分固定快照与页面缓存。本次快照边界有原执行记录及已安装代码支持，不能靠重复publish更新；仅创建最终工作区不能记为已发布。字体扩展名拒绝与浏览器实际加载也分别取证；data URL封装不证明其他交互或完整产品通过。
