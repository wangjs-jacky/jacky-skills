# 制作参数

这些范围是从真实反馈提炼的校准起点，不是所有任务的固定时长或已保证自然的标准。按信息量、软件动画和实际语音调整；动作、讲解和观看可重叠，不能把每个等待逐项相加。

## 声音：稳定复用，素材仍归Voice Material OPS

先通过Voice Material OPS定位唯一库，解析本任务明确选择或本工作流已有声音版本。已有有效绑定且用户未要求改变时直接复用，不每次重选、不新增试听确认。机器上的具体VoiceID、参考和服务地址从对应OPS的本机配置取得，不写死在共享Skill。

实际合成使用兼容所选声音的已有服务。服务就绪、参考版本、真实合成和用户试听认可分别核验；失败先排查和报告，不静默使用macOS say/Tingting或其他引擎替换。鉴权遵循account-pool-ops，密钥只在授权进程内存。

本人声音已入库时按明确版本使用；尚未提供参考时说明素材缺项，进入对应素材建立流程。不要把“以后录自己的声音”写成当前已收到录音、已克隆或已认可；不要在本OPS另建声音库。用户要求将自己的声音设为本工作流默认后，沿声音OPS维护使用关系，保留旧版成品。

录制顺序按素材状态选择：首次探索按用户要求先录真实过程，再依据事件编排口播；已知且可重复的教学路径可先生成完整语义段旁白、取得时长后录制；已有录像只需配音时保留原画面，直接按素材配音与对齐。不能为迁就口播把首次探索假称事先已知或事后模拟。

普通讲解采用清楚、平静、随和的中文说明；“嗯”“等一下”对应实际转折与核对，不为填时长插入。情绪标签以当前服务实际支持为准；历史已试过的`[笑]`不保证其他引擎兼容，英文`wait`不当作未经核验的暂停控制符。

## 节奏起点

| 场景 | 起始范围与检查 |
| --- | --- |
| 首次定位新区域 | 全景或含入口的上下文约0.8–1.5秒，入口文字与目标边界可见 |
| 鼠标移动 | 通常0.15–0.35秒，随距离调整；空闲保持位置 |
| 滚轮浏览 | 一组滚动约0.25–0.5秒，停稳后通常看结果0.8–1.5秒 |
| 普通单击 | 原速单击，稳定反馈通常展示1–2秒；相关句子说完整 |
| 一次性动画 | 等实际结束，再看结尾约0.5–1秒 |
| 重点循环动画 | 完整面板下先看3–5秒，已能看清变化可调整 |
| 目录选择 | 完整弹窗1–2秒；输入后核对2–3秒；确认结果1–2秒 |
| 中文逐字输入 | 整段平均约6–9字/秒，包含采集及停顿成本，长路径可明确演示粘贴 |
| 标点与换行 | 按语义短停，约150–300ms与250–450ms，不能每次机械追加 |
| 口播气口 | 普通句间约300–650ms；真实核对中的“等一下”后约600–900ms |

稳定状态至少有机会被看到约1秒；复杂阅读按内容另算，软件加载等待可观察就绪状态，不能靠固定睡眠认定成功。已交代过的区域连续动作可直接进行。总片长由内容决定，相似完整入门案例约一分钟只是参考，不能压成碎句短片或拉慢输入凑时间。

## 镜头与字幕

- 先交代位置，再对讲解重点放大，完成后回全景或平移到下一重点，阅读时镜头稳定。
- 1080p、16:9可作为缺省导出配置；主窗口宽约85%–90%，保留外围背景与字幕区。
- 放大约0.6–0.8秒、缩回约0.6–0.9秒，缓入缓出。常用1.3–1.8倍，以完整控件边界为先，尽量留24–48px余量；裁卡时降低倍率。
- 标签、轨道、选中结果与必要上下文一起入镜。关键文字约22–32px为检查目标；大弹窗可先全貌再讲局部，不能只拍一个圆点。
- 字幕通常32–40px、最多两行，避开输入与结果；采用一套光标展示，轨迹对应实际动作，保留软件自身回弹。

缩放是成片镜头效果，保持被教学软件本身的布局与比例。相似效果不代表已调用Recordly原生渲染器，交付须说明实际制作路径。

## 局部修订与验收

保留用户较认可的底稿、完整原声与源素材。根据反馈只调整对应局部，不全片统一快慢、不裁句尾和气口。复用真实旧片保留来源说明；当前草稿、已发送与原片成功结果分开标记。

检查真实操作结果、全过程覆盖、口播完整、关键控件不裁边、声音与动作衔接、全片可解码，再通过宿主媒体工具交付。技术检查不能代替用户对自然度的评价；若仍只获“稍好”，如实保存限制与反馈。
