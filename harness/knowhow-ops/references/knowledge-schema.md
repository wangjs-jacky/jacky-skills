# 经验归属与自动维护

每次任务都执行：读取已有经验 → 用当前环境复核 → 实际执行 → 对照成功标准 → 写回唯一归属 → 同步索引 → 报告。完成、失败或中断后均判断可复用事实，不等待用户另行要求记录。

## 归属

- 分类及扩展边界：`ops-model.md`。
- 场景共享方法：`scenarios/<scenario>/index.md`；单个可复用目标：其`operations/<operation>.md`。
- 网页特定定位、页面状态与成功步骤归Ego OPS；声音身份、参考素材、版本与选择归Voice Material OPS；平台配置经验归现有领域OPS。这里只记录跨能力协作与引用，避免复制两套规则。
- 私有配置、设备、账号别名和证据路径：`local/`，由`experience.local.md`小型索引导航。原始录屏、语音、截图、脚本和任务报告留原任务工作区，不搬进共享Skill。

## 身份和渐进读取

分类主键为`scenario`，清单入口为`scenarios/index.md`。每层清单提供稳定ID、目标摘要、读取条件与相对链接；先选场景，再选operation，不遍历全库。软件、版本、宿主、账号和录制方式是适用条件或实例，不创建它们与场景的所有组合。

新增索引或操作使用库内唯一ID，改标题或迁路径时保留ID并更新引用。用户明确要求更换ID时，按一次完整迁移处理：先保存旧新ID映射和原件，再同步修改定义与所有引用，核对唯一性与链接；迁移映射归原任务私有历史，不在现用知识库保留旧前缀。操作最少具有`id/title/summary/scenario/operation/status/last_verified`，可按需要补`use_when/avoid_when/aliases`。一个文件只维护一个可说清的目标；步骤不是单独operation。

## 可信度

| status | 证据范围 | last_verified |
| --- | --- | --- |
| documented | 方法设计、文档或尚未完整实测的指导 | null |
| partial | 有真实局部结果，但该目标仍有必要验收缺口 | null，局部日期写正文 |
| verified | 声明目标及全部必要成功条件均有实际证据 | 真实成功日期 |

文件可读、宿主发现、计划走查、媒体解码、实际操作和用户观感分别记录。技术检查不能证明教程自然；用户“稍好、还OK”不能升级为整体满意。导入历史保留原验证日期，迁移日不作为成功日。

## 写回规则

1. 根据当前任务结果和证据选择状态。未执行的步骤只能写为设计，不伪造操作经验或成功日期。
2. 将新事实合并进已有唯一条目；失效内容原位修正或降级，保留必要历史，不追加相反结论。已验证失败现象、根因和恢复才可提炼通用陷阱；临时网络或登录失败不直接认定产品缺陷。
3. 同范围新增真实操作、场景key、别名与经验按分类模型自动维护，优先复用现有归属，不按每个软件创建重复场景；改变分类轴、拆并既有归属或扩大服务范围再确认。
4. 重复完整成功维护对应operation与父索引的验证日期；同日且没有新事实可无diff，但报告已复核。部分执行不刷新成功日期。
5. 写后从父索引读回条目，核对ID、相对链接、状态、日期与私密信息。已有适用校验器可以复用，不为形式创建后台扫描或新业务服务。
6. 报告实际保存位置与验证范围。写入失败明确报告未保存；没有新事实说明理由，不能以此跳过必要的状态维护。

遵守执行工具的停止、控制权和收尾规则。自动沉淀只维护知识，不自动重跑业务、提交、推送、部署、购买或删除资产，不是后台监控或强制拦截器。

## 私密信息

共享内容不含真实账号、设备路径、动态页面ID、VoiceID、参考音频哈希或完整响应。私有资料也不得保存密码、Cookie、Token、签名URL或可重放凭据。当前服务与唯一声音库通过对应OPS的本机配置发现，不能另建声音真相源。
