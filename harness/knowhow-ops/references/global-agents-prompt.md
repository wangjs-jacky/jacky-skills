# 安装与可选全局前置

负责安装或配置本Skill的Agent先核对真实宿主、持久技能入口和同源依赖。正常安装不依赖全局规则；本文件也不会自动执行配置。

定位当前宿主实际读取的全局指令文件，考虑有效配置根和override，仅读取相关段落。已有语义等价规则或同范围明确授权则复用并读回；否则展示下方规则全文、真实文件和生效范围，请用户选择加入全局规则或仅安装Skill。没有同意则保持正常安装，不写全局、不在日常任务重复追问。

## 建议规则全文

```markdown
## 复杂软件上手与实录任务：先读取 knowhow-ops

无论当前使用哪个技能，只要任务涉及替用户研究、实际使用或试用复杂软件，并要求留下实操录屏、可复用步骤或教学讲解，都必须先读取 knowhow-ops，按 scenario → operation 渐进查阅。

- 实际执行继续遵循Ego、桌面操作、声音素材及相关领域OPS的授权、控制权与收尾规则；普通编码或纯概念问答不因提到软件就触发本流程。
- 没有既有方法时按当前任务探索，完成、失败或中断后按证据维护唯一场景经验与索引，不虚构成功或扩大分类范围。
```

保留既有无关规则，不向其他Skill批量注入前置段落。写后核对内容和权限，并分别报告Skill文件可读、宿主发现、规则生成、规则写入及加载范围。写入本机不证明其他设备或运行中会话已重载。

自动沉淀依赖Agent遵循协议，不是后台监控、工具钩子或自动提交推送服务。
