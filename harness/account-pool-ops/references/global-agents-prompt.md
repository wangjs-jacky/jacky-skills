# 安装与可选全局前置

安装Agent核对本Skill可读、实际全局文件和override。下面规则仅在准确范围授权后合并；创建Skill或提供Key不等于全局文件修改许可。未授权仍可使用Skill，普通操作不重复安装提问。

## 建议规则全文

```markdown
## 平台API密钥：先读取 account-pool-ops

无论当前使用哪个技能，只要任务涉及平台API密钥的保存、检索使用、鉴权验证或替换轮换，都必须先读取 account-pool-ops，并按 platform 及 operation 操作。

- 先检索已有条目，不重复索要已存Key；密钥只进入系统安全存储及授权进程内存，不进入Skill、源码、日志、网页、Git或回复。
- 同平台新增密钥保留旧项，不自动切换默认、轮换池中密钥或跨设备复制；付费生成及其他业务动作仍遵循当前任务授权。
- 完成、失败或中断后按证据维护唯一账号池与操作记录，区分安全保存、鉴权结果和实际业务成功。
```

## 安装验收

分别报告文件可读、宿主发现、规则已生成/已写入/已加载，不互相替代。未获授权时展示全文、准确文件和本机范围，提供一次“启用全局前置”或“仅使用Skill”选择；未答复不写全局。

如果当前CODEX_HOME与持久AGENTS为同一软链接目标，只维护一份真实文件。不改其他规则或声称其他运行会话已重载。
