# 单次模型实测

## 目标与前置

区分Key鉴权、任务受理、生成完成和产物可用，验证一个明确型号的真实调用。收费前以当前区域官方价格、任务数、分辨率及输入输出时长复核预算；原预算为零时先取得明确例外。Key保管授权不扩大收费权限。

## 方法

1. 从账号池选择明确条目和已验证区域，只在授权进程内读取Key，不打印或转存。按对应型号当前官方文档构造最小请求，不把H3-Image与H3视频混为一项验证。
2. 提交前记录精确预算与次数，并用独占本机执行回执防止重复提交。网络结果不明时保留未知，不自动重发收费请求、充值、换Key或换型号。
3. POST创建返回task_id只算受理；检查同一任务最终状态。业务集成可使用官方callback_url；涉及Cloudflare时继续遵循禁止轮询约束，不从临时诊断引入定时查询服务。
4. succeeded后，从带鉴权响应取得结果URL；独立无Authorization的HTTPS下载，拒绝自动转发API凭据。签名URL只在进程内，不存日志或经验。
5. 用ffprobe核对真实编解码、分辨率、帧率、帧数和时长；用ffmpeg全片解码。API宣称时长、usage和真实文件分别记录；抽帧检查画面，但不把抽帧当完整流畅度或循环验收。
6. 本机回执和条目model_checks记录限定结果；素材归原项目。鉴权结果不覆盖模型实测，成功调用不代表所有型号/区域均可用。

## 成功标准

唯一授权任务达到succeeded，产物下载及全片解码成功，确认实际型号与请求规格，并如实披露文件差异。严格时长、透明背景、角色一致性、无缝循环或运行接入有独立要求时分别验收，不因连通成功宣称全部完成。

## 已验证边界

2026-11-16，在明确单次预算内完成一次中国区MiniMax-H3、4秒、768P纯文本测试。一次POST受理、任务成功，下载768×768 H.264/24fps文件，全片解码通过；usage为4输出秒。文件107帧、4.458333秒，严格4秒文件时长检查未通过，供应商原因未知，未重生成或裁剪。该证据仅覆盖文生视频生成与解码；参考图一致性、透明化、无缝循环及运行接入须独立验证。实际账单未查，不把按单价测算视为扣费核验。具体任务、授权和证据仅归本机local及原项目。
