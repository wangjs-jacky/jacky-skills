# 安装与全局前置

安装本 OPS 时检查旧 web-search 兼容入口和当前宿主的可发现目录，保持同一源码。普通使用不重复安装确认。

建议加入实际宿主全局指令的规则全文：

> 无论当前使用哪个技能，只要任务涉及网络搜索、查看站点热点或推荐、发现作者或系列内容、读取网页与公开讨论，都必须先读取 web-search-ops，按 site 及目标 operation 选择已有路径；实际浏览器操作仍先读取 ego-ops，再由 ego-browser 执行。纯本地文件搜索、代码中的查找和不访问网络的讨论不触发此规则。

安装 Agent 先核对真实持久全局文件、范围和已有授权，再展示完整规则。已有同范围授权时去重合入并读回；没有时只请求一次明确选择，未答复就保持正常安装和按需使用，不写全局规则。

分别报告 Skill 文件与入口已保存、宿主是否发现、全局规则已生成/已写入/已加载、业务是否实际验证。复制或链接不会自动执行本交互，不承诺旧会话热加载。跨设备复制与自动提交/推送不属于安装授权。
