# 站点目录

按目标挑选入口。浏览器详情在 Ego OPS 是唯一正文；此目录只保存读取条件和来源导航，不能把索引命中当成业务成功。未列站点可先查 Ego 的站点总索引，按当前授权探索后补入口，不预建平台全部能力。

| site / 稳定 ID | 名称 | 何时读取 |
|---|---|---|

| [douyin](douyin/index.md) | 抖音 | 热榜、搜索发现、精选、AI 搜索、作者/话题 |
| [xiaohongshu](xiaohongshu/index.md) | 小红书 | 笔记搜索/筛选、作者、正文、评论、收藏线索 |
| [xiaoyuzhou](xiaoyuzhou/index.md) | 小宇宙 | 节目/单集公开索引发现与单集详情 |
| [xueqiu](xueqiu/index.md) | 雪球 | 社区热帖和热股榜 |
