# 微信公众号

## 按目标选择

已有公开链接用 read-public-article-source 或 read-public-photo-article。正文和轮播照片是不同区域；未登记全量公众号站内搜索。

## 浏览器目录来源

按当前安装目录定位 ego-ops，再读取 references/sites/wechat-public-articles/index.md；选中后才展开相应 operation。也可用本 OPS 的 catalog list --site wechat-public-articles 查询当前元数据，get 精确复合 ID 读取原正文。源目录增加同类案例后这里无需手抄步骤，历史验证日期继续按 Ego 原记录解释。
