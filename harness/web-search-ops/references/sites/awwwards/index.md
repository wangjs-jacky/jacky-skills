# Awwwards

## 按目标选择

沿 browse-recent-award-references 读取获奖列表和详情，核对日期、作者和真实官网。获奖日期不等于上线日期。

## 浏览器目录来源

按当前安装目录定位 ego-ops，再读取 references/sites/awwwards/index.md；选中后才展开相应 operation。也可用本 OPS 的 catalog list --site awwwards 查询当前元数据，get 精确复合 ID 读取原正文。源目录增加同类案例后这里无需手抄步骤，历史验证日期继续按 Ego 原记录解释。
