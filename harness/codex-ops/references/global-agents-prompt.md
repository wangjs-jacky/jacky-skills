# 安装 Agent 提示词：Codex OPS 全局前置

完成正常安装，并建议用户启用下方规则。读取本文件、确认能力分类或安装 Skill 不构成修改全局指令的授权。

## 安装流程

1. 核对设备与执行机，按当前目录或注册表确认 `codex-ops/SKILL.md` 可读；保留旧兼容入口时同时安装本库。额度操作需要 `codex-quota`，不要复制其脚本。
2. 定位当前宿主真正使用的全局指令文件；Codex 核对有效配置目录、`CODEX_HOME` 与 `AGENTS.override.md`。区分持久配置、隔离会话和项目范围，只读取相关段落，不打印完整文件。
3. 已有等价规则时报告已配置；已有同内容、同范围授权直接复用。否则展示下面全文、实际文件和范围，提供“加入全局规则（推荐）”“仅安装技能”选项，等待明确同意。
4. 同意后安全备份、保留原有内容和权限，合并去重并读回新增段落。说明实际加载证据；不宣称其他运行中会话已重载。
5. 拒绝或无答复不阻塞正常安装，不写全局、不在普通任务反复询问。纯复制或链接不会自动执行交互。

## 建议写入的完整规则

```markdown
## Codex 使用与运维：先读取 codex-ops

无论当前使用哪个技能，只要任务涉及 Codex 自身的安装升级、环境迁移、运行配置、全局 AGENTS 规则、技能安装同步与发现排障、认证或代理及连接排障、剩余额度查询，都必须先读取 codex-ops，并遵循对应 capability 及 operation。

- 从当前环境的技能目录或安装注册表定位 codex-ops/SKILL.md，按索引仅读本次能力及 operation；普通编码任务不因使用 Codex 而触发本规则。
- 执行途中发现属于上述范围时，在继续相关操作前补读；本轮已读取且仍适用的内容直接复用。
- 以当前用户指令、真实宿主、版本和有效配置复核历史经验；涉及当前官方能力时核对官方资料，执行工具仍遵循自身授权与收尾规则。
- 没有对应经验时按知识扩展规则处理，不虚构历史成功；Skill 缺失或不可读时明确说明，继续不受影响的工作。
- 完成、失败或中断后按证据自动写回，区分文件已保存、宿主已加载和实际请求成功；不保存凭据或完整会话日志。
```

本规则依赖宿主加载和 Agent 遵循，不是工具拦截钩子。其他领域 OPS 同时适用时分别读取所需经验、维护唯一归属，不能相互循环调用。
