# 用量

能力：`usage`。当前范围为 Codex 会话日志记录的剩余额度、窗口与重置时间。

## 共用事实与执行归属

- 查询实现和字段解释唯一归属于 `codex-quota`；通过技能目录或注册表定位其 `SKILL.md` 和脚本，不复制实现。
- 日志最后一次额度观测不等于实时服务查询。重新扫描不会向 OpenAI 刷新余额；未知、过期、读取不完整分别报告。
- 当前隔离配置根、持久默认目录和其他账号的记录分别归因，不拼接窗口。目录不同不能单独证明账号不同，读数相同也不能证明账号相同。
- 订阅额度、API 账单、任务 token 预算、连接计数是不同指标；没有官方依据时不能推导统一连接上限。
