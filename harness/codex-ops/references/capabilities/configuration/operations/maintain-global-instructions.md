# 维护全局 AGENTS 规则

## 目标与前置

将用户确认的准确规则合并到确认过的全局文件。安装 Skill 与修改全局指令是不同范围；已获同内容和目标的授权直接复用。

## 流程

1. 区分持久配置根与隔离会话根，核对 `AGENTS.override.md` 等实际加载入口；按宿主证据判断影响范围。
2. 只检查目标规则和文件元数据，不输出整个文件。全局指令中可能含历史秘密，不能认为 Markdown 可以公开展示。
3. 查找语义重复或冲突。需要新授权时展示规则全文、实际文件和范围，获得答复后写入。
4. 在用户私有位置备份，备份目录使用 `0700`、文件使用 `0600` 或平台等价权限；保留目标原权限。写前复查内容、文件身份与软链接目标，发现并发修改时重新合并。
5. 只追加或定点修改授权段落；读回新增部分，确认无重复、原内容完整、无关约束保留。
6. 分别记录已保存和已加载。新运行按宿主机制加载，现有会话只有收到相应指令或其他确切证据才可报告已更新。

## 成功标准

所有明确目标文件包含同一已批准规则，原内容和权限保留，有私有备份且无重复；各文件结果分别报告。

## 坑与恢复

写入未加载的根目录不能改变当前会话；存在 override 时不能无条件承诺基文件生效。恢复只撤销本次段落并保留后来变化，备份不能进入可分享仓库。
