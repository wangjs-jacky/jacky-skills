# 安装或同步技能

## 目标与前置

让目标宿主从明确的事实源读取所需 Skill 及依赖。确认设备、宿主、安装作用域和内容来源；需要远端时先走 SSH 执行 Skill。

## 流程

1. 读取目标 Skill 的安装说明与已有注册信息；按当前宿主确认目录，不能从另一机器复制固定路径。
2. 同机优先复用唯一源的安装链接；同名入口已指向其他来源时报告冲突，不能直接覆盖。使用安装器先查当前版本和子命令帮助。
3. 只安装必要依赖：`codex-env-config` 需要本库；本库查询额度时需要 `codex-quota`。依赖缺失时说明缺口，不复制一份脚本长期维护。
4. 跨机器同步先筛出可分享文件，排除 ignored 私有经验、备份、认证及无关缓存；对共享内容解引用或在目标重建有效链接。机器专属经验按授权单独适配。
5. 读回目标 `SKILL.md`、链接真实来源和相关参考文件；核对 frontmatter、依赖和相对引用。重命名后用 `lstat` / `readlink` 检查旧安装入口；跟随链接的存在性检查会把 dangling 软链接看成不存在。再通过宿主目录表或当前加载证据确认发现情况。
6. 安装说明含全局提示词时展示其完整规则和实际目标文件，按已有同范围授权或新答复处理；没有答复保持正常安装，不写全局。

## 成功标准

目标入口和依赖可读、来源一致、没有悬空链接或同名冲突；宿主发现是否已取证单独报告。全局规则状态明确为已生成、已写入或已加载。

## 坑与恢复

安装器注册成功不证明另一隔离会话可读；插件单独分发兼容入口时要注明独立依赖。回退仅删除本次创建且身份未变的链接，不能删除共享源或其他安装。

本机安装器曾在源码目录改名后报告卸载成功，但跳过已失效的旧软链接；注册信息与文件系统结果须分别核对。只在旧入口仍为软链接、目标与本次改名前来源完全一致且确实失效时清理链接本身，不跟随删除共享源。卸载也可能同时移除注册项，后续取消注册返回“未链接”时先核对现状，不能据此重建旧项。
