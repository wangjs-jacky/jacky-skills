# 比较并定位访问路径

## 目标与前置条件

区分请求实际经过的路径，并据可比证据选择保留或调整入口。已知目标地址、当前客户端及可用代理；不因测量需要复制用户凭据或改变全局网络设置。

## 执行判断

对同一目标做用户动作触发的一次性直连/显式代理对照，记录DNS、TLS、首响应及状态。登录API与WS可使用仅本次的受限测试会话，认证材料保持在进程内并清理测试对象。

浏览器任务按ego-ops→ego-browser读取当前实际代理控制状态，只提取已知目标路由；不导出整份PAC或磁盘profile。有限样本快慢反转时保留不确定性，不能把某一次更快写成全局关代理的依据。

私网ping快不证明Web已接入：备用域名/端口还要对齐HTTPS、回调、Cookie和Origin，不能借旁路跳过原网关。接入身份转identity，资源等待转resource-delivery。

## 成功标准

当前路径可解释，单次样本/条件与未知明确，给出有证据的保留或调整选择。诊断可以完成但入口变更未实施；两者分别报告。

## 坑与恢复

错误地用WS连接存续总时间代替升级首响应会夸大握手耗时。代理差分中改变登录/缓存条件会混入其他变量。需要变更时只调整已授权目标规则并保留回退，不能重置整套代理。

## 证据边界

2026-11-08，实体外部电脑的实际扩展路由、匿名首页、已登录API与WS升级的有限对照已取得；两轮匿名快慢反转，选择保留原入口/代理，私网只有传输探针而无新应用入口。诊断与当前选择完成，不代表冷加载修复或长期网络排名。
