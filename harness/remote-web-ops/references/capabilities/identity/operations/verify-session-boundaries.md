# 验证身份与退出边界

## 目标与前置条件

验证受保护服务登录后的请求可用，退出后原身份不能继续取得私有数据。沿用已有账号/应用授权；新增成员或身份关联属于独立授权范围。

## 执行判断

匿名页面、API和版本资源分别取证；登录后检查应用身份与真实原生API，不将网关身份页当作全部上游通过。原生Cookie/launch凭据如需桥接仅在服务端处理，HTTP与WS的101和非101响应均检查泄漏。

用同一次中央登录建立应用绑定，再退出该绑定并确认旧应用权限及中央会话失效。另一设备/另一次登录的有效会话不能当作同一会话未注销。WS连接关闭交由realtime对应机制核对。

## 成功标准

匿名私有数据拒绝、登录请求可用、原生凭据不外发；同一次绑定退出后旧API及网络资源请求重新要求身份。缓存中的静态程序不会远程抹去，业务权限失效单独证明。

## 坑与恢复

用户相同而session不同仍可能是独立有效登录。身份头伪造、错误Origin及晚到响应应按当前网关验证；失败时保留明确错误，不通过公开原生端口绕过认证。

## 证据边界

2026-11-08，受保护第三方Web服务的临时成员SSO、真实API、匿名拒绝、凭据隔离、同会话退出及旧权限失效通过；协议测试对象已清理，外部浏览器身份API成功。未覆盖自然长时到期、所有身份提供商或任意多租户隔离。
