# 安装 Agent 提示词：remote-web-ops 全局前置

此提示词随 `remote-web-ops` 分发。完成正常安装，并建议用户将下方规则加入当前 Agent 的全局指令；阅读或保存本文件不构成修改全局配置的授权。

## 给安装 Agent

1. 核对目标设备和当前执行机，从技能目录或安装注册表确认 `remote-web-ops/SKILL.md` 可发现、可读取。不要使用创建者机器的路径。
2. 找到当前 Agent 真正使用的全局指令文件；Codex 考虑 `CODEX_HOME` 和 `AGENTS.override.md`，其他 Agent 按其机制处理。区分持久用户配置、隔离会话与项目文件，不把项目 `AGENTS.md` 当全局配置。只读取和展示相关段落。
3. 已存在语义等价且有效的规则时报告已配置，不重复插入；已获相同内容与范围的授权时直接复用。
4. 否则向用户展示下面规则全文、实际目标文件和生效范围，说明建议原因，并提供“加入全局规则（推荐）”“仅安装技能”两个选项。使用宿主可用交互；等待明确同意后才能写入，沉默或预选不等于授权。
5. 同意后保留原有内容，按语义合并去重；有冲突先说明，不覆盖已有约束。读回相关段落，报告位置和宿主的加载时机，不能声称其他正在运行的 Agent 已重载。
6. 拒绝或没有答复时保留正常安装，不写全局规则、不在日常任务重复追问。无交互安装可保留建议供后续配置。

## 建议写入的全局规则

只将以下代码块写入用户确认的文件。生成此提示词时先替换全部变量。

```markdown
## 远端Web服务部署与访问 任务：先读取 remote-web-ops

无论当前使用哪个技能，只要任务涉及远端Web服务的部署、访问通道配置、身份接入、资源加载性能或实时连接排障，都必须先读取 remote-web-ops，并遵循对应 capability 及 operation。

- 从当前环境的技能目录或安装注册表定位 remote-web-ops/SKILL.md，按索引仅读本次对象与 operation。
- 执行途中发现属于此范围时，在继续相关操作前补读；本轮已读取且仍适用的内容直接复用。
- 实际执行遵循对应工具 Skill 的控制权、授权和收尾规则；前置知识不会替代执行能力。
- 没有对应经验时，按 OPS 的知识扩展与分类确认规则处理，不虚构旧经验；技能缺失或不可读时明确说明，并继续不受影响的工作。
- 完成、失败或中断后，按证据与写回协议自动维护经验，区分已验证结果与未完成项。
```

## 生效边界

这是安装 Agent 的指引和可选全局规则。纯复制/链接安装不会自动执行交互；该规则依赖 Agent 遵循指令，不是工具执行器的强制拦截钩子。

## 安装收尾验收

安装 Agent 必须检查目标 OPS 的全局前置入口，不能以文件复制或链接成功代替规则配置。已有明确的同范围授权时自动合并、去重并读回；没有授权时展示规则与目标文件并请求一次选择。分别报告 Skill 已安装、规则已生成／已写入／已加载，未启用时说明原因。浏览器 OPS 的触发范围必须覆盖每次真实网页操作，不能弱化为“需要沉淀时可调用”。此流程依赖安装 Agent 执行，不宣称普通复制或链接自带安装钩子。
