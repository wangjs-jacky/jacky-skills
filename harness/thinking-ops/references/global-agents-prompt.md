# 给安装 Agent

先完成正常安装，再检查目标宿主真正使用的全局文件、override 与等价规则。不把项目指令当用户级配置，不展示无关段落或秘密。

已有相同范围授权或等价规则时复用、去重、读回。否则展示以下规则全文、实际文件与作用范围，只问一次“加入全局规则”或“仅安装技能”。无答复不写入，不阻塞安装；普通使用跳过安装交互。

```markdown
## 困惑与思维方法选型：先读取 thinking-ops

无论当前使用哪个技能，只要用户希望针对自己的困惑选择思维方法、换角度获得灵感，或借思维框架梳理难题与取舍，都必须先读取 thinking-ops，并按困惑场景 scenario 及 operation 渐进读取。

- 从技能目录或安装注册表定位 thinking-ops/SKILL.md，只读命中场景和方法；本轮已读且适用的内容直接复用。
- 推荐合适方法并实际运用；信息充分就分析，只为可能改变判断的缺项提问，对话式方法一次只问一个问题。
- 直接执行、普通事实问答和翻译不因出现“选择”或“问题”就进入思维问诊；用户明确调用其他专用 Skill 时保留其目标与流程。
- 分清事实、假设、灵感和条件建议；研究与业务行动遵循工具和既有授权，方法建议不授权外部行动。
- 完成、失败或中断后按证据维护方法经验、必要私有反馈和索引；无反馈不记为满意，不虚构验证日期。
- Skill 缺失或不可读时说明并继续不受影响的工作；改分类或扩大范围前再确认。
```

同意后保留原内容与权限，备份、合并、去重、读回。分别报告技能可读、宿主是否发现，以及规则已生成/已写入/已加载；不能因写入成功就声称运行中宿主已经重载。

未获授权时保持规则仅生成。此协议不是后台服务、安装钩子或工具拦截器。
