# 困惑场景索引

多个场景都命中时，读[方法选型与灵感](../select-and-use.md)，先处理眼前瓶颈。

场景沿用已确认分类，各子索引中的方法持续补充。下列方法名是当前导航线索，不是固定能力清单；没有合适条目时，先围绕问题分析并按[知识协议](../knowledge-schema.md)吸收或提炼新方法。

| ID / scenario | 当前困惑与用途 | 下一层入口 | 关键避用条件 |
| --- | --- | --- | --- |
| thinking-ops.scenario.clarify / clarify | 说不清卡点、目标或问题含义 | [问清问题](clarify/index.md)：苏格拉底 | 已有清晰任务不强行问诊 |
| thinking-ops.scenario.learn / learn | 缺概念、实例规律、领域地图或事实 | [学习](learn/index.md)：解释、拆解、纵横、核查 | 价值取舍不能仅靠补资料解决 |
| thinking-ops.scenario.solve / solve | 目标和事实大体清楚，但没有好解法 | [解决问题](solve/index.md)：多视角、重推、跨域 | 关键事实未明时先核查 |
| thinking-ops.scenario.decide / decide | 方向间难选，或缺现实反馈 | [决策](decide/index.md)：钢人、实验 | 不知道想要什么时再看 self |
| thinking-ops.scenario.self / self | 优势、能量、价值和人生方向不明 | [认识自己](self/index.md)：天赋、人生设计 | 不因技术选择就推断人生迷茫 |

方法可以来自资料和实践，可信度与日期以 operation 为准；来源核对不等于效果验证。
