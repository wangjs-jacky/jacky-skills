# 事实核查

目标是明确哪些可信、哪些需要修正，不能用幻觉核查幻觉。尽量取得原说法、发布日期与上下文。

## 怎样做

1. 拆分外部可验证事实、由其推出的结论、价值判断，提取真正影响用户判断的主张。
2. 对事实实际查来源、样本、时间、口径和完整上下文，优先原始数据与一手材料。给来源链接和核对日期。
3. 逐条标为已证实、基本成立但需收窄、存在争议、证据不足或明显错误，并解释依据。找不到证据不自动判假。
4. 假定相应事实成立，继续审推理：是否推出该结论、隐含什么假设、是否混淆相关与因果、是否漏掉替代解释，以及成立和失效条件。
5. 给可信部分、必要修正、关键漏洞、补强后的合理版本和当前可相信的程度。

## 成功与常见失配

每个重要事实状态都有可追溯依据，推理问题和价值偏好单独说明。不确定性不足以量化时不编置信百分比。

不能联网或无法访问原材料时说明实际可核范围；可以检查推理，不能称事实已证实。多篇互相转载的文章不是多份独立证据。遇到时效变化记录版本，不沿用旧结论。
