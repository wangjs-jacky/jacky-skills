# 横纵分析法

先明确研究对象、要支持的判断和范围。截止日期写实际执行日期；轻量地图与深度研究按任务需要选择，不默认万字。

## 怎样做

1. 纵向整理诞生背景、需求、推动者、关键转折、成功与失败，解释早期选择留下的能力、路径依赖和包袱。
2. 横向选择真正可比的对象并说明理由，用同一维度、时期、单位和条件比较，解释用户为何选择或放弃它。
3. 合并两轴，判断既有能力和约束如何影响未来；提出三种有机制差别的可能路径，逐一给前提与预警信号，不编概率。
4. 重要结论就近标来源和日期，优先一手资料；区分事实、推断、观点。资料冲突并列呈现，缺证据写暂未核实。
5. 先给支持当前困惑的结论，再给关键时间线、可比表、必要分析与待确认问题，细节随请求展开。

## 成功与常见失配

产出有来源的时间线、可比对象、统一维度和条件判断；资料覆盖不足时报告研究边界，不称全面研究。用户能否据此建立理解另待反馈。

避免把不同套餐、年份或口径硬比；未来路径是推演，不是已证实事实。不能联网时仅整理用户提供材料或列研究计划，不声称完成截至当天的研究。
