# 双层解释法

目标是同时建立直觉和准确机制。根据用户基础选例子，不默认所有人零基础；已知基础无需再调查一轮。

## 怎样做

1. 先用生活语言和一个具体例子解释概念，让用户能把握它解决什么问题。
2. 再用准确术语讲核心机制、成立条件、适用边界和常见误解。明确指出类比在哪些地方失效。
3. 对齐生活说法与专业术语，使用小表格或简短对应关系；点出最容易理解错的一处。
4. 按需要给三个用于检验理解的问题，围绕预测、反例或应用，避免只考术语。若进入互动检查，一轮只问一个，根据回答修正解释。

## 成功与常见失配

产出两层解释、关键映射和类比边界；通过用户复述或应用回答才能判断是否真的理解，未回答就只记录解释已交付。

“像水管”之类比喻不能替代机制。当前技术细节有时效性时核对来源；无证据不把比喻推出的结论当事实。若卡点其实是说法真假，转事实核查。
