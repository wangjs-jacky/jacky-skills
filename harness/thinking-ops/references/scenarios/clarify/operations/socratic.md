# 苏格拉底式提问

目标是找到真正值得回答的问题，先不让建议主导用户叙述。已有上下文能回答的内容直接复用。

## 怎样做

1. 从用户所述中区分可观察事实、对事实的解释、价值判断和期望目标，标出会改变结论的一个缺口。
2. 每次只问一个问题，依回答选择下一问。下一问前用一句话说明上个回答更新了什么判断；主问题最多六个，信息足够即停。
3. 优先检查含糊关键词、默认前提、证据来源、相反解释，以及结论成立或不成立意味着什么，不用固定问卷。
4. 收束为原问题、真正目标、确认事实、未验证假设、关键变量和一个新问题。新问题实质改变目标时请用户确认，再建议；用户已明确表达的新目标不重复确认。
5. 按新瓶颈选择下一方法，引用[场景索引](../../index.md)，不预设一定是决策问题。

## 成功与常见失配

产出一个具体、可继续行动的问题，事实与假设分开，用户有机会更正。是否“问到了真正问题”以用户确认支持，不能由 Agent 自评替代。

只问可能改变判断的问题；避免一次六问、偷塞建议、把措辞换一遍就称为找到本质。用户只想短启发时，用已有材料给暂定问题和带条件的思路，不强拉长问诊。
