# 用最小实验替代空想

本操作默认产出实验设计，实际执行遵循用户授权。不能把计划、试了几天、样本不足或主观喜欢混写成因果结论。

## 怎样做

1. 提取决定背后最需要验证的三个假设，选出最可能改变结论的一个，说明理由。
2. 设计在用户可接受周期和资源内完成的最低成本验证；用户未限定时可以七天为提案，标明假设，不伪造预算承诺。
3. 写清具体动作、时间与资源、观察指标、什么结果支持继续、什么结果要求停止，以及结果带来的新信息。开始前确定标准，不能事后改线合理化。
4. 说明哪些变量尽量固定、哪些混杂无法排除。不能合理量化时使用可观察的质性证据，不编精确阈值或虚构样本。
5. 给明天或下个可用时段就能做的第一个动作，具体到对象和交付物，不只说“做调研”。

## 成功与常见失配

计划能直接执行、有成本和时间边界、继续/停止条件，并确实回答关键未知。“计划完成”与“实验执行和结果验证”分别记录；执行未发生不能刷新实际效果日期。

预售、联系他人、购买、部署等需要真实业务授权，不因设计实验而自动执行。结果不清时保留无定论及原因，不强行宣布赢家。技术比较可交相应实验 Skill 执行，不在这里搭整套平台。
