# 专家会诊

这是一个 Agent 运用互补视角的分析方法，不代表三位真人或三个独立模型已评审。输入包括问题、目标、事实与现实约束；关键缺项只问一个。

## 怎样做

1. 选择三种真正互补的专业视角，说明各自看什么、为何必要。例如用户价值、交付成本和长期运维比三个相近职位更互补。
2. 各视角分别重定义问题，提出路径、指出其他视角可能遗漏的风险，并说明什么证据会使自己改判。
3. 让视角相互质疑，分清共同事实、真正分歧以及分歧背后的假设。无分歧时检查是否选得太近，不制造戏剧性争吵。
4. 综合给推荐路径、适用条件、最大风险、退出条件和第一步。共识不能代替证据，少数视角的关键约束不能被投票抹去。

## 成功与常见失配

产出互补视角、可解释分歧及能回应主要约束的综合建议。不能以观点数量或一致赞同证明方案正确；现实效果待验证。

不模仿真实人物、不编引语，不把“某专家认为”包装成外部证据。若用户确需独立评审，指出当前分析范围，按另行授权使用相应流程。
