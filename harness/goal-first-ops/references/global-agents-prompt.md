# 安装 Agent 提示词：Goal First 项目目标前置

此提示词随 `goal-first-ops` 分发。正常安装后建议启用以下全局规则；创建 Skill 或保存本文件不等于授权修改全局指令。

## 给安装 Agent

1. 核对目标设备和宿主，从技能目录或注册表确认 `goal-first-ops/SKILL.md` 可读。配合 `goal-first` 时核对其安装来源，不硬编码创建者机器路径。
2. 找到当前宿主实际使用的全局指令文件；Codex 区分 `CODEX_HOME` 与 `AGENTS.override.md`，不能把项目 AGENTS 当全局配置。只读取和展示相关段落，避免暴露无关私有配置。
3. 已有等价规则时不重复写入；已有相同范围的明确授权时直接复用。否则展示下方完整规则、真实目标文件和生效范围，请用户选择“加入全局规则（推荐）”或“仅安装技能”。没有答复不修改全局文件，也不阻塞正常安装。
4. 同意后保留原内容，合并去重并读回。分别报告 Skill 可读、全局规则已生成或已写入、宿主是否实际加载；不声称其他运行中的会话已重载。

## 建议写入的全局规则

```markdown
## Goal First 项目任务：先读取 goal-first-ops

无论当前使用哪个技能，只要使用 goal-first、维护其目标工作区、接续其中的任务或复盘项目知识，都必须先从技能目录或安装注册表读取 goal-first-ops，按 project 及 feature 读取目标的报告、过程和已有经验；本轮适用内容可复用。

完成、失败或中断后，按证据自动更新 goal-first-ops 实际目录下 projects/<project>/features/<feature>/ 的目标内容并同步导航。feature 是目标文件夹，需求、报告、过程、产物、证据与方法集中保存在此；不建立 experience.local.md 或独立实例经验层，不虚构成功。任务状态和授权保持唯一来源；记录维护不扩大执行权限。

没有经验时按既定分类从真实任务补充；Skill 缺失或不可写时说明缺口并继续不受影响的工作，不静默另建知识副本。
```

## 安装收尾

核对 Skill 入口、默认知识根和 `goal-first` 的配合读取。没有全局授权时展示规则和真实目标文件并请求一次选择；拒绝或没有答复保留正常安装，普通使用不重复询问。本提示词是 Agent 的配置指引，复制或链接安装不会执行交互，也不是宿主的强制工具钩子。
