# Goal First OPS

以 **project → features** 组织。`feature` 是目标档案文件夹：目标记录、必要资料和过程保存在 `projects/<project>/features/<feature>/`，开发工程独立存放。读取、执行、核验后更新这个目标的既有材料，保持一个权威来源。分类依据见[目标模型](references/ops-model.md)。

## 开始前

1. 从技能目录或注册表解析本 Skill 的真实目录，作为唯一默认资料根。
2. 读 `projects/index.md`，按项目名或别名命中 project，再读 `projects/<project>/index.md` 找到 feature。新安装无索引时按空库处理，首次真实记录从[空索引模板](assets/projects-index.template.md)建立，不覆盖已有内容。
3. 读 feature 的 `index.md` 和本次必要的报告、需求及过程。feature 可包含分任务；其目录本身就是 Goal First 的目标工作区，不再外套 `workspace/`。
4. 以当前用户指令、来源、版本、授权和实际证据复核记录。已有明确目标与执行授权继续有效；存储位置和记录维护不扩大业务权限。

## 目标内怎样保存

- `index.md`：简短目标入口，优先指向核心报告、当前产物与接续依据；涉及开发时说明工程实际路径、当前源码入口及 Git 仓库或实际状态。简单目标可以直接在本页记录内容。
- 核心报告：把问题、实际过程、发现、判断及适用条件讲清楚，是读者的主要阅读材料。
- 需求、重要过程、设计、必要输入、交付快照与验收证据：按实际用途保存在同一 feature，文件存在后再建立导航。可持续开发的工程源码、依赖和构建工作目录必须置于独立工程目录，默认使用 Git 管理，不放入 `projects/`；目标只引用工程，不维护另一份开发副本。位置遵循用户的工程存储约定。
  普通业务工程默认与 Skill 仓库分开；维护对象本身就是 Skill 仓库时沿用其既有工程位置，仍不把源码放进目标档案目录。

- 可复用做法、失败与修复：在对应报告或目标内文档更新，不另建平行的 operations、local 或本机实例索引。
- 不生成或依赖 `experience.local.md`、`instance.md`。本机路径和环境条件随所属目标记录；跨目标事实放项目入口，其他目标通过链接引用。

完整职责和证据处理读[记录与写回协议](references/knowledge-schema.md)。必要的单 HTML、导出包或源码附件可作为标明版本的交付快照保留，不作为继续开发的位置；非开发目标不必建立工程。模板只是可选写法，不要求每个目标建立固定文件套餐。

## 执行与接续

`goal-first` 负责目标确认、任务契约和明确执行选择；本 Skill 负责目标档案的组织、读取与持续维护。保留已有授权、任务状态和专业 Skill 的执行边界。任务状态按既有 Goal First 契约只在实际任务入口维护，项目总览链接它，不复制第二份状态表。

浏览器、发布和平台等领域能力继续遵循其对应 Skill/OPS；当前 feature 引用权威规则，保存自己的实际输入、结果与证据，不复制整套工具手册。

## 每轮收尾

复核本轮证据，按[写回协议](references/knowledge-schema.md)更新同一 feature 的报告、重要过程或方法，修正过时结论，并同步目标及项目导航。只记录影响目标、结论、接续或复用的重要真实变化；无新增时说明无需写回，不为每句对话增加文件。

迁移、文档检查、局部执行和完整业务成功分别陈述。没有对应成功证据，不刷新成功日期；作者自查不能代替用户对报告或设计的认可。报告实际更新位置和未完成项。

## 本机与迁移边界

`projects/` 连同索引、报告、过程、证据均只保留本机，由 Git 忽略；Git 维护 Skill 规则、模板和元数据。凭据、私钥、Token、Cookie、完整私有配置与无关日志不得写入目标档案；对外分享需另行确认实际内容范围并脱敏。

旧 `references/projects/`、`local/` 或 operations 路径若仍有历史消费者，只作为兼容跳转；新记录从 `projects/<project>/features/<feature>/` 进入，不恢复旧的本机经验层。移动后核对引用，保留真实历史与唯一实际目录。

## 安装时

安装或配置本 Skill 时读[全局触发提示词](references/global-agents-prompt.md)，按既有同范围授权或用户选择处理全局前置。普通使用不重复安装交互；复制文件不代表宿主已加载。
