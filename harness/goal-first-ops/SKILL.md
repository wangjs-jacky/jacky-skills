# Goal First OPS

以 **project → operations** 组织目标驱动项目的长期知识。默认读写本 Skill 实际目录：项目共用事实进项目档案，单个目标的做法、决策、证据和坑进 operation；不在各工作区或 Worktree 建副本。分类依据见[分类模型](references/ops-model.md)。

沉淀内容只保存在本机，不提交 Git：`references/projects/`（包括动态项目索引）、`experience.local.md` 与 `local/` 均被忽略。Git 只保存 Skill 规则、元数据和空索引模板，不用强制添加绕过忽略规则。

## 安装时：建议启用全局前置

安装或配置本 Skill 的 Agent，先读[全局触发提示词](references/global-agents-prompt.md)，展示完整规则、真实全局文件与范围，获得明确授权后合并；已有同范围授权直接复用。普通使用跳过安装交互。复制或链接安装不会自行修改全局规则。

## 开始前：渐进读取

1. 从技能目录或注册表解析本 Skill 的真实位置，作为默认唯一知识源。存在 `experience.local.md` 时只读当前项目的实例入口；用户明确指定其他知识根时，记录唯一映射，不双写。
2. 读取本机的 `references/projects/index.md`，用用户当前说明、已有项目标识和工作区上下文命中 project；只有首次归类、歧义或扩展时才读分类模型。新安装没有该索引时按空库处理，首次写回才从[空索引模板](assets/projects-index.template.md)创建它，保留已有索引与项目内容。
3. 仅读该项目 `index.md` 和本次 operation。分支、Worktree、会话和一次任务不另建项目；不能确认两个来源属于同一项目时先核对，不擅自合并。
4. 以当前目标、版本、授权和输入复核旧经验。无条目时按已确认分类从真实任务补充，不把候选做法当成旧成功，也不遍历其他项目猜答案。

## 使用与执行边界

- `goal-first` 管理目标澄清、任务安排、执行选择和工作区协作；本 Skill 只管理知识。独立复盘可直接使用本 Skill，不必重启一轮目标拆解。
- 当前任务的原始产物、确认与授权、完整验收报告和唯一任务状态仍在工作区。OPS 保存复用所需的摘要、适用条件与来源，知识可信度不等于任务进度。
- 领域 Skill/OPS 继续负责实际执行及其专门知识。项目档案记录项目选择和组合条件，引用领域权威入口，不复制浏览器、发布、平台等整套手册，不形成相互调用循环。
- 读取经验和知识写回不授权额外任务、远端变更或发布。目标尚未确认时不借沉淀设计方案、创建工作区或执行任务。

## 自动沉淀与收尾

每轮完成、失败或中断后，读[知识格式与写回协议](references/knowledge-schema.md)，执行 **复核证据 → 提炼并写回唯一归属 → 同步索引 → 检查引用与隐私 → 报告**，不等用户另说“记录一下”。

- 按实际目标和成功条件判断 `documented`、`partial`、`verified`；仅完整验证维护 `last_verified`，重复成功也维护实际日期。未执行、失败或中断不刷新成功日期。
- 新的真实项目和同类 operation 按既定标准自动补充。改变分类轴、拆并既有归属或扩大服务范围时再确认。初始空索引不妨碍使用，不为填满结构预建项目或操作。
- 当前证据推翻旧经验时修正或降级，保留必要历史。没有可复用新事实时说明原因；同日同条件的重复核对可以无文件变更。
- 默认写回本 Skill；只读或校验失败时明确未沉淀，提供可应用修改或请用户指定唯一可写源，不静默改存工作区。

报告实际结果、写回文件、证据覆盖范围和未完成项。自动沉淀依靠 Agent 遵循本协议，不是后台监控、工具拦截、自动提交或推送服务。

## 私有信息

项目可分享事实先脱敏；机器路径、工作区与证据位置映射保存于本 Skill 内 ignored 的 `experience.local.md` / `local/`。凭据、私钥、Token、Cookie、签名 URL、完整私有日志或会话不得进入任何知识文件。共享文件不链接私有路径；知识根目录变化不构成分享或上传授权。
