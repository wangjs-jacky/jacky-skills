# Cloudflare OPS

以 **capability → operations** 组织长期经验，应用实例引用共享知识。沿用 ego-ops 的渐进读取、当前证据复核、验证后写回和隐私分离：ego-ops 的稳定主键是 site，这里的稳定主键是 Cloudflare 能力。

## 安装时：建议启用全局触发

负责安装或配置本 Skill 的 Agent，先读取[全局触发配置提示词](references/global-agents-prompt.md)。向用户展示建议写入的规则、实际目标文件和生效范围，询问是否加入全局 `AGENTS.md`；获得明确同意后再写入。用户已明确授权相同内容与范围时沿用授权，不重复询问。

这项交互仅在安装或配置全局触发时进行；普通 Cloudflare 任务继续下面的流程。仅运行文件复制/链接安装命令不会自动执行此交互，需要安装 Agent 主动读取提示词。

不按应用复制平台规则，不按环境复制 operations。只为实际场景增加操作；多个操作共同需要的事实提升到能力档案。实例索引缺失时可正常使用共享知识，不预建空应用。

## 用户约束：禁止 Cloudflare 轮询

2026-10-14 用户明确要求，覆盖页面、Worker、Durable Objects、执行桥接、SDK 适配和运维脚本：

- 禁止定时、递归超时、sleep 循环、周期 Alarm/Cron 反复查询任务、状态、进度或用量；减频、指数退避和有限次数仍是轮询。
- 变化通过事件、WebSocket/SSE、回调通知；用户动作可触发单次查询。单次操作超时不得接续为查询循环。
- 连接保活不得查询业务状态、读写存储或扫描。事件连接的服务端和底层 SDK 也必须检查，不能仅凭接口叫“stream”就认定合规。
- 同时检查空闲和执行中路径；有残余轮询就明确记录，不能将“空闲时不轮询”写成整个服务合规。已有实现的处理与验证见[事件链路审查](references/event-driven-review.md)。
- 只有用户明确修改本约束才能放宽，不为可靠性、兼容性或排障自行恢复轮询。

## 渐进读取与执行

1. 从当前 Skill 的实际位置推导根目录。若存在，先读小型 `experience.local.md` 实例索引。
2. 读[能力索引](references/capabilities/index.md)，命中本次涉及的能力；再读对应能力档案和目标 operation。跨能力场景仅补读确实涉及的档案，不扫描整个知识库。
3. 只有定位具体应用时，才读取其本机实例；以当前账户、环境、脚本、namespace、绑定、套餐和存储后端复核旧记录。
4. 涉及额度或价格决策时查当前官方来源；能力档案中的日期是上次核对时间，不是永久保证。不能取得最新文档时注明未复核，不以旧数值决定升降级或付费。
5. 选择当前可用的 CLI/API 执行工具，先理解目标和现有授权。真实网页操作时加载可用的 Ego 浏览器 Skill 与 ego-ops；浏览器导航经验归 ego-ops，平台能力经验归本 Skill。
6. 按 operation 成功标准核对结果。部署命令完成、公开首页 200、analytics 暂时为空或计数没增长，都不足以证明业务恢复或没有轮询。

用户已有授权持续有效，不反复确认。知识记录本身不授予部署、删除数据、付费或停服务权限；任务已授权的动作直接完成，新增范围才需要澄清。不要为维护知识创建后台监控、轮询器或定期抓取任务。

## 写回协议

完成设计、诊断或操作后，读取[知识格式与状态](references/knowledge-schema.md)，当场更新唯一归属文件：

- 官方文档事实、源码推断、本地运行证据、生产读回分开写；保留来源、日期、适用范围与未解决项。
- `documented` 是文档/设计指引，`partial` 是只有部分路径验证，`verified` 是该操作声明的目标和成功标准均有实际证据。只有 `verified` 填 `last_verified`。
- 未完成时可以记录真实失败证据与待办，但不刷新成功日期；重复成功才刷新相应 operation 和索引的验证日期。
- 修改失效结论和索引，避免只追加互相冲突的段落。平台数字只更新能力档案；应用状态只更新私有实例。
- 账户标识、真实域名、机器路径、版本 ID 和内部拓扑仅放 ignored 本机记录；任何位置都不得保存凭据、Cookie、Token、签名 URL 或完整业务响应。
- 写回后运行 `node <skill-root>/scripts/validate-knowledge.mjs`，处理结构错误，再声明沉淀完成。校验器不核对 Cloudflare 运行态、不证明无轮询。

自动写回仅修改本次知识，不自动提交、推送或部署。叙述、进度和脚本输出使用中文，代码标识符保留原样。
