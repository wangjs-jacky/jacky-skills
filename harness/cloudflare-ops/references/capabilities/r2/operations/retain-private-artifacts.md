# 管理私有原件与派生产物

## 目标

原件与派生关系可追溯，临时产物可清理，业务删除立即拒绝访问，不引入周期扫描。

## 适用状态与前置条件

已定义身份、文件上限、对象登记、正式/临时保留规则和删除范围。先核实桶访问配置与[能力边界](../index.md)。

## 设计与执行

1. 默认私有桶；通过鉴权API流式上传下载，不向前端提供长期存储凭据。
2. 写入前登记对象ID、期望摘要、来源修订与状态；实际字节、类型和摘要核实后才发布引用。
3. 原件、页面、裁图和模型结果分别保存不可变对象及变换关系。临时前缀配置R2生命周期，正式前缀不被短期规则匹配。
4. 大响应落R2后再事务提交业务引用。中断产生的已登记对象可显式恢复，未采用临时对象由生命周期清理。
5. 删除先tombstone和取消相关任务，再按有限关联清单幂等删除；失败保存进度供用户一次恢复，不用周期列表扫描。
6. 导出包含内容哈希、关系与删除水位；恢复时重放较新的删除决定，区分逻辑不可见与平台备份物理消失。

## 坑与恢复

原件不能被压缩/裁图覆盖；同哈希共享资产须检查其他有效引用。过期通常有延迟，不能对用户保证瞬时擦除。上传成功不等于元数据已提交，临时对象变正式与引用发布的窗口必须可追踪。

## 成功标准

未登录和删除后读取拒绝；上传中断、重复完成、对象落盘后数据库失败均可恢复；生命周期范围与正式引用不冲突；导出恢复关系完整，过期和删除没有应用轮询服务。
