# 发布托管静态快照并核对公开读回

## 目标

通过已安装宿主的 managed tunnel 分支发布授权的静态快照，核对实际公开入口和有限浏览器读回，并记录所查分支的事件驱动与生命周期边界。目标不包括固定 hostname、替换既有源站、hosted 模式、账户配置或运行满24小时的稳定性验证。

## 适用状态与前置条件

当前任务已授权公开明确范围的静态文件，宿主提供签发工作区与发布工具；机器、会话和网络须持续可用。工具的槽位是宿主限额，不能换算为 Cloudflare 平台 quota。

发布流程的权威为 happy-ops → execution / diagnose-integration；精确工作区、固定快照、同 ID 不更新和字体封装继续遵循该操作，不在此复制另一套实现。本条只处理所测 managed tunnel 的平台边界。实际网页读回由 ego-ops 路由至当前产品，再遵循 ego-browser。

## 设计与执行

1. 将源码核对、宿主工具结果与公开浏览器读回分别取证。源码只能说明所读版本的实现；一次发布返回入口不能代替页面或业务验证。
2. 按 Happy 的权威流程准备、发布授权静态快照，保留工具返回的入口、模式和到期时刻到本机实例。内容变更使用新签发目录，不将原快照视作可更新源站；旧链接按用户选择处理。
3. 本次所查已安装 managed 分支将校验文件一次读入不可变内存资源表，HTTP 请求由 server 事件处理。隧道就绪来自 stdout/stderr data 事件及连接注册消息；启动只有一次45秒超时，到期只有一次24小时停止定时器。它们不反复查询业务状态。
4. 已保存核对在该分支未发现 setInterval、sleep/while 或递归状态查询循环；这不是对全部 cloudflared、SDK、Workers、其他模式或平台内部的无轮询审计。单次超时之后不得接续查询循环，继续遵守[事件链路审查](../../../event-driven-review.md)。
5. 根据当前产品的实际入口核对公开页面。修正版主文有桌面1440×900和手机390×844读回、所测宽表局部滚动；所列案例/报告请求与抽样交互、首图加载各按其真实覆盖记录，不能扩展成全部页面功能通过。

## 坑与恢复

- 临时 Quick Tunnel 子域不是永久入口。重新发布的快照有新入口，不能把旧链接保留写成旧内容已更新，也不能混同固定域名发布或源站替换。
- 本次公开阅读 CSS 只增加一处手机主列宽度约束，其余46个公开文件字节不变；本地与公开复验说明该封装修正有效，不构成新的业务实验。
- 源码中的单次启动超时与单次到期停止是有界事件，不是业务轮询；仍不能据此宣称共享平台或进程所有内部路径已审计。
- 工具的最长24小时契约与实际 expiresAt 仅说明约定的有效期。到期停止、会话退出清理、断网恢复及满24小时持续运行均未实测，不填成已通过。
- 本次复制公开资源时出现过 IncompleteRead，后续独立资源下载及哈希核对成功，但未证根因；不将该现象登记为平台缺陷或通用网络修复。

## 成功标准

授权静态范围确有 managed tunnel 发布结果；当前入口有与所声明范围匹配的真实公开读回；源码、公开与生命周期证据分开；所查分支的业务状态轮询核对有明确范围；旧入口保留及源码包仍仅本地的边界有记录。

这些标准只对应本条有限发布与诊断目标，不要求、也不宣称固定域名、生产业务、整个平台无轮询或24小时长稳成功。
