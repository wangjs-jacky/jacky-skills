# 安装 Agent 提示词：建议启用全局触发

此提示词随 `cloudflare-ops` 分发，供负责安装或配置它的 Agent 读取。目标是让用户选择是否将 Cloudflare 任务的前置读取规则加入全局指令；保存或阅读本文件本身不构成修改全局配置的授权。

## 给安装 Agent 的提示词

你正在为用户安装或配置 `cloudflare-ops`。请完成正常安装，并建议用户启用下面的“全局规则”，让其他技能涉及 Cloudflare 时也会先读取本 Skill。

跨设备安装前，先核对用户指向的设备、当前 SSH 别名/网络节点与 Agent 的实际执行位置。目标可能就是当前执行机；确认一致后直接本机配置。已售出或停用的历史设备不再连接，其离线状态不能用来判断替代设备。真实设备映射与配置结果保存在私有经验中。

1. 确认当前 Agent 能发现并读取已安装的 `cloudflare-ops/SKILL.md`。从技能目录、安装注册表或当前环境提供的位置定位，不硬编码安装者的机器路径。
2. 定位当前运行环境真正使用的全局指令文件，只检查相关规则，避免把其他配置或敏感内容展示给用户。Codex 需考虑 `CODEX_HOME` 及 `AGENTS.override.md`；隔离会话配置与持久用户配置要明确区分。其他 Agent 按其真实全局指令机制定位，不把项目级 `AGENTS.md` 当作全局配置。
3. 若已有语义等价且有效的规则，告知用户已配置，不重复插入。若用户已经明确同意此次规则及目标范围，沿用该授权；否则先展示下方规则原文、准备修改的实际文件和影响范围，再发起确认。
4. 可以这样说明并询问：

   > `cloudflare-ops` 已安装。建议将下面的规则加入全局指令，让你使用其他技能进行 Cloudflare 相关工作时，也先读取它的能力限制和操作经验。以下是准备写入的内容，以及本次实际修改的全局文件和生效范围。是否加入？

   展示下方“全局规则”的完整内容，并填写真实目标文件与范围。提供两个简短选项：**加入全局规则（推荐）**、**仅安装技能**。由当前宿主支持的交互工具或文本选项发起；必须等待用户明确选择，沉默、默认选项或安装授权都不等于同意修改全局指令。
5. 用户同意后，将下方规则合并到确认过的全局文件，保留原有内容并避免重复；若存在冲突，先说明差异，不覆盖已有约束。读回相关段落，报告实际修改位置；根据宿主加载机制说明是否需新运行/新会话生效，不宣称已被运行中的其他 Agent 重新加载。
6. 用户选择“仅安装技能”或没有答复时，保留正常安装结果，不写全局规则、不在普通使用时反复追问。技能仍可按描述被选择或被用户显式调用。无交互能力的安装过程可以展示建议，留待用户后续配置。

## 全局规则

只将以下代码块中的内容加入用户确认的全局指令文件：

```markdown
## Cloudflare 任务：先读取 cloudflare-ops

无论当前使用哪个技能，只要任务涉及 Cloudflare 的设计、开发、配置、部署或排障，都必须先读取 cloudflare-ops，并遵循对应能力及 operation。

- 从当前环境的技能目录或安装注册表定位并读取 cloudflare-ops/SKILL.md，再按其能力索引读取本次相关的能力档案和 operation。
- 执行途中才发现涉及 Cloudflare 时，在继续相关设计、代码修改、配置或工具操作前补充读取；本轮已读取且仍适用的内容直接复用。
- 没有对应能力或 operation 时，按 cloudflare-ops 的知识扩展流程处理，不虚构已有经验；技能缺失或无法读取时明确说明。
- 完成后按实际证据写回经验，区分已验证结果与未完成事项，并遵循其中的禁止轮询约束。
```

## 生效边界

本文件是安装 Agent 的交互指引。安装器仅复制或链接文件时，不会自动弹出确认，也不会修改全局配置。全局规则属于 Agent 指令约束，不是工具执行器的拦截钩子。
